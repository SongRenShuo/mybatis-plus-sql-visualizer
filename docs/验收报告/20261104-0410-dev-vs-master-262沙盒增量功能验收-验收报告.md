## 三、环境债（非产品缺陷，登记以备下轮）

1. 预览面板/日志面板的自绘控件（数据源下拉、红条链接、筛选弹层内勾选）对合成鼠标输入 no-op——与既往「插件自绘 UI 对合成输入不可达」同族；弹层可达的例外是「更多」菜单（键盘 Down+Enter 可用）。
2. 设置对话框内容区滚轮/PageDown/滚动条点击 no-op——与既往「设置页滚轮 no-op」同族；低处字段（mask 三档、环境自检按钮、更新回滚）本轮 GUI 不可达。
3. runIde 262 沙盒启动期平台自身 SEVERE 一条（PropertiesComponent/ProjectPropertyService，Plugin: com.intellij）——与插件无关，idea.log:482。
4. 状态栏 widget 的物理坐标在最大化窗口下随 DPI/边框漂移：实测 y=1017（1920×1080，rect bottom=1040 假象），下次探针直接用 D07 量法。
