## 4. 翻译硬规则

具名实参→位置实参；`object`→`INSTANCE`/既有静态形态；顶层函数→`XxxKt` 门面；record 访问器**无 get 前缀**；`copy()` 手工重建；`data class` 拆独立文件；函数类型字段落 `Function0/Function1/...`（**禁 Supplier/Predicate**）；默认参数→显式重载（泛型擦除冲突时弃重载直呼全参构造器）；`val x = when(...)` → **switch 表达式 + yield**；受检异常 override 用既有 `sneakyThrow`；`@Service` 轻服务类显式 `final`；新枚举产出写**限定形态** `return EnumName.X;`；elvis 内层 null 合并勿漏；属性初始化器引主构造参→挪构造器体；`by lazy`→WeakHashMap 侧表；fatal 透传 `throw (Error) t`；`runCatching`→try/catch。
含 `&&`/`||` 与 `== null` 条件**逐条与 master 原文对照**（曾有静默反转致 19 例 NPE）。
