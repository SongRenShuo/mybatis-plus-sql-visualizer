# 导入参数弹框 + 驼峰/下划线自动匹配 + 默认回显当前参数（P-05.1）开发计划

> 状态：✅ 已实施（2026-11-13 代码核对回填——`ParamImportDialog` 多行导入 + `CaseFormatUtil` 驼峰/下划线互转匹配链在 `SqlPreviewPanelParamPanel`）
> 需求来源：用户反馈「导入弹框手动输入 + 灰色示例 + 驼峰匹配」+「弹框默认回显当前 SQL 参数（JSON 格式）」

## 1. 目标与范围

1. **按钮文案**：「导入」→「导入参数」。
2. **弹框手动输入**：点击导入参数时弹出一个带多行输入框的对话框，让用户粘贴/编辑参数文本，并以**灰色占位文本**提示支持的格式示例（JSON / CSV / key=value）。
3. **驼峰/下划线自动匹配**：导入参数时，key 与 source 的匹配除了现有的精确匹配（`key ≡ source` 或 `key ≡ #source`），新增**驼峰 ↔ 下划线**互转匹配（`userName` ≡ `user_name`）。
4. **默认回显当前参数**：弹框打开时，自动将当前 SQL 的参数值（`paramValues`）序列化为 JSON 预填到输入框，用户在此基础上修改。无参数时弹空框 + 占位示例。
5. **格式化 / 清除按钮**：弹框顶部工具栏新增格式化（JSON 美化 / 文本归一）和清除（清空输入框）图标按钮。

**已确认决策**：
- 触发方式：点击「导入参数」始终弹框（不读取剪贴板，不再直接导入）。
- 对话框形态：`DialogWrapper` 子类，顶部工具栏 + 中部 `JBTextArea`（多行）。
- 默认回显：`paramValues` → JSON 序列化 → 预填输入框。空参数传 null（显示占位示例）。
- 灰色示例：`JBTextArea.emptyText` 原生能力。
- 驼峰匹配策略：精确匹配优先 → 去 `#` 前缀精确匹配 → 驼峰/下划线互转匹配（三级 fallback）。
- 互转算法：`userName` ↔ `user_name`（纯字母数字，不含连续下划线/首尾下划线）。
- 图标风格：参考 SqlToJavaPanel 工具栏（`AllIcons.Actions.ReformatCode` / `AllIcons.Actions.GC`，`IconScaler.scale(14f/16f)` 缩放）。

```kotlin
object CaseFormatUtil {
    fun camelToSnake(input: String): String =
        input.replace(Regex("([a-z0-9])([A-Z])")) { "${it.groupValues[1]}_${it.groupValues[2].lowercase()}" }

    fun snakeToCamel(input: String): String =
        input.replace(Regex("_([a-z0-9])")) { it.groupValues[1].uppercase() }
}
```

### 3.2 resolveSource 改造（三级 fallback）

```kotlin
private fun resolveSource(key: String, sources: Set<String>): String? {
    if (sources.contains(key)) return key
    val stripped = if (key.startsWith("#")) key.substring(1) else key
    if (sources.contains(stripped)) return stripped
    val snake = CaseFormatUtil.camelToSnake(stripped)
    if (sources.contains(snake)) return snake
    val camel = CaseFormatUtil.snakeToCamel(stripped)
    if (sources.contains(camel)) return camel
    return null
}
```

```kotlin
class ParamImportDialog(
    private val project: Project,
    private val preFill: String? = null,
    private val onConfirm: (String) -> Unit,

    private val textArea = JBTextArea(8, 48).apply {
        emptyText.text = MpSqlVisualizerBundle.message("panel.param.import.dialog.placeholder")

        content.add(createToolbar(), BorderLayout.NORTH)  // 格式化 + 清除

            MpSqlVisualizerBundle.message("panel.param.import.dialog.clear"), ::clearInput))
    }

    private fun formatInput() { /* JSON 美化 / 文本归一 */ }
    private fun clearInput() { textArea.text = "" }

    public override fun doOKAction() {
        val text = textArea.text
        super.doOKAction()

    }
```

### 3.4 入口改造（SqlPreviewPanel）

```kotlin
fun importParamsFromClipboard() {
    val proj = project ?: return
    // 将当前 paramValues 序列化为 JSON 预填
    val preFill = if (paramValues.isEmpty()) null else serializeParamsToJson()
    ParamImportDialog(proj, preFill) { input ->
        importParams(ParamImportParser.parse(input))
    }.show()
}

/** 将 paramValues 序列化为 JSON 字符串（自实现，不依赖 Jackson）。 */
private fun serializeParamsToJson(): String {
    val entries = paramValues.entries
        .filter { it.value.isNotEmpty() }
        .joinToString(",\n") { (k, v) ->
            val escaped = v.replace("\"", "\\\"")
            """  "$k": "${escaped}""""
        }
    return "{\n$entries\n}"
}
```

**预填效果**：
```json
{
  "name": "张三",
  "age": "28"
}
```

**边界**：
- `paramValues` 为空 → `preFill = null` → 弹空框 + 占位示例
- 所有参数值为空串 → 同上（过滤空值后无有效条目）

### 3.5 格式化逻辑

```kotlin
private fun formatInput() {
    val text = textArea.text
    if (text.isBlank()) return
    val trimmed = text.trim()
    textArea.text = if (trimmed.startsWith("{") || trimmed.startsWith("[")) {
        formatJson(trimmed)  // JSON 美化：加缩进换行
    } else {
        normalizeText(trimmed)  // 非 JSON：去空行 + 行级 trim
    }
}
```
