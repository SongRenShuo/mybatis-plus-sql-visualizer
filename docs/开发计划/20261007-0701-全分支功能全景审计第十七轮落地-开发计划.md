## §九 实施记录

- 20261008 车道A批二 R61 落地（t-lanea2 `7028b1c`）：EXPLAIN 执行计划跨次对比（R33 结构化底座现成，随批上车）。
  - **V113 前提实测回执**：① ExplainJsonPlanTree 无既有节点稳定标识 → 补 `flattenPlanNodes` 结构化视图，节点身份双档（path=结构位置路径 + matchKey=`nodeType on relation#出现序`，兄弟增删只挪 path 不影响同键配对）；② EXPLAIN 结果**会话级**（SqlPreviewPanel 面板实例存活期 `lastStructuredExplain` 基线，不持久化、不跨会话）——对照 ExplainPanelChannel 生命周期核实，会话级即满足跨次对比意图，无需落盘，未过度持久化；③ Oracle DBMS_XPLAN 文本格式统一建模**成本评估后弃置**（文本缩进树需独立解析器、且无真机回归面，成本高于本期收益）——诚实降级只做结构化两族（JSON＝PG/KingBase/openGauss、TABLE＝MySQL/MariaDB/OceanBase，ExplainPanelChannel.STRUCTURED_FORMATS 同口径），Oracle/SQL Server 返回 null 无可比。
  - 实现：ExplainPlanDiff 纯逻辑对比（JSON 按 matchKey 配对比 rows/cost/标量键；TABLE 按 id+table 列配对给数值增量+列文本变化；任侧不可结构化 → null）；SqlPreviewPanel 结构化 onPlan 链计算 diff + 滚动更新基线 + 视图入参；ExplainPlanResultView 对比条（照抄索引建议条形态，diff 非 null 才占位，isEmpty 显式告知「计划无变化」）；bundle 双语 7 键。
  - 定向 EXPLAIN 面板族 40/0 绿（ExplainPlanDiffTest 10 + ExplainJsonPlanTreeTest 13 + ExplainPanelWiringGuardTest 6 + ExplainPlanResultViewUiTest 8 + BundleParityGuardTest 5，含既有全量）。反向验证在案：摘除基线滚动 → `R61_跨次对比接线在位` 变红（6/1，断言会话级基线必须滚动更新）→ 恢复绿。
  - 注：SqlPreviewPanel 同树曾混入遗留陈旧测试类编译产物（NoSuchMethodError 指向旧 SqlHistoryEntry 构造器），删陈旧 class 强制重编译后定向族全绿——非本次 R61 代码问题。
