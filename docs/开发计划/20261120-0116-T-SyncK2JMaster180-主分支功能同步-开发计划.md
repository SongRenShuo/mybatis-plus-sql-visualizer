## 4. 翻译硬规则（两车道共同遵守，摘自 skill + 179 轮沉淀）

具名实参→位置实参；`object`→`INSTANCE`；顶层函数→`XxxKt` 门面；record 访问器无 get 前缀；`copy()` 手工重建；`data class` 拆独立文件；函数类型字段落 `Function0/Function1/...`；默认参数→显式重载（泛型擦除同疑符冲突时弃重载直呼全参构造器）；`when` 赋值→switch 表达式+yield；受检异常 override 用既有 `sneakyThrow`；`@Service` 类显式 `final`；新枚举产出 `return EnumName.X;` 限定形态；elvis 内层合并勿漏；属性初始化器引主构造参→挪构造器体；`by lazy`→按场景（record 无实例字段用 WeakHashMap 侧表）；fatal 透传 `throw (Error) t`；runCatching 降级→try/catch。
本地权威：**新 Java 文件落在与既有 k2j 邻居相同的包与命名风格**；对既有类的修改参照该类 .java 当前实现，逐 hunk 对齐 master 终态（`git show cd1b94562:<path>` 唯一权威读法）。
