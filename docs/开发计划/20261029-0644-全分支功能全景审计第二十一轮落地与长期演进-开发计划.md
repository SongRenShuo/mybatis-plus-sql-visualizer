## 七、执行纪律（沿用仓规）

- 并行铁律：gradle 前查 `parallel_tasks.py`、构建并发 ≤2 路、子代理 ≤3 路、长命令后台启不空等、达标即提交、回填写各自工作树副本。
- 合流顺序硬约束：rp9 → magpie → insight 串行（三支都触 `SqlPreviewPanel*`/CHANGELOG/索引，禁并行合流）；每笔合流后跑一次全量再合下一笔。
- 子代理只跑定向测试；统一全量门禁单派只读收口代理；S2-2 巨文件拆分触发构建校验（大改动）。
- 每券反向验证：守卫类改动必造回缺陷形态验证变红；禁空绿。
- 主控并行写文档期间不得碰 `src/main`；复核判 blocker 且修复落 src/main 时全量读数作废重跑。
