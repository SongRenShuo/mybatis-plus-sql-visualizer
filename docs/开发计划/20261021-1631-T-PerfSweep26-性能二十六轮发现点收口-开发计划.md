## 三、P1 修复详单

### T-PerfSweep26-01（F83）：淘汰回扫键级计数化

- **现状**：SqlLogEntryBuffer.kt:289-302——被淘汰条目恰为该键最新时（唯一键恒真），`entries.lastOrNull { canDedupe(it) && it.dedupeKey == k }` 全队反扫后 remove；唯一键稳态=每接受一条付一次 O(maxEntries) 锁内反扫、结果必空。
- **修法（推荐 B 案）**：
  - **A 案（弃用倾向）**：`dedupeCounts[k] ?: 0 == 0` 时跳过反扫直接 remove 索引。利：零新结构。弊：dedupeCounts 是丢弃计数且自身有容量淘汰（P-1 已证伪其语义），计数被淘汰后误判 0 会造成「同键第二条仍在队内→跳过反扫→索引被 remove→下一条同 SQL 漏去重」的**正确性窗口**；除非先证伪该窗口不可达，否则不选。
  - **B 案（推荐）**：新增「键→队内现存条数」计数结构（与 dedupeIndex 同锁同步维护：接受入队 +1、淘汰 -1），淘汰回扫仅在现存计数 >1 时执行，==1 直接 remove 索引。键域=dedupeIndex 键域，天然有界；O(1) 每条。
- **先红后绿判据**：①新用例「同键多条在队 → 淘汰最新 → 断言 dedupeIndex 重指次新条目」（B 案写错即红）；②「唯一键稳态淘汰 → 断言不再触发全队反扫」（计数缝或扫描探针；修复前 0 守卫，本条即新增守卫）；③反向=摘除计数短路 → 用例② 必红，贴两次读数。
- **风险与交互**：O-147 融合（mergeDuplicateEntry 改变保留条目）时计数同步；dedupeEnabled 关闭态路径不得触发计数维护；isDuplicate 未命中路径不计数。

### T-PerfSweep26-02（F95）：foldingBuilder 尊重 quick + 体量熔断

- **现状**：SqlMapperFoldingBuilder.kt:36-48——buildFoldRegions 忽略 quick 参数，quick=true 仍做 `PsiTreeUtil.findChildrenOfType` 全 PSI 子树遍历+逐标签 getAttributeValue；无体量熔断。
- **修法**：①quick=true 时短路（返回空集，平台 XML 折叠兜底；若 243 沙盒走查见折叠区闪烁再评估「按修改戳缓存上次结果」的 B 方案）；②文件文本 > `XmlSynHiGate.MAX_TEXT_LENGTH`（100K）时短路，与注入族熔断对齐。
- **判据**：先红=quick=true 夹具断言零 PSI 遍历（计数缝）+ 超大文件夹具断言返回空；反向=摘除 quick 短路 → 必红。
- **前提**：P-2（quick 语义从 243 sources jar 核实）。

### T-PerfSweep26-03（F96）：namespace→file 结果级 memo

- **现状**：MybatisXmlTargets.kt:87-94/222-241——只有文件清单 5s TTL 槽，无 namespace→file 结果 memo；TTL 过期后首次 resolve 触发 FileTypeIndex 清单重建+逐文件 namespace 比对。
- **修法**：结果级 memo（键=namespace，失效=ProjectRootModificationTracker 结构版本 + 文件清单代 + 容量上限 64 淘汰）；**memo 命中/未命中语义必须与现行为逐字一致**（含「同 namespace 多文件歧义」的现处理——若现行为取首个，memo 后同样取首个且在清单代变化时重算）。
- **判据**：先红=同 namespace 二次 resolve 断言 FileTypeIndex 触发次数不增长（测试缝）；反向=摘 memo → 红并在清单代变化用例中断言 stale 结果不出现。
- **前提**：P-3。

### T-PerfSweep26-04（F97）：holderClass 解析批内缓存

- **现状**：MybatisXmlReferenceContributor.kt:159-171——BeanPropertyReference.holderClass 祖先链每层对 5 个属性名逐一 resolveClass，最坏 24×5 次，不 memo。
- **修法**：解析改「按类 FQN 批内缓存」（单次 resolve 会话内局部 Map，或带修改戳的 per-file memo——实施时按引用解析器的生命周期选局部 Map 起步，保守无 stale 面）；最坏 24×5 → 24 次 findClass + 5×层次 查表。
- **判据**：先红=批量解析用例断言 findClass/resolve 调用次数下降（测试缝计数）；反向=摘缓存 → 计数回升红。

### T-PerfSweep26-05（F98）：停靠预览同一性短路前置（一行）

- **现状**：SqlDockedPreview.kt:121-122——refreshSelection 每事件先 isPinned()（=editor.document.text 全文拷贝+比较），`displayedEntry === entry` 短路在其后。

- **判据**：先红=同条目连续两次 ListDataEvent 断言 document.text 读取次数为 0（借 `displayedSqlForTest` 旁加读取计数缝）；反向=摘短路 → 红。
