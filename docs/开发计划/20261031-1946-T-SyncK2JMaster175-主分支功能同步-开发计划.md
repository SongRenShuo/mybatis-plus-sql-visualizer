## 7. 已知坑预案

1. **翻译硬规则**（速查）：具名实参→位置；`object`→INSTANCE/既有静态形态；顶层函数→`XxxKt` 门面；record 访问器无 get 前缀；`copy()` 手工重建；函数类型字段落 `Function0/1/...`（禁 Supplier/Predicate）；默认参数→显式重载（泛型擦除冲突时直呼全参）；`val x = when(...)` 落 switch 表达式+yield；受检异常 override 用既有 `sneakyThrow`；新枚举常量产出写 `return EnumName.X;` 限定形态；elvis 内层 null 合并勿漏；属性初始化器引用主构造参数→挪构造器体；`by lazy`→record 无实例字段用 WeakHashMap 侧表；fatal 透传写 `throw (Error) t`。
2. **形态锚点型守卫 vs 默认参双载**：Kotlin 默认参落 Java 双重载后，functionBody 断言会命中 1 参委托壳必红——守卫锚点迁全参真身。
3. **fatal 基线三处联动**：`BannedApiSourceScanTest.fatalCatchSiteTotalBaseline`（现值 912）+ 镜像未判定基线 + 全量副本；一律以守卫实测 message 里的 expected/was 重登，禁行数预判；新落地集文件按判定点数入 `fatalPassthroughGuardedFiles`。
4. **守卫扫描根**：master 新到的守卫类若硬编码 `src/main/kotlin`+`.kt` 须适配 `src/main/java`+`.java`（否则 0 文件静默假绿）；Kotlin 专有判据改 Java 等价形态。新守卫（ChangeNotesRatingLineGuardTest、DialectInferFallbackGuardTest、SqlDialectParserDefinitionPairingGuardTest、DialectCaptureCoverageTest 等）登记 `GuardSelfTestCoverageMetaGuardTest.GUARD_CLASSES`（含 FnKind 与自证语料名）。
5. **共享工作树**：pathspec 限定提交铁律；开工/收口各查 `git log` 分支是否前进；裸 commit 会卷走并行暂存。
6. **gradle**：跑前 `python C:\Users\USER\.zcode\cli\parallel_tasks.py check/register/done --name <任务名>`（裸 done 禁用）；并发加 `-Pkotlin.compiler.execution.strategy=in-process`；中文错误 `| iconv -f GBK -t UTF-8`；判绿双证（PIPESTATUS）；构建并发上限 2 路。
