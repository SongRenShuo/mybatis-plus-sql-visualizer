# 批量 SQL → Java 转换（P1）开发计划

> 状态：✅ 已落地（T-BatchSql 多语句顶层分号拆分批量路径，`ConvertSqlToJavaAction`；2026-11-13 代码核对回填）
> 需求来源：用户反馈「SQL → Java 转换只支持单条语句，粘贴多条 SQL 时报错，希望支持批量转换」。

## 1. 目标与范围

在「SQL → Java」tab 面板（`SqlToJavaPanel`）和编辑器 `ConvertSqlToJavaAction` 上支持**多条 SQL 批量转换**——粘贴 `SELECT ...; SELECT ...;` 这类多语句文本，自动拆分为多个 `SqlReverseResult`，输出为一个代码块（多个方法或多个变量），每条可单独勾选形态。

**已确认决策**：
- 语句拆分：以**顶层分号**为分隔（不拆分字符串/注释内的分号），空语句自动跳过；
- 输出形态：每条 SQL 独立生成一个 Wrapper 表达式/调用语句，按顺序拼接为一个代码块（换行分隔）；
- 实体查找：主表实体候选统一解析一次（所有语句共享同一项目上下文），副表按语句独立解析；
- 错误隔离：单条解析失败不中断整体，失败语句输出错误注释占位（`// 第 N 条 SQL 转换失败：原因`），其余正常输出；
- 形态选择：面板形态下拉（`formatCombo`）对所有语句统一生效，不支持逐条差异化形态。

## 2. 现状分析

### 2.1 当前单条链路

`SqlToJavaConverter.parse(sqlText)` → `SqlReverseParser.parse()` 在遇到分号时直接报错：

```kotlin
// SqlReverseParser.parseTailClauses 内（第 302-305 行）
t.type == TokenType.SYMBOL && t.text == ";" -> {
    cursor.advance()
    if (cursor.current != null) unsupported(cursor, "多条语句（一次转换一条）")
    break
}
```

即：分号后还有 token → 抛 `KEY_UNSUPPORTED` 错误「多条语句（一次转换一条）」。

### 2.2 面板入口

`SqlToJavaPanel.convert()` 调用 `SqlToJavaConverter.parse(text)`，单条失败即红字提示，无批量分支。

### 2.3 编辑器 Action 入口

`ConvertSqlToJavaAction` 同样走 `SqlToJavaConverter.parse`，单条限制同上。

### 2.4 关键约束

- `SqlReverseParser` 是纯函数、零 IDE 依赖，拆分逻辑应在调用层（`SqlToJavaConverter`）处理，不污染解析器；
- 实体查找走 `ReadAction`（PSI 索引），批量场景应**一次性** ReadAction 内完成所有语句的候选查找，避免多次切换线程；
- 面板 `cacheResult` / `cacheText` 缓存机制需适配批量场景（缓存键从单文本 → 文本列表）。

## 3. 架构与数据流

```
多语句文本（粘贴）
  → SqlToJavaConverter.splitStatements(text)  // 顶层分号拆分 + 空语句过滤
      → List<String>（各语句纯文本，去首尾空白）
  → 逐条 SqlReverseParser.parse(statement)    // 纯函数，EDT 安全
      → List<Either<SqlReverseException, SqlReverseResult>>（错误隔离）
  → 实体查找（单次 ReadAction，所有语句的主表/副表候选统一查）
      → Map<Int, List<EntityCandidate>>（语句索引 → 主表候选）
      → Map<Int, Map<String, List<EntityCandidate>>>（语句索引 → 副表候选）
  → 逐条 SqlToJavaConverter.generateCode（形态统一，错误占位）
      → List<String>（各条生成代码或错误注释）
  → 拼接为代码块（换行 + 分隔注释）
  → 输出到结果编辑器
```

## 4. 详细实施方案

### 4.1 语句拆分（`SqlToJavaConverter.splitStatements`）

新增纯函数，顶层分号拆分：

```kotlin
/**
 * 按顶层分号拆分多语句文本（不拆分字符串/注释内的分号）。
 * 空语句（纯空白）自动跳过；保留语句首尾空白 trim。
 */
fun splitStatements(text: String): List<String> {
    val statements = mutableListOf<String>()
    val current = StringBuilder()
    var inSingleQuote = false
    var inDoubleQuote = false
    var lineComment = false
    var blockComment = false
    var i = 0
    while (i < text.length) {
        val c = text[i]
        val next = text.getOrNull(i + 1)
        when {
            // 行注释开始
            !inSingleQuote && !inDoubleQuote && !blockComment && c == '-' && next == '-' -> {
                lineComment = true; current.append(c); i++
            }
            // 行注释结束
            lineComment && c == '\n' -> {
                lineComment = false; current.append(c); i++
            }
            // 块注释开始
            !inSingleQuote && !inDoubleQuote && !lineComment && c == '/' && next == '*' -> {
                blockComment = true; current.append(c); i++
            }
            // 块注释结束
            blockComment && c == '*' && next == '/' -> {
                blockComment = false; current.append(c); i++
            }
            // 单引号字符串
            !inDoubleQuote && !lineComment && !blockComment && c == '\'' -> {
                inSingleQuote = !inSingleQuote; current.append(c); i++
            }
            // 双引号字符串
            !inSingleQuote && !lineComment && !blockComment && c == '"' -> {
                inDoubleQuote = !inDoubleQuote; current.append(c); i++
            }
            // 顶层分号 → 拆分
            !inSingleQuote && !inDoubleQuote && !lineComment && !blockComment && c == ';' -> {
                val stmt = current.toString().trim()
                if (stmt.isNotEmpty()) statements.add(stmt)
                current.clear(); i++
            }
            else -> { current.append(c); i++ }
        }
    }
    // 末段（无尾分号）
    val tail = current.toString().trim()
    if (tail.isNotEmpty()) statements.add(tail)
    return statements
}
```

**边界处理**：
- 字符串内分号（`'a;b'`）不拆分；
- 注释内分号（`-- a;` / `/* a; */`）不拆分；
- 空语句（`SELECT 1;; SELECT 2`）跳过中间空段；
- 末段无分号（`SELECT 1`）也作为一条。

### 4.2 批量解析入口（`SqlToJavaConverter.parseBatch`）

```kotlin
/** 单条解析结果（成功 or 失败）。 */
data class BatchItemResult(
    val result: SqlReverseResult? = null,
    val error: SqlReverseException? = null,
    val sourceIndex: Int,
)

/** 批量解析（纯函数，EDT 安全；错误隔离）。 */
fun parseBatch(statements: List<String>): List<BatchItemResult> {
    return statements.mapIndexed { index, stmt ->
        try {
            BatchItemResult(result = SqlReverseParser.parse(stmt), sourceIndex = index)
        } catch (e: SqlReverseException) {
            BatchItemResult(error = e, sourceIndex = index)
        }
    }
}
```

### 4.3 批量实体查找

在单次 `ReadAction` 内完成所有语句的实体候选查找：

```kotlin
/** 批量实体查找（单次 ReadAction，所有语句共享）。 */
fun findCandidatesBatch(
    project: Project,
    results: List<BatchItemResult>,
): Pair<Map<Int, List<EntityCandidate>>, Map<Int, Map<String, List<EntityCandidate>>>> {
    val mainCandidates = mutableMapOf<Int, List<EntityCandidate>>()
    val subCandidates = mutableMapOf<Int, Map<String, List<EntityCandidate>>>()
    results.forEachIndexed { index, item ->
        val result = result ?: return@forEachIndexed
        mainCandidates[index] = findCandidates(project, result.tableName)
        subCandidates[index] = findSubEntityCandidates(project, result.joins)
    }
    return mainCandidates to subCandidates
}
```

### 4.4 批量代码生成与拼接

```kotlin
/** 批量生成代码（单条失败输出错误注释占位，不中断整体）。 */
fun generateBatchCode(
    results: List<BatchItemResult>,
    mainCandidates: Map<Int, List<EntityCandidate>>,
    subCandidates: Map<Int, Map<String, List<EntityCandidate>>>,
    format: ReverseWrapperFormat,
    invocation: JavaCodeGenerator.InvocationTarget?,
): String {
    return results.mapIndexed { index, item ->
        val result = item.result
        if (result == null) {
            val err = item.error!!
            "// 第 ${index + 1} 条 SQL 转换失败：${MpSqlVisualizerBundle.message(err.key, err.detail)}"
        } else {
            val candidates = mainCandidates[index].orEmpty()
            val subs = subCandidates[index].orEmpty()
            // 复用现有 generateCode 逻辑（单条）
            generateCode(result, candidates.firstOrNull(), format, invocation, subs)
        }
    }.joinToString("\n\n")
}
```

### 4.5 面板 UI 适配

`SqlToJavaPanel.convert()` 新增批量分支：

```kotlin
private fun convert() {
    val text = inputEditor.text
    if (text.isBlank()) { ... return }

    // 拆分多语句
    val statements = SqlToJavaConverter.splitStatements(text)
    if (statements.size > 1) {
        convertBatch(statements)
        return
    }
    // 现有单条路径不变
    ...
}

private fun convertBatch(statements: List<String>) {
    // 1. 批量解析（EDT 纯函数）
    val parseResults = SqlToJavaConverter.parseBatch(statements)
    // 2. 后台 ReadAction 实体查找
    ApplicationManager.getApplication().executeOnPooledThread {
        val (mainCandidates, subCandidates) = ReadAction.compute<...> {
            SqlToJavaConverter.findCandidatesBatch(project, parseResults)
        }
        // 3. EDT 生成 + 拼接
        ApplicationManager.getApplication().invokeLater {
            val code = SqlToJavaConverter.generateBatchCode(
                parseResults, mainCandidates, subCandidates,
                reverseFormat(), buildInvocation(),
            )
            setResultText(code)
            val successCount = parseResults.count { it.result != null }
            status("批量转换完成：$successCount/${statements.size} 条成功", error = successCount < statements.size)
        }
    }
}
```

### 4.6 编辑器 Action 适配

`ConvertSqlToJavaAction` 同样走 `splitStatements` + `parseBatch` 路径，多语句时输出代码块到弹窗/剪贴板。

## 5. 边界与已知限制

- 批量模式下**不弹实体选择弹窗**（交互复杂度过高），统一走自动推断 + 字符串列名回落；
- 批量模式下**不缓存**（`cacheResult` / `cacheText` 仅单条路径使用）；
- 语句数上限：默认不设限，但超过 20 条时状态行提示「语句较多，实体查找可能耗时较长」；
- 混合语句类型（SELECT + UPDATE + INSERT）允许，各自独立生成；
- 分号拆分不识别 `DELIMITER`（MySQL 存储过程语法），超出 P1 范围，报错即可。

### 6.1 纯逻辑单测（`SqlToJavaConverterTest` 扩展）

| 用例 | 输入 | 预期 |
|------|------|------|
| 双语句拆分 | `SELECT * FROM user; SELECT * FROM order` | 2 条结果 |
| 字符串内分号 | `SELECT 'a;b' FROM t` | 1 条（不拆分） |
| 行注释内分号 | `SELECT 1; -- a; comment\nSELECT 2` | 2 条 |
| 块注释内分号 | `SELECT 1; /* a; */ SELECT 2` | 2 条 |
| 空语句跳过 | `SELECT 1;; SELECT 2` | 2 条 |
| 末段无分号 | `SELECT 1` | 1 条 |
| 单条不拆分 | `SELECT * FROM user WHERE id = 1` | 1 条 |
| 批量解析错误隔离 | `SELECT * FROM user; INVALID SQL` | 第 1 条成功，第 2 条 error 非 null |
| 批量代码生成 | 2 条有效 SELECT | 输出含 2 段代码，换行分隔 |
| 批量错误占位 | 1 条有效 + 1 条无效 | 输出含 1 段代码 + 1 行错误注释 |
