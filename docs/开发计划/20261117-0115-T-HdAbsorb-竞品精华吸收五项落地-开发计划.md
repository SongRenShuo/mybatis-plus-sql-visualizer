## §一 五项落地内容（对应私有仓 HD-01~HD-05）

### 1. D215（HD-01）耗时双档语义 + 停驻补偿

- 耗时字段补 `kind`（精确 EXECUTION / 近似 APPROXIMATE）：agent JDBC 精确计时与控制台回落近似计时天然两档；列表与导出标注。
- 近似档停驻补偿：检测宿主调试挂起时间段（debugger suspend/resume）并从墙钟扣减；检测不到只标注近似、不猜。
- 会话/IDE 关闭补发未闭合耗时（agent 出口已有 catch-all，补「链未闭合即关机」flush）。

### 2. D216（HD-02）N+1 嫌疑检测（两刀）

- 第一刀：同模板 ⨉N 计数升级为嫌疑判定——列表行「疑似 N+1」徽标 + 面板可行动提示，阈值可配（registry 可回退）。
- 第二刀：事务维度——捕获链补事务标识（推断不到按线程+时间窗退化），嫌疑升级为「同事务同模板」；跨通道去重不受破坏。

### 3. D217（HD-03）调用栈代理反解

- 业务帧判定后对 `MapperProxy`/Spring Data 代理帧反解「代理自 接口#方法」，与 T-LogMethodName 展示位合并，不加第二行。

### 4. D218（HD-04）数据源指纹五元组

- 预览数据源绑定 last-used 之外加指纹兜底（jdbcUrl+driver+username+catalog+schema），改名不失效；活动连接点亮登记为执行面板增强候选（本册只做指纹兜底）。

### 5. D219（HD-05）MCP 输出分档限流

- `sqlv_render_logs`/`sqlv_history_search` 加「摘要/明细」两档（默认摘要，明细需显式参数）；MCP 11 只契约面不破坏（新参数可选，不改默认行为）。
