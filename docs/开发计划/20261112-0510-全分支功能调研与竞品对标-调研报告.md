## 一、项目自身盘点（2026-11-12 现状）

### 1.1 产品定位与七环闭环

产品名 **SQL Visualizer**（插件 id `cn.song.mybatisplus.visualizer.sql-visualizer`，Marketplace 33633），slogan「服务未启，SQL 先知」（`README.md`）。定位是 **IDEA 内多 ORM 的 SQL 调试七环闭环**：

1. **编码期静态预览**：Wrapper 全族（MyBatis-Plus / MPJ 联表）、Mapper XML 动态标签（`if`/`choose`/`where`/`set`/`foreach`/`bind`/跨文件 `include`）、注解 SQL（`@Select` 等 + Provider）、JPA/Hibernate（派生方法/JPQL/Criteria/Specification/QBE/HQL/hbm）、iBatis 2.x（`<sqlMap>` 六类语句）、其他 ORM（JdbcTemplate、Querydsl、Easy-Query、xbatis、MyBatis Dynamic SQL、自研 DAO 字符串 SQL）。
2. **编辑期能力**：XML/注解 SQL 注入着色、`#{}`/`${}` 区分、表列与参数补全、resultMap 属性补全、引用导航、动态标签折叠、iBatis 双向跳转（Ctrl+B / Ctrl+Click 双向）。
3. **运行期捕获**：Java agent 增强捕获（真实参数/耗时/调用栈/影响行数）+ 控制台日志回落（MyBatis/Hibernate/JdbcTemplate/iBatis/ShardingSphere Logic SQL，按线程分桶）。
4. **验证执行**：预览内嵌 IDEA 原生 Database 控制台执行、EXPLAIN（14 方言计划入口）、性能建议、JOIN 关系图（PNG/SVG 导出）、写入风险与回滚预案、SQL 快捷模板。
5. **反向生成**：SQL → Java（QueryWrapper/LambdaQueryWrapper/Wrappers/MPJ，`Alt+Shift+J`），实体/表 → CRUD SQL。
6. **历史与导出**：全量落盘历史、正则检索、钉住、双版本 diff、SQL/CSV/TSV/文本导出、Markdown/HTML 分享、可移植 SQL 导出。
7. **MCP/AI**：11 个 MCP 工具（`sqlv_render_sql`/`render_logs`/`schema_context`/`explain`/`check_sql`/`perf_advice`/`mapper_check`/`crud_sql`/`reverse_sql`/`rollback_plan`/`history_search`），总开关 + 逐工具控制。

### 2.1 盘点结论

1. **功能供给的重心不在「没有的功能」，在「已做未发行」**：dev 的 F 队列 15 项 + 三支在轨车道（方言 25 家、安全加固、隐 bug/perf 22+ 券）加起来约 **30+ 件用户可感增量**全部停在发行链之外；master 本身功能面已高度完整。
2. **三支陈旧残留可清理**：`feature/p05-dialect-verification`、`feature/rename-sql-visualizer`、`merge/sql-visualizer-integration` 基于老 master（落后 4300+ 笔），其内容已分别被 master 的内嵌控制台实现、插件更名事实、现行合流流程取代——属安全清理候选（删支须用户点名，AGENTS.md 对外动作纪律）。
3. **kotlin-to-java 是唯一在远端持续维护的非发行线**：820 笔领先、落后 3899 笔的「双向大漂移」意味着每轮同步成本递增；其存在价值（Java 生态兼容/许可证叙事）值得在路线图里做一次明确裁决（见开发计划 §五）。
4. **分支健康度好于 r37 时的担心**：t-security-audit-fixes / t-domestic-db-dialects / t-hiddenbug-perf-scan 三支都已各自完成收口文档与验收读数，均为「待合」而非「未完」状态。

### 4.2 逐家要点（含 web 公开资料补充）

1. **MyBatisX（baomidou 官方，+6,349/天）**：导航跳转、XML 补全、方法名→SQL 生成、从表生成代码（FreeMarker 模板）。优势＝官方背书+免费+装机基盘；短板＝无运行期捕获、无静态预览、无执行/EXPLAIN、notes 多版逐字相同（改动不可见，r37 §3.1）。与本插件是**互补大于竞争**：它管「写」，我们管「看与调」。
2. **MyBatisCodeHelperPro（145 万下载，收费）**：补全/inspection/代码生成/导航周更。优势＝MyBatis 开发效率工具链最全的收费插件；短板＝无运行期、iBatis 零能力（r37 §5.2：让位门已与其解耦）、补全回归报障响应慢（27 轮册 §5.2-6）。
3. **MyBatis Log 系（obroom/Free/Jtools/Ultra）**：日志还原赛道真实增长引擎（Free +203/天）。公开资料中的共性骂点：参数含单引号/换行时还原 SQL 断串、占位符错位、依赖应用开 SQL 日志、付费版退费无门。我方「p6spy 要改你的应用，我们只需要你的 IDEA」+ 类型感知字面量（dev F-01）正面覆盖。
4. **JPA Buddy（689 万下载，被 JetBrains 收编）**：JPA/实体开发辅助，加速持续第五窗（+2,677/天，基盘抬升）。无运行期捕获与还原；与本插件在 jpa sql 关键词上正面，但能力面不重叠。
5. **Hibernate Debugger（JetBrains 第一方，曝光位爆发 +203/天）**：官方推荐位驱动的量级跃升（单版 1,162 下载）。**中期最大外部变量**：官方生态在 JPA/ORM 调试面三连升级（JPA Buddy 收编→加速→曝光位）。它是断点态调试，不是「不启动应用先看 SQL」，能力错位但抢的是同一批用户的注意力。
6. **DBX（Rust 系通用数据库工具）**：154 笔重回扩张但火力在外壳（编辑器/导出/网格）；内核四读数三平（MCP 50 冻结、EXPLAIN 11 方言 19 窗零增量）；**唯一结构信号＝语义诊断破零**（`60da8419e` 报未知表别名）——与 dev F-02 参数可解析性 Inspection 正面对位，窗口在收窄（r37 §7 #320）。
7. **Database Tools/DataGrip 官方**：图形化 EXPLAIN、火焰图、数据库图、结果图表齐备（2026 文档实证）。启示：**「画计划图」官方已经做了，我方 EXPLAIN 环的差异化必须落在「ORM 语境的解读」**——把计划结论翻译成「哪条 Wrapper/哪段 XML 造成了这个计划、缺哪个索引、和你的实体映射什么关系」，这是通用工具做不了的（R45 体检的立项依据）。
8. **TableBridge（34687）/MybatisToolPlus（35174）/zMyBatis（30447）**：量级无关或活跃度与产品演进脱钩（r37 §3~4），维持盯防不立项对位。

### 4.3 差异化定位与差距结论

1. **七环闭环全市场独占**：静态预览+运行期捕获+执行验证+反向生成+MCP 深度接入，无一家齐备；竞品威胁面 37 轮保持为零。
2. **还原正确性是工程壁垒不是功能点**：899 个测试文件、iBatis 官方引擎逐字节黄金对照、真机方言矩阵、S2 反向验证纪律——竞品评论区最密集的还原类骂点（断串/错位/引号）在我方是守卫测试资产。
3. **信创/国产库是最硬的差异化叙事**：25 方言（含 9/10 腿真机验证）+ 增强捕获驱动面逐 jar javap 取证，DBX 与 Database Tools 都无此深度；「信创体检 BannedApi 六件套」（dev）是唯一把合规检查做进 IDE 的。
4. **差距 1——发现与口碑**：双零（0 票 0 评论）80+ 天、29.5/天 vs 大盘 3,667/天、sql preview 位次 20→28 回撤（r37 §9 风险 2/3）。产品供给强度不是瓶颈，曝光是。
5. **差距 2——EXPLAIN 解读层空白由官方补位的窗口在关小**：DataGrip 图形化计划已成熟、Hibernate Debugger 拿曝光位；我方 R45 若再不落地，「计划可执行化解读」的先发叙事让给官方只是时间问题。
6. **差距 3——诊断环竞品破零**：DBX 语义诊断首笔 + MyBatisX 差评存量，dev 的 Inspection 环（5+3 规则）必须随合流尽快转正，否则「告诉我 SQL 哪里写错了」被通用工具先占心智。
