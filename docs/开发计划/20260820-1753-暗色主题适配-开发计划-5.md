# 暗色主题适配（P1）开发计划

> 状态：✅ 已落地（T-DarkTheme `LafManagerListener` + `ThemedSplitPane` + dark icons，总纲 §7 记载；2026-11-13 代码核对回填）
> 需求来源：用户反馈「暗色主题下预览弹窗的部分文字对比度不足，分隔条发白，整体观感与 IDE 暗色主题不协调」。

## 1. 目标与范围

检查并修复 SQL 预览弹窗（`SqlPreviewDialog` / `SqlPreviewPanel`）在暗色主题下的显示效果，确保：
- 所有文字颜色使用 IDE 命名色（`JBColor.namedColor` / `UIUtil` 动态色），不硬编码固定色值；
- 分隔条（`ThemedSplitPane`）在暗色主题下不出现白色竖条纹；
- 错误警示、状态行、按钮等组件在亮/暗主题下均与 IDE 融为一体；
- 主题切换时（用户实时切换 IDE 主题）弹窗动态响应。

**已确认决策**：
- 主题化策略：**命名色优先**（`JBColor.namedColor` 自带亮/暗双值），`UIUtil.getPanelBackground()` / `getLabelForeground()` 等动态 API 兜底；
- 实时切换：注册 `ThemeListener`（`com.intellij.ide.ui.LafManagerListener`）监听主题变化，触发 `repaint()`；
- 不引入自定义 LAF：完全依赖平台主题体系，不注册自定义 `Skin`。

### 2.3 关键发现

经代码审查，当前暗色主题适配**整体良好**，仅以下两处需修复：

1. **`updateMeta` 警示色**（第 1115 行）：`JBColor.RED` 硬编码 → 应改为 `JBColor.namedColor("ErrorForeground", JBColor.RED)`（与 `status()` 方法统一）；
2. **`ClassPickerField.paintComponent` 兜底边框色**（第 430 行）：硬编码 `JBColor(0xC8C8C8, 0x5C5C5C)` → 应移除硬编码，仅保留 `JBColor.namedColor("Component.borderColor", ...)` 并以 `UIUtil.getTextFieldBackground()` 的暗色变体兜底。

### 2.4 ThemeListener 需求评估

当前弹窗为**模态对话框**（`DialogWrapper`），用户切换主题时弹窗通常已关闭。但以下场景需要实时响应：
- 工具窗口模式（`SqlPreviewPanel` 直接嵌入工具窗口，非弹窗）——用户可能在预览面板打开时切换主题；
- 长时间打开的预览弹窗（用户切主题后弹窗仍在）。

**结论**：工具窗口模式需注册 `ThemeListener`；弹窗模式可选（低优先级）。

## 3. 详细实施方案

### 3.1 修复 `updateMeta` 警示色

```kotlin
// 修改前（第 1115 行）
metaLabel.foreground = if (currentWarning != null) JBColor.RED else JBUI.CurrentTheme.Label.foreground()

// 修改后
metaLabel.foreground = if (currentWarning != null) {
    JBColor.namedColor("ErrorForeground", JBColor.RED)
} else {
    JBUI.CurrentTheme.Label.foreground()
}
```

### 3.2 修复 `ClassPickerField.paintComponent` 兜底边框色

```kotlin
// 修改前（第 430 行）
g2.color = JBColor.namedColor("Component.borderColor", JBColor(0xC8C8C8, 0x5C5C5C))

// 修改后
g2.color = JBColor.namedColor("Component.borderColor", UIUtil.getBorderColor())
```

其中 `UIUtil.getBorderColor()` 为平台动态色（亮/暗自适应），作为命名色缺失时的兜底。

### 3.3 ThemeListener 注册（工具窗口模式）

在 `SqlPreviewPanel` 构造块内注册主题监听：

```kotlin
init {
    // ... 现有初始化 ...

    // T-XX：主题切换时重绘（工具窗口模式下实时响应）
    ApplicationManager.getApplication().messageBus.connect(this)
        .subscribe(LafManagerListener.TOPIC, object : LafManagerListener {
            fun lookAndFeelChanged(source: LafManager) {
                // 命名色已自动更新，仅需触发重绘
                this@SqlPreviewPanel.revalidate()
                this@SqlPreviewPanel.repaint()
                // 类选择字段同步刷新
                callerField.refresh()
                voField.refresh()
            }
        })
}
```

**依赖**：`LafManagerListener` 在 `com.intellij.ide.ui` 包（243 平台可用）。

**Disposable 管理**：`messageBus.connect(this)` 的 `this` 需为 `Disposable`。`SqlPreviewPanel` 已实现 `JBPanel`，但需显式实现 `Disposable` 接口（当前未实现）。

**修改方案**：`SqlPreviewPanel` 实现 `Disposable`（已有 `dispose` 逻辑可迁移），或复用 `SqlToJavaPanel` 的 `Disposable` 生命周期。
