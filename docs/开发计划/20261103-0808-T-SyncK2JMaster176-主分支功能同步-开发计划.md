- **共享工作树提交铁律**：pathspec 限定；开工/收口各查一次 `git log` 分支是否前进。

- **Kotlin→Java 互操作**：具名实参→位置实参；`object`→静态形态；record 访问器无 get 前缀；函数类型字段落 Function0/1/…；默认参数→显式重载（守卫锚点迁全参签名）；箭头 switch 表达式+yield；受检异常 override 用既有 sneakyThrow；`@Service` Light Service 直接注解。
- **Light Service 注册**：P1 的 `@Service(Service.Level.APP)` 无需 plugin.xml（上轮同型实证），**勿当缺陷补注册**。
- **gradle 输出中文乱码**：`| iconv -f GBK -t UTF-8`；并发 gradle 加 `-Pkotlin.compiler.execution.strategy=in-process`。
- **测试红先看报告 XML tests 计数**（缓存锁/争用会让 BUILD FAILED 而测试没跑）。
- **命令行中文必乱码**：提交信息一律 UTF-8 文件 `git commit -F`。
