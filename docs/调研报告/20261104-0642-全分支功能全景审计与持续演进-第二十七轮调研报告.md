## 四、UX 痛点与六条新盲区（本轮新发现，此前 26 轮均未提）

1. **功能发现率是最大 UX 短板**：能力面 10 个 `<li>` 块 vs 触达入口仅 gutter/右键/快捷键 + 一条一次性 balloon。
2. **插件卸载/禁用后 agent 残留**：AgentManager.kt:1623「禁用不卸载」设计内行为——插件卸载后用户应用 JVM 内 agent 类/落盘 jar 不清理，插件走了痕迹还在。
3. **SQL 历史应用级多项目混流**：SqlHistoryManager application-level（SqlHistoryManager.kt:26）且历史无项目归属字段，双项目并发混流（微服务团队常态）。
4. **交互面无超大 SQL 护栏**：MCP 通道 200k 上限、留痕导出 10KB 截断，但预览面板交互链对 1MB 级拼接产物无截断/懒渲染，极端形态可能假死（需实测定性）。
5. **项目设置文件 VCS 协作面**：`.idea/mp-sql-visualizer-project.xml` 进版本库，团队方言覆盖/参数预设互相覆盖产生 diff 噪声，缺「哪些字段适合进 VCS」分层。
6. **中文注释 + GBK 编码工程形态未验证**（非 Gradle 项目已正面销账＝无盲区）。

改进建议按投入/收益排序的完整表见[优劣势深查底稿](20261104-优劣势与用户体验深查-草稿.md) §四（首位＝update.json 收口 + 去 `-beta` 后缀）。
