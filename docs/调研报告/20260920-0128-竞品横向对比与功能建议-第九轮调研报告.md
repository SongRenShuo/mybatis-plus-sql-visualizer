### 4.3 深挖：从「求值孤岛」到「可执行纵切片」（本轮最大信息量）

上轮它建的是「准备引擎」（静态切片求值）；本轮七个 PR 把**契约→引擎绑定准备→物化→目标解析**四段闭合，Leap 从契约建模阶段进入可执行纵切片阶段：

- **物化层是「证据岛矩阵」而非通用 literalizer**（`Materialization.kt`，8ce0c8d+ce737af）：两个物化器，`ZeroBindingExecutionMaterializer`（:134，只接受零绑定且零 `${}`）与 `MaintainedExecutionMaterializer`（:170）。后者的 CAST 依据写在注释里：MyBatis 3.5.19 `LongTypeHandler` 调 JDBC `setLong`、pgjdbc 把 setLong 绑成 INT8，所以显式产物用 `CAST(<decimal> AS BIGINT)`（:163-165/:276）——**绑定语义从 TypeHandler→JDBC→驱动链逐环推导，不是格式化拍脑袋**。准入矩阵极窄：引擎必须 `org.mybatis:mybatis` 3.5.19 + XMLLanguageDriver（:199-208）；绑定必须 `java.lang.Long` + `LongTypeHandler` + BIGINT/null jdbcType + IN mode + 无 numericScale（:231-277），每条不满足都有独立失败码（:314-330 共 8 个），值超 Long 范围单独失败码（:269-274）。
- **可证拓扑替换**（:279-299）：替换 `?` 前置证明——SQL 含单引号/双引号/`$`/`--`/`/*` 任一即整体拒绝（:280-281），再要求 `?` 数量恰等于绑定数（:282）。注释直说 "intentionally rejects quoted/comment/dollar syntax instead of attempting a partial SQL lexer"（:167-168）——诚实拒绝而不是写半吊子 lexer。PostgreSQL jsonb 的 `?`/`?|`/`?&` 操作符不用特判：天然导致计数不匹配而 fail-closed（有专门用例）。
- **物化产物版本化指纹**（:331/:366-426）：`MaterializedExecution` 携带 SHA-256 指纹，`zmybatis-materialized-execution-v1` 做域分隔前缀、字段 4 字节大端长度前缀防边界歧义；source revisions 排序后哈希（插入序不影响）；`declaredMutation`（statementKind != SELECT）与 `${}` 旗标进指纹——mutation 从 README 承认的「未单列」变成产物内机器可读证据。
- **目标身份与展示名分离**（`ExecutionTarget.kt`，987310e）：descriptor 的 equals/hashCode 只看 `targetId`（数据源稳定 UUID + 显式 schema），displayName 注释明写 "presentation metadata only"（:25-42）；**方言身份刻意不进持久化身份**（:53-65）——防「持久化时是 PG、执行时换库」的陈旧方言，失败分类含 TARGET_STALE。
- **精确解析 0/1/N 三态**（`DatabaseToolsTargetResolver.kt`，e1cdd28+304e281）：数据源与 schema 各做 0→MISSING、1→取用、N→AMBIGUOUS，重复稳定 ID 绝不回退按名字匹配；DBMS 白名单只认 `Dbms.POSTGRES` 精确第一方身份，衍生库/自定义/UNKNOWN 全部 fail-closed（:104-107，注释明说等每家族有自己的保真证据）；`ProcessCanceledException` 重抛、普通异常转 null（取消语义有专门用例）；失败诊断不含资源名或 SQL。
- **引擎侧真实绑定捕获与对账**（`XmlMapperPreparationEngine.kt`，0efeeb2）：从「只准零输入」放开到「有界绑定输入岛」——真引擎 `getBoundSql` 产出 ParameterMapping 后逐条校验（mapping 类由隔离 loader 加载、property 禁嵌套 `.`、别名恰解析到一个、mode=IN、TypeHandler 在 `org.apache.ibatis.type.` 包内）。**核心一招：把引擎真实生成的 `?` 数量与 PSI 侧契约的 Placeholder 证据计数做全等对账**——两条独立推导链互证，漂移即红。
- **集合快捷别名带规则溯源**（`XmlMapperMethodParameterContractFactory.kt`，1f46f79）：逐字复刻 MyBatis 3.5.19 `ParamNameResolver.wrapToMapIfCollection`——仅「单参数且无 @Param」时 `T[]`→"array"、`List`→"collection"+"list"、`Collection`→"collection"；GeneratedAlias 携带 `ruleId = "mybatis-3.5.19-param-name-resolver-wrap-to-map-if-collection"`——**别名出处直接编码上游版本与方法名**。
