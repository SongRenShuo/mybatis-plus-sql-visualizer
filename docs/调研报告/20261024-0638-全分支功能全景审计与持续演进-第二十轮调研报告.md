## 四、劣势与风险（五组）

**产品/UX**
1.【继承】设置项持续膨胀：面板 checkbox 守卫计数到 44，`PluginSettingsPanel.kt` 47 处 checkbox；beta.3 的搜索只治「找得到」，没治「看不懂」。
2.【继承→部分收口】O-145 多模块方言归因已实现但真实 IDE＋真库未验收（`CHANGELOG.md:33` 自述）；出错时用户无从自助。
3.【新】**增强捕获「打开即授权」**：默认开启＋无确认弹窗（`PluginSettings.kt:603`），首次 Run 即向用户应用注入 agent。对企业内网/安全敏感用户是信任风险点，README 有说明（`README.md:109`）但产品内不可感知。
4.【新】onboarding 单薄：仅 `OnboardingAnchorTip` 一条 gutter 引导（`plugin.xml:370-371`）；工具窗空态（日志列表为什么是空的）、历史自动保存默认关等首用路径无解释。

**正确性**
5.【继承】执行超时护栏仍只覆盖 MCP 直连，IDE 原生控制台不覆盖（已诚实披露未解决）。
6.【继承】Kotlin Wrapper 识别器可用但不可靠还原，入口诚实隐藏（`README.md:98`）——Kotlin 用户整个入口不存在。
7.【新】MCP 符号链接/跨平台路径负例在 Windows 侧环境受限未验证（第十九轮续记 `:147`），macOS/Linux 无回归保障。
8.【继承】Oracle/SQL Server EXPLAIN、模板抽样硬编码 LIMIT 等方言级真机债仍登记（9/11 方言真机、2 项待验）。

**性能**
9.【继承】F100/F106~F110 六条登记不修（全局文档监听常驻、agent Gson 全量解析先于闸门等）；F75（SqlHookCallbacks getMethod 缓存缺位）自性能二十三轮挂账至今（`20261021-1613-...md:60,116`）。
10.【继承】巨型文件回潮：SqlLogPanel 2264 行／SqlPreviewPanelExecution 2166 行／SqlPreviewService 2072 行，T-M53-II「全部 <2000 行」目标失守（`20261021-1613-...md:144`），推高并行合流冲突率。
11.【继承】真机性能读数长期缺位（V38 memo 命中率、Memory leak 四类、注入激活形态均无 profiler 实测），量级词都是代码级推算。

**工程债**
12.【新】update/update.json 只能用户本人手改（`docs/变更记录.md:20`），自更新稳定通道单人 bus factor。
13.【继承】beta.1 单次发行跨 519 笔提交，批次过大回归归因困难——rp8 门禁提速落地后具备缩小批次的条件，应趁势改节奏。

**分发与增长**

## 五、用户体验走查

- **新用户**：Marketplace 安装→gutter 图标/Alt+ShiftQ 预览可用（Community 即可）→点「执行」才发现要 Ultimate＋Database Tools（UI-035 已给直达入口）。最易困惑：①第一次 Run 就被注入 agent、无任何可感知提示；②工具窗日志空列表无解释文案；③历史自动保存默认关，翻历史发现是空的。
- **老用户**：写 mapper 看预览、调参执行、看日志找慢 SQL 三条高频路径均已成熟（方言闸门阻断文案带就地修复链接）。剩余摩擦集中在 O-145 未验收的多模块方言归因出错场景。
- **最易流失点**：Community 用户走不到执行/EXPLAIN 主卖点；首次注入无感知；Kotlin 工程用户的入口整体缺失。

**前 5 个 UX 改进**（纯文案/通知级，投入很小）：①工具窗空态补「为什么列表是空的」三行引导；②首次增强捕获注入给一条非模态一次性通知，把「打开即授权」变成「可感知的授权」（不恢复确认弹窗，不违增强捕获默认开启定案）；③Community 环境把执行/EXPLAIN 入口降灰并写明原因；④设置页顶部「最常用 5 项」快速入口，对冲 44+ 开关膨胀；⑤历史自动保存首次打开历史页时一次性询问。

## 九、长期演进三条战略主线

1. **正确性与信任**——守住「解析对」这个第一性卖点。全市场第一共性骂点是适配慢/解析错（竞品 MP 挂审 199 天、MyBatisX 挂审）；我方 8122 用例门禁＋反向验证纪律是唯一可叙事的信任资产。路径：R45 EXPLAIN 体检（可解释、只读）→ R43/SI-04 渲染溯源 → 每版「正确性修复清单」进 CHANGELOG 叙事。决胜点：竞品在 EXPLAIN/还原/解析面集体沉默，先把「信得过的 SQL 视图」钉死，等竞品醒来时语料已拉开代差。
2. **AI 原生工作流**——把「SQL 上下文供体＋验证回环」做成品类。AI 上下文 v2/R37/R91/R94 已上车、MCP 11 工具在册、窗口正开。路径：MCP resources/prompts（NEW-3）→ AI 等价验证器（NEW-4）→ 脱敏交递内化为默认。红线：不做订阅 AI、不做云端分析。决胜点：开发者把 SQL 任务交给 agent 时，第一个被调用的插件；差异化在「可信」而非工具数。
3. **分发与增长**——货架化节奏＋评价资产＋品类词。剪刀差第 8 天、65 天 0 评、517 下载，能力与分发严重倒挂。路径：beta 转正上架→48h 复测→破零动作→养词→MCP Registry 内容页获客→双仓（Gitee＋GitHub 镜像已落地）承接流量。决胜点：双周小批双发＋243 无上限＋免费，对阵 263 单线跟版的双寡头与付费/停更长尾；增长驱动是自身货架化节奏而非模仿放量王。
