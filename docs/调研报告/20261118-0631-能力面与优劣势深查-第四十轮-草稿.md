## 2. 优势清单（相对同类插件）

1. **ORM 覆盖面全场最宽**：MyBatis/MyBatis-Plus/MPJ/iBatis 2.x/JPA-HQL 全族/JdbcTemplate/MBG/Querydsl/Easy-Query/xbatis/MDS/自研 DAO，同一预览窗收敛（§1.1 全表）。竞品面：MyBatisCodeHelperPro 不做 JPA-HQL 与 iBatis；Hibernate Debugger 只做 JPA 断点侧；zMyBatis（新威胁）主打 MyBatis 且 263-only。iBatis 2.x 是无人区独占（20 形态官方引擎黄金对照，`xml/ibatis/fidelity`）。
2. **捕获环结构性独占**：agent 直接采集真实执行（参数/耗时/影响行数/调用栈/报错），控制台日志为不改工程回落通道——七环闭环中「还原真实发生了什么」这一环没有任何竞品具备（20261112 全分支调研报告 §1.1）。
3. **国产/信创方言面**：15 方言已发行（含达梦/GoldenDB/磐维/金仓/瀚高/海量/GaussDB），方言车道分支另有 10 家（25 家口径，`t-domestic-db-dialects` 已收口待合），配真机验证矩阵与保留字词表逐方言取证——竞品无一做方言保真到「真机逐词验证」粒度。
4. **执行安全护栏深度**：方言闸、`${}` 确认、无界写判定（fail-closed 词法二级证明）、超时护栏、回滚 SQL + before-image 快照——竞品的「执行」普遍只是跳控制台。
5. **诚实施设计**：降级横幅七型原因分型、Kotlin Wrapper 不可靠推断时明示不猜、方言能力矩阵如实标注（GoldenDB EXPLAIN 行 false）、捕获静默路径全量可见化——这类「不造假」在 Marketplace 差评驱动的竞品环境里是信任资产。
6. **工程纪律资产**：LESSONS 80 条带 hash 证据的教训账本、944 测试文件、方言黄金对照、真机矩阵 CI 腿、性能九期连审——迭代速度（一天多版）与质量闸并存，r39 实测下载 1,085、`sql visualizer` 位次 1/60（r39 落地册 §现状基线）。
7. **平台兼容纵深**：243~263 四目标、2026.3 每次 API 移除（setMapping/allowLoadUnloadWithoutRestart/MCP 页面搬家）均在用户报障当天内以能力族探测修复（CHANGELOG 2026.11.8/11.3/11.12）。

## 5. 新功能推荐

约束沿用既有红线：与 IDEA 原生能力重叠的显示层不做（原生优先，参照 T-PreviewInlayNativeYield 先例）；任何优化不得收窄 ORM 覆盖面；无用户请求不扩方言。

| # | 推荐 | 目标用户场景 | 与现有能力关系 | 竞品 | 价值判据 |
|---|---|---|---|---|---|
