### 3.2 MyBatis Log 系用户痛点

- 2026-02-15 CSDN 排障文（抓取 SQL 日志失败：日志级别未 DEBUG、log-impl 未配、格式不匹配）——排障类长尾流量继续，说明「配置摩擦」仍是该赛道的第一痛点。

### 3.4 JPA Buddy 2026 新版与叙事（本轮舆情最大增量）

- **JetBrains 官方 help 文档（2026-08-13 更新）：自 IntelliJ IDEA 2026.2 起，JPA Buddy 插件不再提供自己的数据库连接管理，改用 IDE 内置 Database Tools 集成。**

- 无独立的 2026 新版公告（与 r40 判读一致）。
- 判读：其「数据库连接」一环被平台层吸收，独立价值面收窄到设计器/生成器；对照面——我方的 ORM 语义链（十族 ORM、15 方言、预览执行环）平台层不提供也不会提供。「平台广覆盖 + 语义独立」叙事可直接引用这条官方文档做对比弹药。
