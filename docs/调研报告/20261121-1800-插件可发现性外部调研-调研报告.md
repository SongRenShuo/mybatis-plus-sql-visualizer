## 1. 结论摘要

1. 品牌词「sql visualizer」在 Marketplace 站内搜索排第 1（61 条结果），品牌护城河没问题；问题在场景词——「mybatis sql」第 117/154、「mybatis」第 205/247、「mybatis log」第 75/82、「mybatis plus」第 54/63、「sql log」第 86/156，「sql formatter」整词完全不入结果（29 条里没有本插件）。目标用户的真实搜索词全部落在 50 名以后。
2. 排名机制官方口径：文本相关性（插件 ID、名称、描述、标签、厂商名五个字段，各字段权重不同）先打分，再乘下载量系数 log10(1+5×下载量) 与评分系数 sqrt(rating)。本插件 1204 下载、无评分展示，两个乘数都处在全场低位；名称「SQL Visualizer」对 mybatis/preview/log/formatter 系搜索词在名称字段零匹配，只能靠描述正文得分。
3. 最近更新时间不影响默认搜索排序（官方文档明说，只影响「New plugins」列表）。天天发版换不来排名；实测前排也确有一批 2021~2023 年未更新的老插件。
4. 无评分是结构性短板：评分公式为贝叶斯平均 `(sum+2*meanVote)/(count+2)`，且评分以 sqrt 系数直接进搜索排序。当前搜索 API 中 rating=None、插件页无星级展示。
5. 浏览器侧：Google 已收录文档站 10+ 页且品牌词+jetbrains 组合能命中 Marketplace 页与文档站；但中文场景词「mybatis sql 预览 插件」的第一名是竞品 Mybatis SQL Viewer（知乎问题页带头），全网未检索到任何一篇本插件的第三方文章（掘金/知乎/CSDN/公众号均无）。Bing/Baidu 真实结果因反爬墙未取得（详见局限）。
6. 文档站 SEO 技术面健全超预期：title/meta description/OG 全套/canonical/lang/两段 JSON-LD/sitemap.xml/robots.txt 全部就位，VitePress 常见的缺 sitemap 问题不存在。短板不在技术面，在外链与内容零生态。
7. 仓库面：GitHub topics 8 个、homepage 指文档站，但 star=0、fork=1（2026-10-22 才建仓）；Gitee star=4 但 homepage 字段没设。GitHub star 作为搜索/展示信号目前为零。
8. 官方唯一 Featured 通道是 Staff Picks：由 IDE 产品团队按 4/7/11 月发行周期人工挑选，作者可通过 YouTrack 工单（project MP）主动申报，无付费置顶；下载量被明示为「primary factor」。baomidou 官方生态（官网生态外链区、awesome-mybatis-plus 清单）均未收录本插件，且 awesome 清单里根本没有 IDE 插件节可挂。

## 4. 排名机制结论（每条带出处）

以下条目均出自 JetBrains Marketplace 官方文档，引用以 2026-11-21 读取为准。

1. 搜索索引覆盖五个字段：插件 ID、名称、描述、标签、厂商名。出处：https://plugins.jetbrains.com/docs/marketplace/plugins-ranking.html（原文 "the plugin ID, name, description, tags, and the plugin's vendor name"）。
2. 字段间权重不同：官方明确 "Matches in different fields are scored differently"，未公开具体权重。实测旁证见 §2.2：258 下载的名称连写插件压过 340 万下载的官方插件拿「sql preview」第一。出处同上。
3. 下载量以乘数进排序：score × log10(1 + 5 × downloads)。本插件 1204 下载对应约 3.8，MyBatisX 565 万对应约 7.5，乘数差距约 2 倍。出处同上。
4. 评分以乘数进排序：score × sqrt(rating)；评分为贝叶斯平均 `(sum(userRatings) + 2 * meanVote) / (count(userRatings) + 2)`，少数 5 星刷不出高分。出处：https://plugins.jetbrains.com/docs/marketplace/plugins-ranking.html 与 https://plugins.jetbrains.com/docs/marketplace/plugins-rating.html。
5. 最近更新时间不影响默认搜索排序，只用于「New plugins」列表排序；用户可手动按 downloads / update date / publish date / name / rating 重排。出处：plugins-ranking.html。实测旁证：2021~2023 年停更的 Mybatis SQL、iBATIS/MyBatis mini-plugin 仍占前排。
6. Staff Picks（人工精选）在搜索结果中获得额外加成系数；全文档未见任何付费置顶/赞助位机制。出处：plugins-ranking.html。
7. Staff Picks 由各 IDE 产品团队人工挑选，评估维度：Marketplace 政策无违规、质量与 UX、描述诚实、有用性与流行度（"downloads are the primary factor"）、好评、独特功能、活跃维护；作者可主动申报——提交 YouTrack 工单（project MP，类型 Staff Picks），按 IDE 发行周期（4/7/11 月）评估，可被拒后改进重报；外部收款（不走 Marketplace 计费的付费插件）入选几率更低。出处：https://plugins.jetbrains.com/docs/marketplace/staff-picks.html（2024-02-05 版）；JetBrains 平台博客 2024-04 起的 Plugin Spotlight 系列即来源于此，https://blog.jetbrains.com/platform/2024/04/plugin-spotlight-on-jetbrains-marketplace。
8. 标签是搜索过滤器并展示在插件页名称上方："used as search filters"、"Choose your tags wisely, as they will affect searchability"；缺标签可邮件申请。出处：https://plugins.jetbrains.com/docs/marketplace/best-practices-for-listing.html。
9. 描述直接关系搜索："Draft the description with SEO keywords in mind, but please avoid keyword stuffing"（写描述时考虑 SEO 关键词，但禁止堆砌）；前 40 字符须为英文摘要；描述可在后台直接改。出处同上。
10. 名称建议 1~4 词、最长 20 字符，描述性优先于营销词，避免 Support/Tool/Integration 等通用词；名称在 plugin.xml 里，改动须随新版本上传生效。出处同上。
11. 截图/视频/图标是转化因素不是排名因素（"the first element that users will see"），影响点击而非索引。出处同上。
12. 本插件当前 preserveUIEdits=false：包内 plugin.xml 描述是权威数据源（后台改描述会被下次上传覆盖），与全局记忆 pitfall-marketplace-description-two-stores-preserveui.md 的判定口径一致（判据字段读数为 false）。出处：详情 API preserveUIEdits 字段。

## 7. 给开发计划的输入建议（合规优化方向，按影响排序）

以下均为官方文档允许或中性的操作；不包含刷下载量、刷好评、误导性关键词堆砌等任何灰手段（官方政策出处见 §4.9——描述可做 SEO 关键词设计但明令禁止堆砌）。

1. 名称字段的场景词缺口（影响最大）：展示名「SQL Visualizer」对 mybatis/preview/log 等高频搜索词在权重最高的名称字段零匹配。官方允许名称 1~4 词、最长 20 字符、描述性命名，且名称改动随版本上传生效。可评估改为带场景词的名称（如含 MyBatis 字样），但需权衡：品牌词「sql visualizer」现有第 1 名是既有资产，改名有稀释风险；建议先小步试验（名称里加一个词）再观察位次变化。
2. 标签扩面（零成本、即时生效）：当前 4 个标签，竞品普遍带 JEE、XML、Inspection、Viewer、Debugging、Code Quality 等 searchable 标签。标签是搜索过滤器（官方明说影响 searchability），在后台 General Information 可直接增改，无需发版。
3. 评价获取（公式级加成）：sqrt(rating) 直接进排序公式，当前无评分等于缺一项乘数。合规路径是在产品内自然引导满意的用户去 Marketplace 评分（不承诺利益、不批量诱导、不筛选性引导）；贝叶斯公式决定了少量真实好评也能建立基础分。
4. 描述补词（零成本）：英文描述按官方建议带 SEO 关键词是明示合规操作。针对实测缺口补事实性表述：「sql formatter」整词零命中——补一句 15 方言格式化能力的英文陈述；「slow query」「sql log」「execution plan」等已有功能对应的英文词自然出现在描述中。前提是如实描述已有功能，不堆砌不存在的能力。
5. Staff Picks 申报（一次性高杠杆）：下载量是明示的主因素，当前 1204 尚单薄；建议作为下载量过数千后的既定动作记入计划，按 4/7/11 月周期提交 YouTrack MP 工单，被拒可改进重报。
6. baomidou 生态收录：awesome-mybatis-plus 目前没有 IDE 插件节——提 PR 新设节并收录本插件是低成本动作；同时评估在文档站/README 以「非官方、社区项目」的准确表述关联 MyBatis-Plus 生态（不得暗示官方背书）。
