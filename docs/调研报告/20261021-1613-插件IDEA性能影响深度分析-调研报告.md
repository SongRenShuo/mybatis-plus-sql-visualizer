## 1. 总结论

**主体结论维持：对 IDEA 无体感影响；且本轮是本系列开始以来「正向修复密度」最高的一轮——上轮唯一「高」级发现 F79（XmlSynHiGate per-host 探针税）连同 F80/F84/F85/F57/F89/F90/F93 七条存量发现在本轮内全部修复销账。** F79 两刀（T-PerfSweep24 stamped memo + D68 谓词前置重排）经 A 路全文通读确认形态完备：memo 键=宿主弱键、戳=文件修改戳+注入器清单实例、fail-safe 异常不入缓存、V38 计数缝 opt-in 落位；重排后非 mapper XML 每高亮 pass 残余成本收敛为「2 次 instanceof + 1 次 volatile 读 + O(树深) 祖先走查」，零探针、零 EP 访问。

**新增面整体健康**：T-XmlGap 编辑器族 EP 簇（foldingBuilder/referenceContributor/externalAnnotator/liveTemplate 族/spellchecking/colorSettingsPage/补全贡献器）全部具备 O(1) 早退，其中 `lang.syntaxHighlighterFactory` 是「EP 名误写被平台静默忽略」的真根因修复——高亮器从「从未运行」变「真实运行」，mapper XML 打开期净增一份高亮成本，属功能正确性换来的合理代价。O-146 日志面板重写全面贯彻节流与缓存纪律（渲染条目级缓存、过滤纯函数+正则 memo、双阈值内容通知、搜索 200ms 防抖），红线干净。增强捕获默认开启未引入任何常驻空转线程（monitor 懒启 + stopMonitor 真取消 + dispose shutdownNow 三段闭合）。新发现 16 条（低 6/微 10）无中高级，全部为「有界但可再收窄」形态；上轮中低级发现 F83（淘汰回扫）维持未修，继续挂账。

## 4. 本轮增量审计（三链路）

### 4.1 编辑器热路径族（A 路）

- **T-XmlGap EP 簇逐件成本模型**（全部 O(1) 早退，红线干净）：`lang.foldingBuilder order="first"`（SqlMapperFoldingBuilder）非 mapper 文件 rootTag 名比对 O(1) 早退（:38），mapper 文件见 F95；`psi.referenceContributor`（MybatisXmlReferenceContributor）可见区收集 isMapperFile rootTag O(1)，全部 soft 引用、不触发校验器形态，resolve 仅跳转/用法/重命名按需付（成本见 F96/F97）；`externalAnnotator language="SQL"`（PreviewUnknownColumnAnnotator）collectInformation 首行文件名紧致判据+路径 endsWith 秒拒（:100-109），doAnnotate 经 SchemaValidationGate 三参入口只读已预热缓存（:89-91），无 DB I/O——用户自己的 .sql 零标注，KDoc 声称属实（注册面残余见 F107）；changeLocalityDetector 每键入 O(1)+≤24 深祖先走查且脏区收窄到语句标签；backspaceHandlerDelegate 仅删 `{` 进判定；spellchecking 按注入语言注册恒 EMPTY_TOKENIZER；colorSettingsPage 仅设置页实例化；liveTemplateContext 仅模板列出时被问。
- **`lang.syntaxHighlighterFactory` 名修复的净成本面**：此前裸 `<syntaxHighlighterFactory>` 被平台按未知 EP 静默忽略，高亮器从未实例化；修复后 mapper XML 文件打开期真实运行高亮（这是用户报「SQL 文本整段白」的修复）。属功能正确性换来的合理新增，登记入 §6 量级表。
- **gutter 族与 PSI 层**：T-JarEmbedded 方案 1+2 护栏复核通过——分片 LIBRARY_SWEEP_SLICE=500 每片独立短读动作片间真释放读锁、每 64 短名 checkCanceled、失效键=ProjectRootModificationTracker 结构版本+投递冷却窗 max(5s,上趟耗时)+全局在途上限 1、触顶 200_000 返回 -1 不落缓存、只认 @TableName、热路径 find() 未就绪投递后原样返回空不阻塞。WrapperAnchorDetector 削 89 行（Kotlin 文本扫描路径整体移除，fail-closed）。F-4 Kotlin 策略切换为 kotlin-optional.xml 仅一条 lineMarkerProvider（启动面零增量，功能面见 F103）。
- **补全链**：MybatisConfigCompletionContributor 无约束 extend 模式（F101 微）；OgnlVariableSources PSI 收集限于 enclosing tag 子树；XmlSqlCompletionContributor/ResultMapColumnCompletionContributor 守卫先行形态维持。
