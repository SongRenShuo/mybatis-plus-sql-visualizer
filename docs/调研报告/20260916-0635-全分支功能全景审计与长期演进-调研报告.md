## 1. 调研范围与方法

三个口径先行钉死，避免全景审计最常见的三种失真：

1. **「所有功能」按分支归属计，不按 Marketplace 计**。master、dev、t-uinative、feature/t-m56-01-agent-base 四条活线上的功能全部入表，每项标注「用户可见性」——已上架可见、待合流可见、仅分支内部可见。功能清单与竞对矩阵（第五轮 §5）互补：那张表回答「比什么」，本报告回答「有什么、在哪、用户用没用上」。
2. **计数以实测为准，历史声明作废**。第五轮报告立项时的 94/26 漂移在本次审计时点已变为 94/29（master 又走 3 个 docs 提交），origin/master..master 未推送从 5 提交变 8 提交。T-MergeDev2Master 计划本身约定实施时实测定案，此处只刷新快照不修订计划。
3. **两条记忆滞后在本轮审计中修正**：t-listparamcollect 已合入 master（merge 09cc6c6，随 v2026.9.18-beta.1 链发行），log-timestamp 与 log-search-copy-timestamp 两分支已完全合入 master（分支头 3e2d2be/89a04de 均为 master 祖先）。「分支上还有三个未合功能」的旧认知不成立，实际未合流的功能线是 dev、t-uinative、M56 三条。

方法上，逐分支读全量独有提交日志（dev 94、M56 19、t-uinative 8、k2j 101 中功能相关部分），master 侧以 plugin.xml 注册面与八域功能清单交叉核对；结论性判断引用既有报告时注明出处，不重复其数据抓取。

## 4. 优势盘点

1. **写前静态预览赛道唯一活跃玩家**。五轮竞品交叉验证一致：同赛道仅有的 MyBatisSQLPreviewer（208 下载）与 MyBatis SQL Analyzer（07-13 重建后停摆 64 天）均无威胁，MyBatisX 1.7.7 解剖证伪入场。这个生态位目前无人竞争。
2. **功能闭环宽度全场第一**。竞品单环生存（Log 系只做还原、MyBatisX 只做生成、CodeHelperPro 付费线做校验），本插件六环闭环之外第七环 MCP 十工具也是全场最宽 agent 面，且 mapper_check 把叙事从「校验置信度」升级到「可复核证据」（第五轮 §5）。
3. **兼容区间唯一全宽**。243–无上限覆盖 2024.3 至今全部 IDEA；对手集体收窄（MyBatisX 251+、Log Free 262+、Analyzer 卡死 251、Flex-Helper 困在 261–262），2024.3~2025.1 段没有对手新版可竞争——这是可以写进 marketplace 页的叙事素材。
4. **工程质量护城河**。四千余用例 + 三族守卫测试 + verifyGate 三目标兼容门禁 + 默认零开销性能审计文化，是同赛道竞品普遍不具备的密度（头部竞品测试规模普遍低一到两个数量级）。这是「长期打磨」叙事的工程底座，也是发版信心的来源。
5. **免费开源 + 全渠道在线**。对比 CodeHelperPro 双轨付费墙与 obroom 付费，价格是本插件在冷启动期唯一的天然杠杆；Gitee 抢先体验 + Marketplace 双通道已跑通。
6. **交付机器成熟**。周更多任务批次、每任务计划-实施-回填三处同步、并行会话登记、文档体系 57 份。单人项目里这套流程密度罕见，它解释了为什么功能资产能以周为单位累积。

## 5. 劣势与风险

1. **交付债第三犯，体量创纪录（首位）**。4421 绿的成果与十工具 MCP 面全部滞留 dev，agent 字节码增强滞留 M56，UI 原生化滞留 t-uinative——四条活线里三条的用户可见资产为零。第五轮已把合流立项为最高优先级（T-MergeDev2Master），本报告只补充一个观察：同一条沟连翻三轮说明问题不在认知在机制，「批次合完即回合」必须成为固定动作而不是每轮调研的催办事项。
2. **冷启动破局未成**。238 下载、0 票 0 评论、需求池四状态分类全为 0（2026-09-16 实抓）。+13/日 的正拐点只有一天样本。产品资产在涨、口碑资产为零，漏斗在「发现→信任」环节断裂：搜索位第一拿到了，页面上没有任何社会证明承接。
3. **功能画像断层**。marketplace 描述停在 v2026.9.11 能力画像（无 MCP、无回滚、无快捷键设置节），48 条 CHANGELOG 的版本已上架但页面没讲新故事。用户看到的插件比实际存在的插件小一圈——在 0 评论的冷启动期，页面就是全部信任来源。
4. **性能遗留五项**。第五轮性能复查维持「默认零开销」结论，但留 1 中低（JdbcTemplateLogParser 每行现场编译正则，EDT 捕捉路径）+ 4 低，其中重放守卫与 WrapperCache 两项连续三轮在册未清账。
5. **分支与工作树复杂度超载**。8 个功能分支 + 9 个工作树 + 3 个备份点同时在线；K2J 线更是只有成本没有进展——锚点同步已发生「Master171 史上最大轮」，而主源仍是 283 个 Kotlin 文件对 3 个 Java 文件，移植本体一个文件都没动。这条线当前是纯负债：每轮 master 前进都要背一次同步义务，换来的只是「将来可以移植」的期权。
6. **单人总线因子**。真机验证依赖单机环境（JDK8 目标、runIde 走查、达梦金仓容器「环境受限未验证」），任何一段时间的不可用都会同时冻结发版与验证。流程密度缓解但不消除这个结构性风险。

## 6. 用户体验专项诊断

把八域资产按新用户旅程走一遍，结论是：**功能深度过剩，引导深度不足，短板全部集中在「第一次接触」**。

- **装完之后没有人告诉用户能干什么**。13 个 gutter 标记器覆盖面极广，但触发完全被动——用户的项目里恰好有 Wrapper 链才会看到图标。没有首次检测到可预览代码时的主动提示，没有「Alt+Shift+Q 试一下」的一次性引导。快捷键是零认知成本入口，但认知本身需要成本。
- **空状态无引导**。工具窗四 tab 与预览面板的空态是纯空白，没有「打开一个含 Mapper 的项目」「从日志还原第一条 SQL」之类的下一步提示。空状态是免费的教学位，目前弃用。
- **文档与功能分离**。功能矩阵、FAQ、需求池全在官网，插件内只有 description 链接与帮助菜单入口；用户在预览失败、日志没抓到时缺乏就近的「为什么会这样」出口。
- **反馈闭环已建未用**。一键上报（errorHandler EP）与需求池入口都在，但需求池零真实帖子——不是通道问题，是前面没有足够的用户走到会反馈的那一步。

对照竞品抱怨清单（历轮扫描沉淀的同类插件高频差评：误报、卡顿、日志抓不到、兼容崩），本插件在「会不会坏」的维度上已经防御充分（金样矩阵、性能审计、243 全宽），但在「知不知道有好东西」的维度上没有做任何事。这两件事对下载转化的影响同样直接。

## 8. 长期演进路线

**近期（本月，十计划窗口）**：合流发行是唯一主线——T-MergeDev2Master 让 4421 绿与十工具见用户，随后 T-ErrorLocate 与发行随行件（N-17 首评 + N-20 视觉素材 + N-21 目录收录）。这一窗口的目标只有一个：把「用户可见资产」从 §3 表的一半以下补到八域全亮。

**中期（1~2 个月）**：四份新计划落地（N-22/N-23/O-22/O-23）；M56 在性能评估前置解除后启动合流（「增强捕获」对外叙事已定，默认关+失败回落的安全形态不破坏零开销承诺）；t-uinative 合流收口 UI 面。窗口末发一个「能力大版本」（暂名 v2026.10）：MCP 十工具 + 回滚 SQL + agent 增强捕获 + UI 原生化 + 快捷键设置节齐活，这是上架以来最大的一次能力跃迁，值得配一次描述重发与 Gitee 发行说明置顶。

**远期（季度+）**：三件事定生死。其一，agent 生态卡位固化——竞品 MCP 面均未成气候，窗口期内让 sqlv_* 工具面成为中文 MyBatis 生态里 agent 协作的默认选择，先手只有一次；其二，口碑飞轮——首评 → 评分 → 搜索位巩固 → 下载 → 更多反馈的正循环一旦转起来，「持续打磨」才有放大器，转不起来则始终靠人工获客；其三，验证纵深——方言矩阵从「环境受限未验证」走向真机化（Lab 配方已备好），工程质量护城河补上最后一块。

产品锚点全程不动摇：ORM SQL 调试闭环。判断新功能做不做的标尺沿用第五轮定案——扩张「调试闭环内的深度」（如 N-23）就做，跨出闭环做数据库产品形态就不做。

## 9. 落地优先级建议

如果只做三件事：**合流发行**（十计划的 T-MergeDev2Master，含推送留底与正式版上市场，用户可见资产一次性补齐）、**首评与素材**（N-17 首评引导 + N-20 视觉矩阵 + N-21 生态收录，三个市场动作打包在发行窗口执行，漏斗的「发现→信任」段才接得住）、**首用引导**（N-22，成本最低、新用户感知最直接的一件功能活）。

一句话总结本轮：盘点下来这个项目不缺功能、不缺质量、不缺流程，缺的是把这些东西送到用户面前的最后一公里——代码在分支上、故事在旧页面里、引导在空白处。长期活下去靠的从来不是继续堆宽度，而是让已经堆出来的宽度开始产生回报。
