## 环境就位清单（每次开新沙盒都要）

- 主题 Islands Dark + 缩放 120%（新沙盒这两项要重设；Islands Dark 会随 colors.scheme.xml 保留，Zoom 缺省回 100%）
- 编辑器字体确认 13pt 默认——「120% + 18pt」正是被用户判退的中间态，别搞混
- 窗口定位 (277,25,1370,984)：用 Win32 `MoveWindow`（DPI 感知脚本），**等 IDE 完全空闲后再移**——刚启动/改完 Zoom 的窗口会被 AWT 最小高度钳制（1042→1100）弹回
- 关项目目录树（修订九硬性项）：Project 工具窗的「—」隐藏按钮，别点到「折叠全部」
- 系统输入法切英文态：微软拼音「中」态下 typewrite 走组合输入，候选框会录进画面且提交时机不稳
- 录制中系统空闲时优先，用户/其他会话动鼠标会打偏点击
- **录「执行类」画面（EXPLAIN / 执行 SQL / 真实结果）前，核对 IDE 数据源的连接参数与应用配置逐字一致**（2026-10-12 加）：本轮应用 `application.yml` 的 MySQL URL 带 `sessionVariables=sql_mode=ANSI_QUOTES`，而 `.idea/dataSources.xml` 的同名数据源没有 → 同一句 `FROM "user"` 应用能跑、IDE 侧报 `1064`，为此白查数小时。两边拉平后**需重启 IDE 生效**（`.idea/` 通常已 gitignore，属本机状态不进仓）。

## 管线流程

```
标定（shot.py 抓帧定坐标 → 改 scene 脚本常量）
→ scene_tN.py 重放（mss 15fps 无损 mp4 + curlog 光标日志）
→ assemble.py 转制（空白压缩 + 光标回绘 + palette GIF + poster）
→ ffmpeg 抽帧逐点验收（动作节点/定格/poster 三处）
```

固定套路：

- scene 脚本内**自包含就位**：open_file/goto_line/图标检测全在 `Recorder.start()` 之前，take 中途只做演示动作
- gutter 图标用 `find_gutter_icons` 像素检测动态取，不写死坐标；当前构图条带在 region 相对 x≈95~130
- 13pt 下视口行数比 150% 时代多一倍，「取最低簇」会误选下方方法的图标——用窄 y_range 直取或取最接近视口中心者
- 弹窗控件坐标（取消按钮、复选框、输入框）必须弹窗打开态现标；取消按钮当前在 (1485,827)
- 转制后核对 `decoded 帧数 == Recorder.frames`，防残留帧混入（见下）

## 录制期纪律（适用所有轮次，不折中）

**插件功能问题一律停录回修，不在录制现场处理**（用户 2026-09-19 定调）。

录制过程中一旦发现插件功能问题——界面异常、数据错误、崩溃、行为与文档描述不符、工具返回不符合预期——**立即停止录制**，不在现场改代码、不打临时补丁、不绕过问题继续录。带着问题往下录只会产出与真实行为不符的演示，事后还得重录。

处置流程：① 停录并记录现场证据（截图 / `idea.log` 片段 / 复现步骤）；② 回插件项目按正常流程定位根因 → 修复 → 补或跑测试 → 提交；③ 修复验证通过后**重新开始录制该张**（不是续录，停录时的现场状态已不可信）；④ 若问题同时影响文档描述，同步订正对应文档页。

**沙盒侧的操作限制不算「插件功能问题」**：例如「合成点击对某控件不生效」属于本机自动化环境限制，处理方式是换等价交互面并在脚本里注明，不进停录流程——但要在实施状态里如实记录，避免下一次重复踩。

## 本轮踩坑定论（按代价排序）

1. **assemble 残留帧**：decode_frames 原来不清 frames 目录，上次解码帧数多于本次时旧尾帧混入新 GIF（T4 实证 132=119 新+13 旧，旧构图布局直接穿帮）。已修复为解码前清目录；转制后核对帧数是最后防线。
2. **T5 捕捉顺序**：先点「捕捉」再启动应用，监听建立失败、列表恒空。正解是应用先跑起来（Services 选中 MybatisPlusDemoApplication 后点面板 ▶），再点捕捉，脚本内 urllib 轮询 `/user/list` 触发查询。
3. **IME**：整个录制期保持英文态，打字前看一眼任务栏指示器。中文态的候选框入镜只有抽帧才能发现。
4. **T3 类打字场景全键盘化**：goto_line 居中有 ±2 行漂移，点击行坐标不可靠；goto 本身把光标落在目标行行首，之后 End/Enter/键入全键盘完成，鼠标只做演示滑动。
5. **前台抢夺**：`AttachThreadInput + SetForegroundWindow` 只给焦点不改 Z 序，视觉上窗口还在浏览器后面，坐标点击会穿透。要配 TOPMOST→NOTOPMOST 舞步；点击坐标在窗口可视区内（DWM 阴影边约 13px 不算数，超了就点到后面的窗口上）。
6. **坐标系两套**：shot.py/region 截图是 region 相对坐标，点击要 +277/+25；全屏截图 raster 是 1280×720，物理坐标 ×1.5。混用是最大的时间坑，写坐标前先想清楚手里是哪张图。裁剪局部图量的坐标还要再加一层偏移——三套数字（屏幕 / region / 裁剪内）逐级换算，点错一格就是 neighboring 控件。
7. **运行时改 Zoom 的钳制**：见环境就位清单，预写 other.xml 或等空闲后再定位。
8. **PixPin 全局热键撞车**：PixPin 常驻时 `Ctrl+Shift+A`（截图）、`Ctrl+Alt+S`（取色）都会被它劫持——Find Action 和 Settings 快捷键全部失效还会弹出它的覆盖层。开 Settings 走 IDE 工具栏齿轮菜单；Find Action 期间先确认 PixPin 不在撞键范围。
9. **IDE 编辑器缓冲污染**：误打进编辑器的文字用 Ctrl+Z 可能撤不掉（撤销栈状态异常），关标签重开也可能复用内存脏 Document。可靠清理是右键 > Local History > Show History，选污染前的时间点 Revert——它按内容快照回滚，不依赖撤销栈。
10. **置顶覆盖层抢前台**：ZCode 自动化面板等常驻应用若处于置顶态，TOPMOST→NOTOPMOST 舞步会把 IDE 抬回非置顶带、照样被盖住，坐标点击会打进覆盖层（曾误触自动化面板）。点前先 EnumWindows 核对目标窗口标题与位置，必要时让 IDE 持续保持 TOPMOST 干完活再撤。
11. **活动态像素判定量错元素**：tab 活动高亮改成判定规则前，先沿判定带扫一条像素列看真实 RGB——修订九用的「亮蓝 b>120」阈值实际量到的是聚焦下拉边框，活动标签药丸本身是暗蓝 (35,53,88)，规则应为 b>60 且 b−r>30。活动/非活动两态都量一遍再定阈值。
13. **合成点击对部分控件根本不生效**（本轮代价最大）：插件设置页的逐项复选框，同一坐标点阵扫描 9 点 **0/9 命中**（长悬停 1.5s、间隔 3s 均无改善），而同一窗口内的按钮、左树行、输入框全部可靠；平台页同语义的 Enabled 复选框 4/4 可靠。gutter 图标的合成点击同样不稳（4 连击全空），键盘入口 `Alt+Shift+Q` 反而每次成。**分镜设计前先逐控件试一遍**，不可靠就换等价面（本轮把「逐工具门控」从插件页移到平台页）。
14. **总开关一关，整组控件置灰**：插件设置页的总开关关掉后，十一个工具复选框整体转禁用态，症状与「坐标点错」完全一样（点不动），白耗数轮。凡「点不动」先查有没有把上游开关关掉。
15. **悬停浮层会拦截后续点击**：鼠标停在编辑器 gutter 上约 1 秒会弹出「Ask AI」小浮层（约 235×42），此后取消/复制等按钮连续点空。移向 gutter 后要**立刻点**，别停留。
16. **误操作会污染后续整轮**：一次误点（总开关）或一次误打（Ctrl+A/Delete/paste 落在编辑器里把文档覆盖）都会让后面全错。录制前先做状态归一 + 像素自检；发现编辑器内容被改，磁盘文件用 `git checkout --` 还原、编辑器缓冲用 Ctrl+Z 或 Local History Revert。
17. **录制段从 prep 已就位的界面开始**：把开窗、寻路、搜索、滚动全部移进 prep，录制段只留动作——M1 实测 40s → 13.3s。代价是 prep 要自己做状态归一（开关、勾选、滚动位置）与像素自检，失败就中止而不是录进坏画面。
18. **接缝 diff 的来源往往不是光标**：M1 首版 6.22 是光标没归位（补一次 `move` 回起点后 0.02）；S1 的 1.79 是**状态差**——条目选中高亮在、焦点却在列表 vs 编辑器。首尾要停成同一态，**连焦点在哪都要一致**。另：列表按时间升序、新条目在下方，解析还没落库完就开录会让首尾列表内容不同，录制前给足落库时间（本轮 7s）。
19. **字节码增强会话的两条断线规律**（2026-09-20 实测，影响所有需要「调用点」的场景）：① 把面板「捕捉」关掉会**连带断掉 agent 会话**，再打开不会自动重连（日志 `pushCaptureActive: active=true → disabled=false（sessions=0）`），此后捕获的条目**没有调用点**、依赖调用点的菜单项全灰；② 会话会在挂载后约 **45~80 秒自行掉线**（`AgentSession - Socket closed`），而应用进程并未退出（端口仍在、pid 不变）。→ 需要调用点的场景必须「**重启应用 → 立刻开捕捉 → 立刻触发查询**」，把条目抢在窗口内录进列表；条目一旦入库就带调用点，后续操作不受掉线影响。另：demo 应用若含 DevTools，改源码触发的自动重启会让新 JVM 不带 agent，会话同样掉线。

20. **AI Assistant 的「对话面板」不是点主工具栏 AI 按钮**（2026-09-20 实测，曾据此误判「ACP 面板不可达」）：点主工具栏 AI 按钮打开的是 AI Assistant 的**落地页/推广页**（本沙盒无 Ultimate 许可时整页是订阅 FAQ + Trial 标签）；**对话面板是右侧工具窗**（图标在右侧栏），打开后顶部是 `Chat History` / `New Chat`，正文是 agent 名（如 `Codex`）与 `Configured authentication: Managed by agent`，底部是提示框与 agent/模型两个下拉。**判据**：面板左上能看到 agent 名与认证行才算面板。
21. **需要「现场打开某个文件」的桥段一律移进 prep**：M1-c 首版把「打开 idea.log」放在录制段里，Find Action + 原生文件对话框 + 4.5s 载入共 13s，成片直接 30s 超规格；改到 prep 里开好并定位，录制段只切标签后压到 11.9s。**判据**：录制段里任何「等待外部资源加载」的动作都该前置。
22. **搜索定位要选唯一子串**：在 idea.log 里搜 `[MCP-AUDIT]` 会先命中上一轮的旧审计行（工具名还是改名前的 `mpsv_`），画面上工具名对不上；应搜 `tool=sqlv_check_sql` 这类唯一子串。

12. **runIde 构建疑似卡死**：daemon 低 CPU、产物目录长时间无变化、日志停在同一行即判定卡死，杀 gradle client+daemon 重跑（第二次全 UP-TO-DATE 很快）。构建输出直写日志文件（`> abs/path.log 2>&1`），`-q` 加管道会缓冲到结束才可见。另注：沙盒 IDE 进程是 java.exe 而非 idea64.exe，找窗口按标题不按进程名。

## 2026-10-12 大范围录制补充（A11 EXPLAIN / wrapper-preview hero / settings.png / A29 MCP 门控 / A13 试录）

23. **裸屏捕获不含光标，鼠标移动会被静段裁剪整段吃掉**（代价：一张片白录）。`Recorder` 只采像素，纯凝视型 take 转出的成片实测只有 **3.6s**（take 的 mp4 本身约 11s、是完整的），安排的凝视动作全没了；有真实 UI 变化的同类成片能到 7.5s。**take 里必须有真实 UI 变化**（浮窗弹出 / 面板展开 / 结果网格出现 / 临时文件执行）。判据：成片时长明显短于脚本动作时长，先怀疑这条。
24. **设置页内容无法滚动**：滚轮（`pyautogui.scroll`）、`PageDown`、**拖页面滚动条**全部无效，只有**左树**滚动条可拖。页面高于可视区时底部控件被切（MCP 页高约 750px vs 可视区约 715px，底部「全部启用/全部禁用」被切）。**处置＝拉大对话框**：拖标题栏上移 + 拖**右下角精确角点**（差几像素就落空、点到后面编辑器上并弹右键菜单），拉到 981px 即全部入镜。⚠️ 判「滚不动」前先确认目标不在极限位——本轮一度用「树滚不动」断定滚轮全坏，其实那次树本就在底部，且 `pyautogui` 正数＝向上滚、方向也搞反了。
25. **设置对话框是模态的**：开着时对其它窗口的点击**一律无效**——关 SQL 预览浮窗、点编辑器都必须先关对话框。本轮在此陷入过「反复点浮窗取消按钮毫无反应」的死循环，白烧数轮。
26. **`Esc` 是设置对话框的取消键**：拿它关搜索框的补全下拉会**连整个对话框一起关掉**。补全下拉用点别处或方向键收。
27. **设置对话框不是进程主窗口**：`Get-Process.MainWindowHandle` 看不到 → `EnumWindows` + `GetWindowThreadProcessId` 按 PID 过滤再 `GetWindowRect`（实测 (399,79)/1125×875，与同批静态截图逐像素吻合）。另：设置页搜索框过滤不稳（两词查询报 "Nothing to show"、单词查询只自动选中不筛选、补全下拉会吞输入）→ **要树展开到某页，手动展开 + 拖树滚动条比走搜索稳**。
28. **插件的列文档浮层会粘住**：鼠标压编辑器标识符弹出的「Data Source / Schema / Table / Column」浮层**鼠标离开也不退**（Esc 可关），末帧右侧被整块挡掉。触发点常是**开文件时坐标扫掠的余点**（弹窗关掉后余点落到代码上）。→ 收尾鼠标停预览左栏 / 原生控制台等空白区；**别停代码**（弹文档浮层）、**也别停结果网格**（弹列类型浮层，如 `partitions: MEDIUMTEXT`）。
29. **弹窗按钮行位置要按窗口底边推算**：内容高度可变的弹窗（SQL 预览面板这类），按钮行 y **目测写死必错**（实测偏低约 48px，连点三次全落空）。取弹窗 rect 后按钮行恒在**底边上方约 39px**（`bottom − 39`）；退一步可用**像素剖面**（逐行取按钮文字所在 x 带的灰度均值，最亮连续段即按钮行，实测文字行 47~60 / 背景 26）。
30. **面板展开态跨浮窗保留**：预览面板折叠区（如「预设」行）的展开状态会**跨预览保留**，take 前必须归一到确定态，否则那一下点击反而把已展开的收起（末帧仍是收起态）。状态判据用条带灰度标准差，**阈值按暗色主题定**——Islands Dark 下收起态本底噪声就有 13（实测收起 13.09 / 展开 34.95 → 阈值 22），照「空白≈0」取 8 会把归一化做反。
31. **开文件两条路径各有坑**：坐标扫掠（点 Go-to-File 结果行）可靠，但**Return 打不开结果行**（JBR 吞键）、行位在 region y 350~366 浮动故须扫掠 3 点，且**弹窗关掉后扫掠的余点会落到编辑器代码上**触发上一条那个粘住的浮层；键盘路径（`↓` 选中首条 + Return）能避开浮层却**会开错文件**（实测把 `settings-1.1.0.xsd` 当首条结果）。取舍：用扫掠，但把扫掠 y **标定到该文件的空白行**——写死的 350/358/366 只对旧目标有效。
32. **判「示例/演示坏了」之前先对两处 URL**（本轮最贵的判断失误）：同一段 SQL 的合法性取决于连接 `sql_mode`；我据「MP 与 MPJ 源码都原样拼接表名」推出「运行时必然报错」，**漏了连接选项这个变量**——取证只覆盖你查的层，结论别越界。
33. **「在不在沙盒里」只有一个可靠判据：日志落点**。按命令行判不成立——正确启动的沙盒命令行可能只是一个裸 `idea64.exe`（路径全在 vmoptions 文件里）；按窗口标题判也不成立——起错的日常 IDE 同样有主窗口、同样不弹许可（用的就是日常那份有效许可）。**唯一硬判据**：起完立刻核 `build/MPSV-<名>/…/log/idea.log` 的 mtime 是否在刷新，且日常 `%LOCALAPPDATA%\JetBrains\IntelliJIdea<ver>\log\idea.log` 不动；反了就是起错了。核 `ls` **必须带 `-t`**，不带时 `idea.log` 会被 `tail` 按字典序截掉（`i` < `t`），据此会得出完全相反的结论。
34. **启动沙盒统一用 `./gradlew runIde -PgifRecord=true --args=<demo 工程绝对路径>`**（用户 2026-10-13 定调）。它同时做两件事：**重建并安装插件**（改了插件代码必须走它才生效）+ **合并沙盒 `config/idea64.exe.vmoptions`**（用户在里面保留的第三方 agent/参数才带得进去，进程命令行可逐字核对）。**不要用**下面两条：
    - `idea64.exe "-Djb.vmOptionsFile=…\sandbox.vmoptions"`：启动器**不解析该命令行参数**，静默退回默认配置＝**起了一个日常 IDE**（症状与沙盒完全一样，肉眼分不出；2026-10-12 用户连纠两次，定为严重问题）。
    - `IDEA_VM_OPTIONS` + `record/sandbox_start.cmd`（**此前本节把它写成「正确姿势」，该口径已作废**）：它只读 `record/sandbox.vmoptions`，**沙盒 `config/idea64.exe.vmoptions` 根本不会被读取** → 用户放在那里的 agent/参数被静默漏掉，还绕过 gradle、插件改动不重装。仅作应急备选（如不想等构建），用完回到 gradle 命令。
    （附：写 `.cmd` 只写 ASCII——中文注释按 UTF-8 存、cmd 按 GBK 读，`rem` 行会裂出乱命令。）
35. **Go-to-File 开文件：键盘路径完全无效，坐标必须点行左半**。`↓` + Return 实测**一点作用都没有**（Down 连选中行都不动、Return 也不开文件，弹窗仍在、窗口标题不变），别再试键盘路径。点结果行则要注意：**首条结果行的右半被一个白色浮层 chip（`1 mpjdemo/UserServiceImpl.java`）盖住**，点在它边缘会**穿透到后面的编辑器**（症状＝弹窗还开着、编辑器却选中了一行、标题不变）——实测 x=777 失效、x=600（落在 chip 左侧的路径文字上）命中。判据用窗口标题（含文件名），命中即 break。
36. **预览弹窗底部按钮行要按几何标定取，且弹窗必须是新建态**。`bright_band_y` 全高扫描会命中**顶部标签行**（SQL / JOIN 图，又长又亮），最左亮簇就成了「压缩」而不是「执行 SQL」；而底部按钮行的**行**均值只有 40~43（面板底色 26，按钮是描边样式、文字稀疏），行向阈值法根本分不出来。正确做法：按 **`底边 − 39`** 取按钮行，再用 `bright_band_x` 取**列**向亮簇（实测三簇恰为 `执行 SQL` / `复制 SQL` / `取消`，最左簇＝执行 SQL）。⚠️ **前提是弹窗处于新建态**——停在结果态时按钮行会整体上移约 40px，`底边−39` 落到按钮下方空白处；所以 prep 里的「关旧窗 + 重开」不是可选项。另：无边框弹窗的**窗口矩形比可见底边低约 40px**，点「取消」按钮的坐标必错，关窗改走 `locate.close_preview()`（点弹窗体 → Esc，判据＝EnumWindows 里窗口消失）。
37. **IDE 启动气泡会落进录制区且很难点掉，开录前必须先清**。两个实测案例：① 「Full Line Code Completion offers an LLM for Java…」（LLM 模型下载提示）② 「New/updated database configurations found」（连库建议 + `Do not suggest again`）。它们固定在**右下角**、压在预览弹窗与原生控制台之上，末帧/poster 直接被污染。**关闭按钮只在悬停时才显示、且右缘常被 IDE 窗口边界裁掉**（本轮按截图目视连点十余次全落空）。**更稳的处置：重启沙盒**——① 重启后不再出现（② 可点它自带的 `Do not suggest again`）。
38. **开录前先确认「前台不是别的应用」——盲点坐标会打进别人的窗口**。本轮清气泡时盲点了十余次，事后查 z 序发现**微信（`Weixin`）在最顶层且是前台**（其提示框正压在编辑器上），第 5 层还开着 `7-Tool`。这些点击可能落到别人窗口上（本轮微信弹了「你已退出微信」提示框，无法确认是否由此引起）。**纪律**：机器被别的应用占前台 → **立刻停手**、说明情况、让用户腾出屏幕，不抢置顶、不换工具硬试；清气泡这类操作前先 `locate.windows()` 看一眼 z 序与前台 PID。

## 2026-10-21/22 T-DocsRefresh1023 轮补充

39. **gutter 图标位置随滚动状态漂移，「取最接近视口中心」会选错行**。同一文件连续 `goto_line` 后图标 y 每次都变（实测 `[(363,95),(517,95)]` → `[(363,95),(561,95)]`），且条带里混着**编辑器折叠箭头**（x≈117~129，不是插件图标）。判据：`find_gutter_icons` 的返回里 x 落在 95~105 才是插件图标；更大的是折叠箭头。**更稳的替代**是绕开 gutter：`goto_line(目标行)` → 点编辑器行内 → `Alt+Shift+Q`。但要注意光标必须落在**可预览表达式上**（落在方法声明行会弹「未在光标处找到可预览的 SQL 源」，需落到 Wrapper 链的某一行）。
40. **JBPopup 的菜单项必须「先悬停再点」**。预览面板的「更多」菜单、执行视图的数据源下拉都是 JBPopup：直接 `click` 有一半概率只把菜单关掉而不选中项（同一坐标前一秒成、后一秒败）。正解是 `moveTo` → 停 0.5s → `click`。这个坑让 N05 白录两轮。
41. **`Escape` 在预览里会连预览一起关掉**，不只是关菜单。清残留菜单要**点预览标题栏空白处**（如 `(600,161)`，即「方言/类型/表」那一行的右侧空区）。
42. **预览左栏的滚动条是唯一能滚的通道**。参数面板里 `fill` 字段（`create_time` / `update_time`）在列表下方，`pyautogui.scroll` 与 `PageDown` 全部无效，必须拖左栏滚动条（region 相对 x≈450）。同源现象见指南第 24 条（设置页）。
43. **设置树滚动全部失效，定位只能靠搜索框，且必须单词查询**。`Visualizer` 能定位到插件设置页；`SQL Log`（两词）返回 `Nothing to show`。补全下拉要用 `Escape` 收（但注意第 41 条——在预览里别按，在设置对话框里可以）。设置内容区顶部那个带放大镜的输入框是**补全输入**，不是设置过滤器。
44. **预览绑定哪个数据源由 `last.runner` 记忆决定，而这个记忆藏在项目 `workspace.xml`**。键名 `mpsql.visualizer.last.runner` / `.id`（`PropertiesComponent`，新版是 `keyToString` JSON 里的一行）。演示「执行 / EXPLAIN / 影响面」时若目标库 URL 与渲染方言不匹配（典型：`mp_demo` 无 `sql_mode=ANSI_QUOTES`，而 MPJ 渲染 `"user"`），会直接 `[1064]`。**改记忆比跟 JBPopup 下拉死磕可靠**——改完必须重启 IDE 才读入。
45. **数据源密码不持久化时，报错是 `Access denied ... (using password: NO)`，不是驱动缺失**。右键菜单第一项 `Download Driver Files` 会误导（驱动其实在）。正解是数据源连接弹窗的 `Change Credentials` 补密码，凭据落 `dataSources.local.xml` 后下次启动直连。
46. **反编译器弹窗会挡住 IDE 主窗口创建**。误点 gutter 可能打开某个 `.class`，弹出的 `JetBrains Decompiler` 许可对话框是**模态**的，IDE 主窗口（`SunAwtFrame`）迟迟不出现，`EnumWindows` 里只有一个 `SunAwtDialog`。判据：robot-server 已通（根节点 300+）但找不到 `SunAwtFrame` → 先关掉所有 `SunAwtDialog`。
47. **`dist/demo` 被 preview 服务器占着时构建会失败**，报 `ENOTEMPTY: directory not empty, rmdir .../.vitepress/dist/demo`。这不是内容问题——先停掉 `vitepress preview`（或删 `dist`）再 build。
