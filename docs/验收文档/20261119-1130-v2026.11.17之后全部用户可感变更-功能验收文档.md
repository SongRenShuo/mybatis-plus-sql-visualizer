## 一、独立 SQL 预览工作台（本次最大新增面）

> 全部操作都在**第 5 个页签「SQL 预览」**里。工具栏从左到右：`解析预览` / **`执行 SQL`（D233 新增）** / `格式化` / `清空` / `在弹框中打开`。

### A1 页签入口与开关

**路径**：右侧边栏 → SQL Visualizer 工具窗 → 「SQL 预览」页签；或 Tools 菜单 / `Alt+Shift+P`（剪贴板里有疑似 SQL 时自动预填）。
**步骤**：① 点页签；② 清空剪贴板后按 `Alt+Shift+P`；③ 复制一段 `SELECT ...` 到剪贴板后再按一次。
**期望**：① 页签出现，上下分栏（上输入 / 下预览），底部状态行有内容；② 打开空输入且无预填；③ 自动预填并可解析。
**回退**：Registry `sqlvis.preview.standaloneTab` = false → 重启后页签消失（控件在 Settings → Appearance & Behavior → Registry… 搜索 `sqlvis.preview`）。

### A2 粘贴纯 SQL：识别 + 填值 + 复制

**路径**：工作台输入区。
**步骤**：① 粘贴 `SELECT * FROM t_user WHERE user_name = #{name} AND email = ?`；② 点「解析预览」；③ 在下方参数表给 `name` 填值、给 `?` 位置填值；④ 点「复制 SQL」。
**期望**：① 状态行显示「识别为纯 SQL / 参数 N 个」；② 参数表列出两个参数；③ 产物 SQL 把值正确代入，`'` 转义正常（`O'Brien` → `'O''Brien'`）；④ 剪贴板内容与产物一致。
**回退**：无（核心能力）。

### A3 mapper XML 片段（含动态条件 / foreach / bind）

**步骤**：粘贴一段带 `<where>`/`<if>`/`<foreach>`/`<bind>` 的 `<select>`；点「解析预览」。
**期望**：状态行显示「识别为 mapper XML 语句块：<id>」；条件行可**勾选**、`foreach` 可填值重放、`bind` 变量能回填；勾/取消勾选即时改产物。

### A4 网页复制形态与 markdown 围栏

**步骤**：粘一段含 `&lt;`/`&gt;`/`&amp;` 转义的 XML 片段；再粘一段 ``` ```xml ``` 围栏包住的 SQL。
**期望**：两种都识别成功（转义解码、围栏剥离），不报「未识别」。

### A5 iBatis 2 语句（本次新增）

**步骤**：粘贴：

```xml
<select id="selectByCondition" parameterClass="User" resultMap="userResult">
  SELECT * FROM T_USER
  <dynamic prepend="WHERE">
    <isNotNull prepend="AND " property="id">ID = #id#</isNotNull>
  </dynamic>
</select>
```

**期望**：状态行「识别为 iBatis 2 语句：selectByCondition」；条件行可勾选；`#id#` 能填值；**不出现** `Unknown element <dynamic>`。

### A6 缺失 `<include>` 占位与补齐（本次新增）

**步骤**：粘贴一段 `<select>` 里引用了 `<include refid="baseColumns"/>`、但没有 `<sql id="baseColumns">` 的片段。
**期望**：① SQL 里该处是 `/* TODO: missing <sql id="baseColumns"> */` 注释，结构完整可读（不是残句）；② 工作台底部出现「缺少片段：baseColumns —— 点此补上内容」；③ 点它 → 弹补齐框 → 点「从文件选择…」选工程里某个 mapper XML → 自动抽出该 `<sql id>` 内容；④ 补齐后立即重渲染、提示行消失；⑤ 补齐框按钮是「补齐 / 取消」（不是 OK/Cancel）。

### A7 「在弹框中打开」（含空输入）

**步骤**：① 有 SQL 时点「在弹框中打开」；② 清空输入后再点一次；③ 粘一段完全无法识别的文本（如一段 YAML）再点。
**期望**：① 真的弹出预览弹窗（历史缺陷：点了只在页签内刷新）；② 空输入也弹窗，给空白编辑器；③ 未识别文本弹窗并**原文展示** + 信息级说明（ℹ 前缀，不是渲染失败）。

### A8 弹窗里贴内容自动识别（本次新增）

**步骤**：点「在弹框中打开」拿到空弹窗 → 直接往弹窗编辑器里粘一段 mapper 片段 → 等约 0.8~1 秒。
**期望**：自动识别出参数行与条件行；识别成功后交还手动编辑（你继续打字时不再被改写）。
**注意**：从正常语句预览打开的弹窗**不受影响**（那里的编辑是在调产物）。

### A9 弹窗从文件加载（本次新增）

**步骤**：弹窗里点「从文件加载…」→ 选工程内一个 mapper XML。
**期望**：直接载入识别，无需先复制粘贴。

### A10 工作台快捷键 `Alt+Shift+Q`（本次修复）

**步骤**：光标停在**工作台输入区**（不是编辑器文件）按 `Alt+Shift+Q`。
**期望**：真的重新解析预览（历史缺陷：按键被丢弃、零反馈）。预览区空态提示文案应为工作台自己的（不含「选中代码」字样）。

### A11 长警告能看全（本次修复）

**步骤**：构造一条超长错误/警告（例如粘贴一段超长且语法错误的 XML），让警告横幅出现。
**期望**：① 悬停横幅显示完整 tooltip；② **点击横幅正文**弹出「完整提示信息」对话框，可选中、可滚动、可一键复制。

### A12 执行 SQL（D233，未发行）

**路径**：工作台工具栏第二个按钮「执行 SQL」。
**步骤**：
1. 未解析任何内容时看按钮状态 → **期望禁用**；
2. 解析一段 `SELECT * FROM t_user WHERE id = 1` → 按钮变可用；
3. 点它 → 选数据源 → 执行 → **期望出结果表格**（在下方预览区内嵌的控制台里）；
4. 解析一段 `UPDATE t_user SET user_name = 'x' WHERE id = 1` → 点执行 → **期望弹 DML 二次确认**（取消后不执行）；
5. 解析一段含 `${}` raw 段的 SQL → 点执行 → **期望弹 `${}` 确认门**；
6. 点「清空」后按钮回到禁用。
**期望补充**：按钮禁用态下不应发生任何执行；若竞态下动作被触发（面板已释放），状态行给「请先解析预览 SQL 或片段，再执行」，不裸跑。
**回退**：无独立开关（按钮禁用即回退）。

### A13 粘贴即体检（D234，未发行）

**步骤**：① 解析 `SELECT * FROM t_user WHERE id = ?`；② 解析 `SELECT 1`；③ 解析一条没有 WHERE 的 `UPDATE`。
**期望**：① 预览面板的**性能建议行**出现 `⚠ SELECT *` 一类建议（与语句预览同一套规则文案，不重复报）；② `SELECT 1` **零建议**、不占行；③ 缺 WHERE 的 UPDATE 出对应建议。
**回退**：Registry `sqlvis.preview.standalonePerfCheck` = false → 不再体检（建议行不出现）。

## 二、SQL 日志（右侧边栏「SQL 日志」页签）

### B1 耗时按来源分档 + 断点补偿（D215，本次新增）

**步骤**：① 跑一个 Spring 应用（挂了插件 agent）产生几条 SQL → 看条目耗时列；② 关掉 agent，只用控制台日志解析通道 → 再看耗时列；③ 在 SQL 执行处下断点，挂起 10 秒后继续。
**期望**：① agent 精确计时原样显示；② 控制台解析的近似耗时带 **`~` 前缀**；③ 断点那条的耗时**不**被墙钟虚增（挂起区间被扣减）。
**回退**：Registry `sqlvis.log.durationSuspendCompensation` = false → 回到原样墙钟。

### B2 「疑似 N+1」红色徽标命中（D216）

**步骤**：在一个循环里连续执行 6 次同模板不同参数的查询（同一线程、60 秒内）。
**期望**：列表里这些条目头部出现**红色「疑似 N+1」**徽标（与琥珀色「×N 同结构」计数徽标分层存在）。

### B3 N+1 不误报（负例，务必做）

**步骤**：同一模板分别从多个不同线程各执行 1 次（例如并发请求各查一条）。
**期望**：**不出现红色徽标**（跨线程不聚合）。
**回退**：Registry `sqlvis.log.nplusOneSuspect` = false 关总开关；`sqlvis.log.nplusOneSuspect.minCount` 调阈值（默认 5）。

### B4 徽章点开看全（D235，未发行）

**步骤**：按 B2 构造出红色徽标后，**点击那条徽标的文字**（不是整行 SQL 区）。
**期望**：① 列表立刻只剩该模板的一组条目；② 列表上方出现摘要行：「N+1 聚合 ｜ 同结构 6 条 ｜ 首末时间 ｜ 线程名」；跨线程时写明「分散在 N 个线程：a、b、c…」；③ 页签栏出现同结构 chips（与右键「只看同结构」同形态）。
**负例**：点该行的 **SQL 区**（徽标下方）→ 应走原来的单击预览，**不**进过滤态；点没有徽标的条目 → 不反应。

### B5 退出聚合过滤态（D235）

**步骤**：B4 进入过滤态后，① 点摘要行右侧「返回全部」；② 再进入一次，按 `Esc`。
**期望**：两条都能恢复完整列表，摘要行与按钮消失，滚动位置不丢。

### B6 调用栈里的代理帧（D217）

**步骤**：从一条由 Spring 代理调用产生的 SQL 条目打开调用栈弹层。
**期望**：不再显示 `$Proxy7` / `$$SpringCGLIB$$0`，而是业务接口 FQCN / 基类；点击可直达源码；反解失败时**原样保留**（不猜）。

## 三、预览与执行链

### C1 首开不再误报「简化模式/完整编辑器尚未就绪」

**步骤**：冷启动 IDE（清缓存后首次）打开一个 mapper 语句直接点预览；另外在预览弹窗开着时切换标签让编辑器重建一次。
**期望**：**不出现**「简化模式 / 完整编辑器尚未就绪」的失败横幅（历史缺陷：每次首开都先弹一条再静默换装）。

### C2 已加引号的值不二次转义（T-PreQuotedLiteral）

**步骤**：XML 预览里给一个 int 参数输入 `'abc'`（带引号）。
**期望**：产物是 `'abc'`（不是 `'''abc'''`）；同时 `O'Brien` 这类真实撇号仍转义成 `O''Brien`。

### C3 数据源记忆的指纹兜底（D218）

**步骤**：① 执行一次预览选定数据源；② 把该数据源**改名**（或让 IDE 重建一次）；③ 再点预览执行。
**期望**：不弹选择器，按「URL+用户+库名」指纹**唯一命中**静默复用；若存在多条同指纹，才弹窗口让你选。

### C4 索引构建期点击预览不静默

**步骤**：File → Invalidate Caches 后重启，趁索引进度条还在跑时点某个 XML 语句预览。
**期望**：等索引就绪后自动重试一次；仍不行给**可见提示**说明原因（不是「点了没反应」）。

### C5 iBatis 工程首次预览不再整模块慢扫（PerfSweep31 券01）

**步骤**：在 `ibatis2-demo`（`parameterClass` 用别名）里第一次点预览，之后改一次 `sqlMapConfig` 的别名配置保存，再点预览。
**期望**：首次点击**秒级**出结果（不再整模块 XML 逐个解析卡一下）；配置保存后**立即生效**（不用重启）。

### C6 iBatis 图标缓存按项目隔离（PerfSweep31 券04 / 32 券02）

**步骤**：同时打开两个工程（一个含 iBatis 语句、一个不含），在两边来回看 gutter 图标。
**期望**：在一个工程确认过的语句/调用点，不会替另一个工程「作证」——不该出图标的不出。

## 四、MCP（AI 工具）

### D1 工具清单完整（含 IDEA 2026.3）

**路径**：Settings → Tools → SQL Visualizer → **MCP 工具**；外部 MCP 客户端（Claude Code / 任意 MCP 客户端）工具列表。
**步骤**：① 看设置页 MCP 区；② 外部客户端连 `http://127.0.0.1:<port>/stream` 后列工具。
**期望**：① 设置页显示门控状态行（见 D2）；② 外部客户端能列出 **11 个 `sqlv_*` 工具**（不是只有 `sqlv_render_sql` 一个）——**2026.3 专测点**（历史缺陷：263 新增三钩子未实现导致只剩 1 个）。

### D2 门控状态行（本次新增）

**路径**：同上设置页 → MCP 工具区。
**期望**：有一行只读状态，取值为六态之一：「已生效 / 平台契约未识别 / 已关闭 / 无此能力 / 已熔断 / 尚未探测」；不用翻 idea.log。
**回退**：Registry `sqlvis.mcp.gateFilterEp` = false 只关过滤 provider 注册（逃生开关），插件其它功能不受影响。

### D3 子页改动无需重启生效（本次修复）

**步骤**：在 **MCP 子页**里切总开关 → 点「确定」→ 不重启，看外部客户端工具清单。
**期望**：勾上 → 11 个工具**立即**出现在清单；取消 → **立即**消失；设置页门控状态行同步刷新。

### D4 关总开关不再拖垮平台 MCP（本次修复）

**步骤**：关掉插件 MCP 总开关 → 重启或不重启 → 用外部客户端连**平台**内置 MCP Server。
**期望**：平台 MCP Server 正常可用（`POST /stream` 200），插件不再往平台扩展点挂过滤 provider；重新打开总开关即补注册。

### D5 工具输出分档（D219）

**步骤**：外部客户端调 `sqlv_render_logs`：① 不传 `detail`；② 传 `detail=false`。
**期望**：① 与历史契约完全一致；② 得到摘要/紧凑清单（计数 + 短预览）。
