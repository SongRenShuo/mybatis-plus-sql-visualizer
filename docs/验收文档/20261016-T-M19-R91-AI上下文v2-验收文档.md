## 范围

从 `t-m19-r90-plan-history@316b5a48` 建独立分支 `t-m19-r91-ai-context`，不重复搬运 R90 提交。共享 `ShareContentProjection.kt` 来自主控 dev，仅复制到工作树用于编译，不在 R91 提交中；合入前由主控先提交共享文件。

真实入口是 SQL 预览面板菜单的 `copyAsAiContext`。输出标明 v2，读取当前编辑器 SQL，默认隐藏标识符并遮蔽字面量/参数名、移除注释；无法可靠投影时整段省略。不提供显示标识符选项。`AiContextExport.build` v1 原实现不变。

EXPLAIN 只消费已获取结果。确认上下文取本面板 EXPLAIN 提交时捕获的目标，复制时验证同一预览、目标仍有效，并用当前 SQL 的真实 EXPLAIN 包装文本重建 R90 key；项目、UUID、方言、格式、模板、exact 必须全部一致。未知 UUID、目标切换、新预览、SQL 参数变化不借用旧计划。没有确认目标不会去找“最近使用”的项目数据源。

计划摘要只允许固定节点/访问类型、数值 rows/cost/filteredPercent。Filter、extras、NOTICE、原 JSON、路径、参数、表列名均不输出；JSON 无法解析或采集截断则标未取得。静态摘要只读当前 PreviewResult 的真实 tableName/columns，输出表列数量，注明静态预览元数据，不冒充数据库 schema；手工改 SQL 后不借旧预览元数据。

复制不触发 JDBC、HTTP、MCP。已有计划可来自持久化历史，或本面板已取得的内存快照；复制不写历史。内存快照受历史清理 generation 失效保护。v2 整块预算 16384 UTF-8 字节，超限按计划、静态摘要、SQL 顺序整段删除并标注，不恢复原文。

## 自动验证方法

每次 Gradle 前执行 `parallel_tasks.py check`，登记 `T-M19-R91 / sandbox-t-m19-r91-ai-context`。本树 `.local/r91-sandbox.init.gradle` 将沙盒隔离到 `build/sandbox-t-m19-r91-ai-context`；机器级 gradle-gate 限两路，in-process Kotlin，JDK21。所有长命令后台启动，不 sleep/轮询；仅根 `:test --tests ...` 定向，不跑全量、构建、clean、--stop。

定向类：

- `AiContextExportTest`：既有 v1 回归。
- `AiContextV2ExportTest`：v1 golden 字节、严格 SQL、各维度不匹配、JSON 白名单、非法数值、UTF-8 预算。
- `AiContextV2PanelTest`：调用生产菜单回调、读平台 CopyPasteManager 剪贴板；核对当前编辑器与真实历史消费、目标变化、内存计划、静态摘要。
- `AiContextV2OfflineBoundaryTest`：复制及投影调用域无 SQL 执行、结构化获取、HTTP、MCP、schema 探测与异步派发调用；只读当前绑定目标，不查最近源。
- `ExplainPlanHistoryPanelTest`：R90 原生产捕获入口兼容回归。
