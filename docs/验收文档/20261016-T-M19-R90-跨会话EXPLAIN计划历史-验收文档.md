## 实现契约

- 复用 APP `SqlHistoryManager` / `SqlHistoryEntry`，由原 `MpSqlVisualizerHistory` 组件写入 `mp-sql-visualizer.xml`。不创建数据库或历史 sidecar。
- 独立 `explainPlanRetentionEnabled` 默认 false，旧配置即使开启结构化渲染也不迁移为同意保存。预览设置在复选框下始终展示 APP XML、原始计划未经脱敏可能包含业务值/秘密/凭据、清除预览历史可删除计划的说明；勾选后须 Apply 才生效，Reset 丢弃未应用改动。
- 提交时和成功回调保存时两次检查独立开关，二者都开启才允许保存；中途关闭或提交时未同意均不保存。关闭后保留同会话比较，不读取跨会话基线，也不自动删除已有计划；删除走清除预览历史。
- `projectIdentity` 为规范化项目根路径的 SHA-256，不把本机路径明文加入计划 DTO。无根路径、无有效数据源 UUID 时仅保留会话基线，不凭显示名或 URL 猜测身份。
- 持久化匹配键包含项目身份、数据源 UUID、方言、格式、模板指纹和 exact 指纹。exact 对实际提交的 EXPLAIN 文本计算，含 EXPLAIN 包装；模板只用于结构关联，不跨参数值比较。
- `PreviewResult.historyEntryId` 在正常预览入库时记住原条目。XML/日志等未经过 recordHistory 的纯文本预览仅在独立保留开关开启时，于首次结构化 EXPLAIN 提交前建同域条目。已经分配过 ID 的条目若被删除，不再自动补建。
- 请求提交前固定原 entryId、实际目标、SQL 指纹、clear generation。成功回调先取旧基线，再保存新结果；不在回调里查询当前面板/当前数据源来决定归属。
- 单条最多 5 份；单份真实 XmlSerializer XML UTF-8 大小最多 256 KiB；所有计划合计最多 8 MiB。总额淘汰只删最旧计划，不删收藏 SQL。单份超限返回 TOO_LARGE，结果视图显示拒绝原因，不缩短结果再偷偷保存。
- DTO 默认空字段，兼容旧 XML；只包含值类型及 JSON 编码列头/行/截断标记，不持有 PSI、Swing、JDBC 或数据源对象。不专门采集数据源 URL、显示名、凭据字段，不保存驱动 notices。这不是 payload 无凭据的保证：计划行仍是数据库返回的未脱敏原文，业务谓词/字面量可能包含秘密、URL 或凭据；启用前必须披露并由用户独立选择保留。
- R61 同目标会话比较保留。UUID 未知时仅对同一会话内同一数据源对象比较；切换未知目标对象不比较。历史下拉框可以选任一当前保留且匹配的基线，仅重新计算 diff，不执行 SQL。
- 全部历史清空或 loadState 使代际变化，迟到回调不能恢复历史，也不能把旧会话基线继续带回来。

## IDEA UI 正式验收方法（待执行，未启动沙盒）

1. 先保持“跨会话保留原始 EXPLAIN 计划”默认关闭，即使结构化渲染已开启，运行 EXPLAIN 也只能同会话比较、不新增计划。打开预览设置，确认无需悬停即可看到 APP XML/未经脱敏/业务值与凭据/清除说明；勾选后 Reset 应回到关闭，再勾选并 Apply。随后在支持结构化通道的 MySQL TABLE 或 PostgreSQL JSON 目标上，用稳定 UUID 和固定参数 SQL 运行 EXPLAIN，才应出现“已保存”。
2. 修改受控测试库索引或统计信息后再次 EXPLAIN，确认默认基线来自前次；记录可复现的 rows/cost/访问方式差异。不把业务真库写变更作为本自动验收的动作。
3. 正常退出 IDE 再重开同项目、同 UUID、同 SQL，执行一次 EXPLAIN，确认历史基线仍在。下拉选择每份保留基线，观察 diff，核对数据库审计/受控执行计数在切换时没有新增 SQL。
4. 切换项目、UUID（即使显示名相同）、方言、输出格式、参数值，分别确认不串基线；UUID 无法解析时明确“仅本会话”。
5. 制造超过 256 KiB 的结构化结果，确认显示未缩短、明确拒绝保存；重复保存超过 5 次只保留最近 5 份。检查 8 MiB 淘汰不会删收藏 SQL。
6. 开始慢 EXPLAIN 后清空历史；回调到达不得恢复条目。另在提交后关闭保留并 Apply，回调不得保存；提交时关闭、回调前才开启也不能追认。删除原条目、切换预览时重复该对照。确认当前面板的回调代际与 history clear generation 两层均生效。
7. Light/Dark、窄宽面板检查选择器、提示条与树/表格可读性，并验证“回到原生控制台”仍走原双通道行为。

这些项目全部保持待验。跨版本平台行为、真实 IDE 自动保存到磁盘的重启生命周期、真实 JDBC 行采集上限及性能，没有本轮运行证据。相同路径项目身份保持稳定；移动项目目录会开启不同身份，不迁移旧计划。
