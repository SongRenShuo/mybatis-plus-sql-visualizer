# dev 分支新增功能人工验收手册

> 2026-10-18 编写。配套文档：`20261016-T-DevFullUI-合流后全功能沙盒验收记录.md`（沙盒自动化验收全账，44 组矩阵与 30 个缺陷的判定依据在那边）；本手册面向人工走查，只写「在哪里点、按什么顺序、看到什么算对」，并把沙盒里验不了、需要真人定性的项单独列入第四节。
>
> 用法：按第二节冒烟路径过一遍核心链路（约十分钟），再按第三节分域逐项勾选；任何与预期不符的，记下操作步骤与截图，对照第五节「正常现象速查」排除后仍异常的，按缺陷报。

## 一、准备

1. **安装 dev 构建包**：dev 工作树 `build/distributions/mybatis-plus-sql-visualizer-2026.10.16.zip`（以最新一次 buildPlugin 产物为准）→ Settings → Plugins → 齿轮 → Install Plugin from Disk → 重启 IDE。日常 IDE（2026.2 及以上均可，插件 since-build 243）或 runIde 沙盒都行。
2. **核对版本**：Settings → SQL Visualizer → About，应显示 2026.10.16 与内部构建号 `MPV-Build: …`；装包时间晚于 2026-10-18 18:54 才包含「差异对比」基线修复（UI-023）。
3. **演示工程**：`mybatis-plus-sql-visualizer-demo`，从 IDE 里 Run 启动 `MybatisPlusDemoApplication`（8081）。捕获类功能的前提是应用从 IDE 里跑（外部终端启动捕获链挂不上）。
4. **打开工具窗**：右侧边条或 Find Action（Ctrl+Shift+A）搜「SQL Visualizer」，工具窗有四个页签：SQL 日志 / 日志 → SQL / SQL → Java / SQL 历史。

## 二、十分钟冒烟路径

1. 开捕捉：SQL 日志工具窗标题栏**悬停**出现绿色三角 ▶（tooltip「捕捉」），点一下变红色方块＝捕获中。下方出现实时诊断行（「捕捉中 | 增强：… | 控制台：已挂载 N 个，已扫描 N 行」）。
2. 浏览 `http://localhost:8081/user/1` 几次 → SQL 日志列表出现条目；增强捕获开启时条目行带方言、耗时、`[UserController.java:70]` 源码链接。
3. 双击任一条目 → 弹出「SQL Visualizer - SQL 预览」面板，SQL 语法高亮；改参数区输入框 → SQL 实时重渲染。
4. 预览面板点「更多」→「差异对比」→ 出现「SQL 差异对比」窗口（**注意**：该窗口当前可能开在主窗后面，Alt+Tab 查找——这本身就是第四节要人工定性的项，请记录窗口是否自动到前台）。
5. 「更多」→「分享」→ 七个出口单选在位 → 选「复制为 Markdown」→ 确定 → 粘贴到任意编辑器核对内容。
6. 切「SQL 历史」页签 → 有按日聚合的历史文件 → 双击钻入 → 双击条目可再开预览。
7. 预览面板点「执行计划」→ 出结构化 EXPLAIN 或回退提示（首次可能弹数据源选择器，选中后自动重试）。
8. Settings → SQL Visualizer 各页走一遍（SQL 日志 / SQL Preview / MCP Tools / About），布局无截断、开关可点。

### 3.6 执行与错误面

| 功能点 | 路径与操作 | 预期 |
|---|---|---|
| 执行 SQL | 预览 → 执行 SQL →（首次）选数据源 | 写语句弹确认框；未知渲染方言时红字整体阻断（fail-closed）；确认后 Database 控制台真实执行并回显结果 |
| 未知写拒绝 | 方言未知时执行 DELETE | 阻断而非放行 |
| 富错误 | 执行 `SELECT * FROM 不存在的表` | 底部完整回显 `[42S02][1146] Table … doesn't exist` + 当前库/数据源三元组 + 「复制错误信息」 |
| 失效定位 | 错误后点「定位失败语句」 | 编辑器选中出错语句 |
| 未知 QUERY 确认 | 执行前弹确认，长时间停留 | 用户思考多久都不误取消、不误提交（停留数分钟后再点仍正确） |
| SQL 快捷模板 | 预览里**双击选中表名** → 右键 → SQL 快捷模板 | EXPLAIN 选中表 / COUNT 选中表 / 抽样 10 行三项点亮（未选中表名时灰置）；COUNT 真实执行返回行数 |

## 四、人工定性重点（沙盒验不了，请重点走）

1. **差异对比窗口 z 序（最重要）**：预览 → 更多 → 差异对比，观察「SQL 差异对比」窗口**是否自动出现在最前**。沙盒合成输入下它稳定开在主窗后面（登记为 UI-024，未定性是真缺陷还是自动化环境产物）。若人工点击也置后，请记录——这就是要修的缺陷；若正常到前台，则闭环撤销该登记。
2. **gutter 图标右键菜单**：预览 gutter 图标上右键，应弹「预览 SQL / 最近执行记录」菜单。合成输入点不出来（13 次尝试零痕迹），人工右键一次即可定性。
3. **二维码三态**：About 页交流群二维码的加载成功 / 加载失败 / 关闭后晚到结果三态。
4. **持久化重启保留**：造一条屏蔽规则 + 一个命名预设 → 正常退出 IDE → 重启 → 两者应保留（沙盒退出链被确认弹窗阻断，强杀不落盘，此路径只有人工能验）。
5. **更新可用态**：发新版本后「检查更新」出现可用更新提示的形态。
6. **高对比度主题与缩放组合**下的列表配色与页签布局。

## 五、正常现象速查（别当缺陷报）

- **控制台永远明文**：插件不改写应用控制台输出，Parameters 行原文在案是设计（采集与展示解耦，脱敏只作用于列表/浮层/导出）。
- **「复制 SQL」是原文**：复制出口不走展示脱敏（口径内）；列表、预览浮层、导出文件才打码。
- **列表没有方言/耗时列**：当前条目来自控制台通道就是没有这三项；增强通道开启后才有。
- **列表空但控制台有 SQL**：捕捉开关没开（空态会换成诊断行，开录前先看诊断行确认在收条目）。
- **重启后首次预览出红色「降级模式（内存 PSI）」横幅**：预热迟到或临时文件失效的设计内降级，点「重试」或关开预览即恢复完整支持。
- **窄栏下「日志 → SQL」页签左端被裁**：平台 JBTabs 行为（无省略号），约 228px 以下整个工具窗会被平台收起。
- **设置页控件词搜索不到**：自定义页未实现内容搜索，属已知限制。
- **勾选动态条件没反应且顶部有降级横幅**：降级期联动不生效（横幅已披露），点重试恢复完整模式后再试。
