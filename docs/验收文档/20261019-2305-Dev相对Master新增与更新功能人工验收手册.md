## 一、准备

1. 安装 dev 构建包：dev 工作树 `build/distributions/mybatis-plus-sql-visualizer-2026.10.16.zip`（以最新一次 buildPlugin 产物为准）→ Settings → Plugins → 齿轮 → Install Plugin from Disk → 重启。
2. 版本核对：Settings → SQL Visualizer → About，显示 2026.10.16 与 `MPV-Build: …` 内部构建号。
3. 演示工程：`mybatis-plus-sql-visualizer-demo`，从 IDE 里 Run `MybatisPlusDemoApplication`（8081）。捕获类功能要求应用从 IDE 启动。
4. 工具窗：Find Action（Ctrl+Shift+A）搜「SQL Visualizer」，四页签：SQL 日志 / 日志 → SQL / SQL → Java / SQL 历史。

## 三、分域验收步骤

### 3.1 方言与执行安全（O-145 系列）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开任意 Wrapper/注解/XML 预览 | 头部显示「方言: MySQL（模块已学数据源）」等来源标注；未验证时显示「方言未验证：兼容按 X 预览（原因）」 |
| 2 | 多数据源工程打开 MPJ Lambda 预览 | 无绑定/学习时显示「项目候选方言不一致；执行一次 SQL 或手动指定方言即可确定」 |
| 3 | 点「执行 SQL」并选目标数据源 | **不关预览**，方言行应在一个刷新拍内变为「方言: MySQL（已绑定数据源）」；绑定行与方言行不再自相矛盾 |
| 4 | Settings → SQL Preview → 数据库方言手动选 PostgreSQL，绑定 MySQL 源后执行 | 红字整体阻断（不覆盖手动选择、不暴露冲突会话控制台） |
| 5 | 关开预览 | 方言状态保持一致，不回退为未验证 |

### 3.4 执行、计划与 Schema

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 预览点执行 SQL（写语句） | 写确认框；未知方言红字阻断；确认后控制台真实执行 |
| 2 | 执行计划（无绑定） | 直接弹数据源选择器 → 选中后自动重试结构化；取消只说明一次 |
| 3 | 结构化计划（设置开启） | 面板内表格；PG 源为树形 + SEQ_SCAN 体检条；两次执行显示「计划无变化」；历史可回看 |
| 4 | 预览编辑器改错列（如 usernme） | 红色波浪 + 悬停建议（仅 MySQL/MariaDB、已预热、目标明确） |
| 5 | 预览 SQL 选中表名 → 右键 SQL 快捷模板 | EXPLAIN/COUNT/抽样三项点亮（未选中灰置）；COUNT 真实执行 |
| 6 | 预览中执行只读动作后查看编辑器 | 预览编辑器内容不被替换；执行视图有「返回预览」 |

## 四、更新类行为变化（相对 master 的既有功能）

以下不是全新功能，但行为/默认值相对 master 有变化，验收时按新行为判定：

1. **增强捕获默认开启**、首次注入确认移除（设置页可关）；暂停按钮暂隐藏。
2. **只读动作不再替换预览编辑器**：影响行数内联显示、EXPLAIN 非模态、执行视图可返回预览。
3. **差异对比修复**：执行/参数变化后可正常出图（此前恒报「无上次预览」）；窗口 z 序观察项 UI-024。
4. **方言状态行随执行即时刷新**：不再需要关开预览。
5. **历史页新增「滚动到底部」**，过滤集合下直达真实末条。
6. **AI 上下文 v2**：结构关键词保留 + 第九项「含表列名」。
7. **FieldFill 面板**：角标与字段名同行、模拟值行按开关显隐、模拟值优先并置灰普通输入。
8. **工具栏图标全部改为插件自带 SVG**，四页签统一。
9. **展示脱敏 INSERT 对位修复**（UI-021）；降级横幅补充交互缺失披露（UI-022）。
10. **错列红波浪**（UI-025/029）与 **EXPLAIN 回退选择器直弹**（UI-030）。
11. **设置页布局修复**（UI-001/024/026）：默认窗口宽下控件不裁切。

## 七、正常现象速查（别当缺陷报）

- 控制台原文永远明文（脱敏只作用于展示/导出）；「复制 SQL」出口为原文。
- 列表无方言/耗时列＝条目来自控制台通道（增强通道才有）。
- 列表空＝捕捉开关没开（看空态诊断行）。
- 重启后首次预览可能出「降级模式（内存 PSI）」横幅，点重试恢复。
- 窄栏（约 333px 以下）页签左端裁切、228px 以下工具窗收起，属平台 JBTabs 行为。
- 暂停按钮当前默认隐藏（设计内收敛），不是功能缺失。
- 差异对比窗口可能在主窗后（UI-024 待真机定性）。
