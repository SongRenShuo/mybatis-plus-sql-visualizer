## 一、批 A：三族 attach 事件回流 —— 闭环

### 做法（这是上一轮卡点的正解）

上一轮卡在「插件挂不到非 IDE 启动的外部 JVM」。本轮改走**IDE Run 链路**，让平台自己注入 `-javaagent`：

1. demo `pom.xml` 加三条 **system-scope** 依赖，指向 `lib/` 下三族驱动 jar
   （jar 来自插件沙盒 `plugins-test/.../lib`，即插件已在用的同一批）
2. 每次只改 `src/main/resources/application.yml` 的 datasource 四项（驱动类/URL/账号/密码）
3. IDE 里 Shift+F10 跑 `MybatisPlusDemoApplication`（已有 Run 配置），
   平台 `updateJavaParameters` 自动注入 agent → premain 回连 → 事件进面板
4. 每族跑 ~40s（`SchedulerDemoTask` 每 3s 一条 SQL），面板读数后换下一族

### 附带确认的两件事

- **失败语句同样回流**：三族都对 `user` 表报了 `ERROR: column "id" does not exist`（PG 族 `user` 是保留字），
  面板照常出条目并带 `Caused by: com.highgo.jdbc.util.PSQLException` 等错误链——证明捕获钩子挂在
  执行入口而非成功分支（与 `WovenEvents.emit(… failure …)` 设计一致）。
- **角标取自 JDBC URL**：同一份代码、同一个面板，换 datasource 即换角标，三族互不串味。
