### 9. GaussDB `DELETE ... LIMIT` 语义 — 通过（真机 DB 读数）

实例：`103.36.220.245:25882 / xc3_test`，`version()` = `gaussdb (GaussDB Kernel 503.1.0 build f53b4ed8) compiled at 2023-03-27`（**老版本，兼容模式仍是 A/B/C/PG 老命名，不是 5.x/6.x**）。

| 步骤 | SQL | 读数 |
|---|---|---|
| 建表插数 | `CREATE TABLE s28_del_limit(id int primary key, v text)` + 插 5 行 | 5 rows |
| LIMIT 1 | `DELETE FROM s28_del_limit WHERE id <= 5 LIMIT 1` | **1 row affected**，剩余 4 行（id 2..5） |
| LIMIT 2 | `DELETE FROM s28_del_limit WHERE id <= 5 LIMIT 2` | **2 rows affected**，剩余 2 行 |
| 清理 | `DROP TABLE s28_del_limit` | 0 rows |

结论：`DELETE ... LIMIT n` 在 GaussDB Kernel 503.1.0 上**语义成立（真的限行）**，不只是语法接受。按计划 §R1 的告诫，此读数**不得**外推成「GaussDB 5.x/6.x 已验证」；是否把 `supportsDeleteLimit` 翻 true 属产品决策，本轮只交读数。
