面板仍报同一句「都还没有连接成功或尚未完成内省」。**结论两条**：

- **产品面**：`首次执行跑通` 没成立——连接与内省都补齐后仍 `runners=0`，说明 UI-046 的修复**没有触及真正的门槛**。
- **本轮把真门槛定位清楚了**：不是「未连接」、不是「未内省」，而是**平台 `DatabaseRunners.getAttachDataSourceRunners` 需要「文件 → 数据源」的绑定/关联**。这不是推断——本仓自己的 KDoc 早就记着同一事实：`DataSourceSelector.kt:419-422`（T-ExplainPwdPrompt W4，2026-10-24）写的是「数据源无方言映射时平台 `getAttachDataSourceRunners` 返回空；243 沙盒实测：**Database 视图已连接仍为 0**」。EXPLAIN 链当年为此加了 W4/W9 回落（绕开绑定链取源），**执行链没有同款回落**。
- 预览面板的绑定行本身也在说这件事：`未绑定数据源（在控制台执行一次查询即可绑定）`（u046-15-preview4.png）——即当前产品语义是「必须先开 Database 控制台跑一次」，首次执行从预览走不通是**设计缺口**，不是偶发。

### 3. 新缺陷 UI-048（P2）：`DIALECT_MATCHED_BUT_UNUSABLE` 档的文案在不该说的时候说「未连接」

- 复现：单源、**已连接、已表级内省**、未绑定 → 点执行。
- 实际：报「已检测到 1 个数据源，但它们都**还没有连接成功或尚未完成内省**…」——本态下这句**为假**。
- 成因：`ExecDialectRouting.classifyEmptyRunners` 的四档里，`DIALECT_MATCHED_BUT_UNUSABLE`（方言判得出、也对得上，却仍枚举不出 Runner）与 `DIALECT_UNKNOWN` **共用 `notConnected` 文案**，把「未连接/未内省」当因果写死了。
- 修法建议（择一或组合）：
  1. 用已有的 `ExecFileBinding.probeExecBind(project, vf)` 探针再分一档「未绑定」，文案给可行动作「先在 Database 控制台执行一次查询以绑定数据源」（与绑定行口径一致），不再断言连接状态；
  2. 至少把 `notConnected` 文案改成**不含因果断言**的中性表述（如「平台当前无法为本条 SQL 定位可执行的数据源：请确认数据源已连接、已完成内省，且本文件已与其绑定」）。
- 严重度：P2——不损坏数据、不阻断已有绑定用户，但对新用户的排障方向仍有误导（与 UI-046 同族，只是换了个错误方向）。
- 证据：u046-26-introspect.png、u046-28-exec3.png（同一帧内 Database 树已列出 11 张表）；日志 05:29:40 三行。

## 四、过程坑（回写 skill 与记忆）

1. **沙盒 config 的真实层级**是 `build/<容器>/<插件名>/<IU-版本>/config`——`idea.key` 拷到 `build/<容器>/config` 无效，会弹「Manage Licenses」且报 `JBA connection error`（本轮第一次踩）。
2. **沙盒没有 JDBC 驱动实体**：Properties 报「Download missing driver files」。整拷宿主 `jdbc-drivers` 目录后**必须重启 IDE**（驱动清单启动期读取，重启前面板仍显示 Problems）。
3. **「Trust and Open Project」对话框标题为空**，`EnumWindows` 按标题找不到；它还会被其它窗口压在下面——点击前必须**按 rect 命中 HWND 并 `SetWindowPos(HWND_TOP)`**，否则点击落在别人窗口上（本轮两次空点就是这么来的）。
4. 沙盒 IDE 是**提权进程**：非提权 python 的 SendInput 被 UIPI 静默拦（不报错、无反应）；`jcmd` 读它的命令行也要提权。
5. **硬杀 IDE 会留下用户映射文件锁**：`prepareSandbox` 报 `Could not copy file … alpn-api-*.jar（请求的操作无法在使用用户映射区域打开的文件上执行）`＝`ERROR_USER_MAPPED_FILE`；且卡住的 gradle wrapper 进程要一并杀（`Stop-Process -Id`，别在 Git Bash 里写 `taskkill /PID`，MSYS 会把 `/PID` 转成路径）。
6. 预览多语句文件会弹「选择要预览的 SQL」，必须**选中目标行 + Enter**；点空白处不生效。插件自定义动作不进 Find Action，预览只能 `Alt+Shift+Q`。
