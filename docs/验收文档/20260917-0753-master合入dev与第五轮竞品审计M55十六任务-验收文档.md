## 三、分功能验收步骤

### 3.1 执行错误定位按钮（T-ErrorLocate）

**前置**：Ultimate + 已配数据源 + 预览面板已出 SQL。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 故意执行一条带语法错误的 SQL（如 `SELECTT 1`） | 结果区红字错误 + 「复制错误」旁出现「定位到出错语句」按钮（仅错误态出现） |
| 2 | hover 定位按钮 | tooltip 注明「跳转到源文件中的语句起始行（错误行映射不可靠）」；驱动带位置时注明 Position 值 |
| 3 | 点击按钮 | 跳转到预览来源文件的光标行（v1 诚实降级=语句起始行，不虚标列级） |
| 4 | 执行成功的语句 | 定位按钮消失（仅错误态出现） |
| 5 | 从未登记锚点的入口（gutter 直开预览）触发失败 | 定位按钮不出现（诚实降级，不出现失效按钮） |

### 3.2 断连但 DDL 已生效警示（T-DdlRecover）

**前置**：MySQL/PG 数据源；能人为断连（停库容器/断网）。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 执行 `CREATE TABLE ddl_probe (id INT)` 后立刻停库（制造断连） | 原错误红字在位；数秒内出现橙色警示「连接已断开，但对象 `ddl_probe` 已存在（探测于 HH:mm:ss…）」 |
| 2 | hover 警示 | tooltip 保留完整原始错误（警示不消除错误原文） |
| 3 | 执行非 DDL 语句（SELECT）后断连 | 只有原错误，无警示条（不误伤） |
| 4 | 执行 CREATE 后断连但目标建库侧未生效（如回滚） | 维持原错误 + tooltip 追加「已尝试生效性探测：未检出对象」（绝不把没查到包装成没生效） |
| 5 | 消息带 deadlock 的普通失败 | 无警示（排除表生效，deadlock 非连接类） |

### 3.3 MCP explain notices 与 index hints（T-NoticeChannel / T-ExplainIndex）

**前置**：MCP client 已接入（IDEA 2025.2+ 内置 MCP Server）；PG 数据源最佳。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | MCP 调 `sqlv_explain` 跑一条普通有索引查询 | 输出末尾无 `notices:`/`index hints:` 节（空清单零追加，与既有输出逐字节一致） |
| 2 | PG 上构造 NOTICE 场景（如 `DO $$ BEGIN RAISE NOTICE 'x'; END $$` 所在函数链）后 explain | 输出尾出现 `notices:` 节，每条一行 |
| 3 | explain 一条无索引大表查询（MySQL `type=ALL` 且 rows≥1 万；PG `Seq Scan` 大表） | 输出尾出现 `index hints:` 节：`[FULL_SCAN]`/`[SEQ_SCAN]` 规则 + 表名 + 建议文案 |
| 4 | explain 命中 filesort/temporary 的语句 | `[FILESORT]`/`[TEMPORARY_TABLE]` 建议行在场 |
| 5 | 小表全扫（rows<1 万） | 无建议行（阈值防噪音） |
| 6 | DM/Oracle 等方言 explain | 无 hints 节（不支持方言静默降级） |
| 7 | 观察错误语句的输出 | 失败走错误通道，notices 不出现（失败路径丢弃口径） |

### 3.4 语句命名标注（T-StatementNaming）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 粘贴一段多语句日志（语句带前导 `-- Name: 分页查询` 注释）到「日志 → SQL」并转换 | 组头显示 `-- SQL #N [分页查询]` |
| 2 | 语句只有普通行注释（无 Name: 前缀） | 组头附最近一条非空行注释内容 |
| 3 | 语句无前导注释 | 组头维持 `-- SQL #N` 逐字节不变（硬门禁） |
| 4 | MCP `sqlv_render_logs` 传同款日志 | 语句头 `-- SQL #N [来源] … [名称]` 附名 |
| 5 | 逐条执行带名称组头的产物 | 原生控制台正常执行（注释不影响执行） |
| 6 | 名称超 40 字符 | 截断到 40 |

## 四、已知边界

- **定位按钮 v1 为语句起始行**：驱动报错位置指向被执行 SQL 文本，与 mapper 原文行不一一对应（动态 SQL 拼接/参数注入），列级精确定位后续迭代（tooltip 已如实注明）。
- **IDE 原生控制台结果行无程序化读取面**（T-EI-01 定案）：index hints 走 MCP explain 承载位；IDE 面建议条挂账（备选 B 自渲染成本收益不成立）。
- **DBN 结果页签不可命名**（displayName 只读）：语句命名落在还原组头与 MCP 语句头，不动原生页签。
- **方法聚焦首批仅 Java 调用方**：Kotlin 调用方条目聚焦不可用（右键项不出现或 toast），记已知边界。
- **MP 内置语句（Wrapper CRUD）无 mapper XML**：跳 XML 自动回退 Java，不劣化。
- **CrudSqlTool 产物为 CRUD 模板无前导注释**：语句头天然不附名（零差异）。
- **requestTag 来自 MDC（key=`sqlvisRequestTag`）**：应用未埋 MDC 时无请求标签、无「按请求聚焦」入口。
- **锚点探测为文本启发式**（T-UxOnboard 偏离记录）：零 PSI 依赖；误报后果仅为多弹一次一次性提示。
- **T-NoticeChannel IDE 面**：DBN 原生 Output 区是否已展示 notices 属真机定案项（MCP 链不受影响）。
