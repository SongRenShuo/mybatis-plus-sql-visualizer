### 3. T-XmlDtdHardening — 有条件通过（1 项阻断，已修 `c80a845`/`6deaa70`/`2e707ee`）

**阻断：三道膨胀闸门被一个 6 字节诱饵整体绕过。** 独立复核实测 6 条「声明/引用对预扫不可见」的绕过——同一载荷（4 层 × 10 引用 × 4000 字符）不加诱饵时预扫正确拒绝（chars=65537），**加 6 字节诱饵后预扫 PASS 且 JDK 实际展开 40,000,016 字符**。根因是子集切分用 `indexOf("]>")`，不识别引号/注释/处理指令/条件段。

逐条处置：

1. 子集切分改**引号/注释/处理指令/条件段状态机**，结束符 = `]` + 可选空白 + `>`。三种诱饵形态（实体值 `<!ENTITY d "]>">`、注释 `<!-- ]> -->`、处理指令 `<?pi ]> ?>`）实测 JDK 均接受且不构成子集结束。
2. **`] >`（`]` 与 `>` 之间有空白）此前完全不认结束符** → 整段不扫。
3. `indexOf("<!DOCTYPE")` 被序言注释/处理指令里的假 DOCTYPE 抢占 → 改为只在注释/处理指令/CDATA 之外认。
4. **参数实体走私**（PE 字面量里的声明对预扫不可见，`%hide;` 被按 1 字符计）→ 新增 `visibleSubset` 把 `%name;` 迭代替换为字面量（轮数上限 32、展开预算 262,144 字符，超限即拒），三项判据同时恢复可见。
5. **非 ASCII 实体名**（`<!ENTITY é "…">`）不被 `[A-Za-z_]` 起头的名字正则认下 → 改走宽松 `isNameChar`（只排除空白与结构性字符）。
6. **误报方向一**：递归护栏 `visiting.size >= 16` 应为 `>`——头先声明的 16 层链（合法，实测 JDK 接受）此前被误拒，深度判据不得依赖声明顺序。
7. **误报方向二**：子集内处理指令里的 `<!ENTITY …>` 文本此前被当声明（实测 JDK 口径相反：PI 里的声明不生效）→ 抽出 `skipNonMarkup` 供声明扫描与 PE 替换共用，消除「PI 里 70,000 字符文本把合法文件误判为展开超限」的误报（先红后绿实测）。

另加 `indexOfDoctype` 快路径（全文无 `<!DOCTYPE` 时不做状态扫描）。**读数**：改前 6 条载荷预扫全 PASS、实际展开 40,000,016 / 10,000,016 / 1,000,016 字符（探针非提交物）；改后 `SecureXmlTest` 28 例全绿（改前 26 例 8 失败），诱饵与走私载荷均在 1~12ms 内由预扫拒绝（无展开发生），`xml.*` 定向 223 例 0 失败。**放行不回退**：官方 DTD 真文本（test classpath 上 mybatis-3.5.19 的 `mybatis-3-mapper.dtd`，7,819 字节 / ELEMENT 33 / ATTLIST 28 / ENTITY 0 / 无 `%` 引用 / 无 `]>`）整段内联仍放行，新增用例 `官方DTD整段内联不被误伤` 钉住。

**同时订正了实施方自己的两处事实性错误主张**（计划「偏离说明②」原句）：(a)「字符数上限不受影响」不成立——三项判据只对**可见声明**有效，而可见性此前无任何保证；(b)「对真实攻击判据充分」不成立——深度判据当时还依赖声明顺序，字符数判据只是**单实体**展开估算、不含正文引用次数（实测 `<!ENTITY big "y"×65,536>` 正文引用 100 次 → 展开 6,553,616 字符放行）。**订正后口径**：三项判据管「单个可见字面量实体展开量 ≤ 65,536、引用路径深度 ≤ 16、可见字面量声明数 ≤ 64」，**不管文档总展开量**（由 JDK `totalEntitySizeLimit` 50M 兜底）。

**先红后绿**：`mcp.*` 红 104/6（错误路径 6 例全红，报文里审计槽位只剩 `dataSource=demo dialect=MySQL sql=…`，92 字符错误文本整段不在）→ 绿 104/0/0/0（McpAuditLogTest 11/0/0/0，改造前 6 例 + 本轮 5 例）。

- **T-PsiCaptureProtocol**：`textRange` 越界态只有表驱动覆盖（真夹具无法在 stamp 不变的前提下改文档长度）；守卫 `psiCapture` 的漏报面未穷举（只覆盖 `executeOnPooledThread` 池化块本体）。
- **T-ErrorReportRedact**：云侧端到端未验；指纹「残留塌缩」为已知限制（用例钉住，防被当 bug 反复修）。
