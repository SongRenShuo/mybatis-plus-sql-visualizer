## 一、背景与判据

v2026.10.29 的 P0：2026.1.x 启用 MCP Server 后，插件的工具过滤器代理按 2026.2 契约（`applyFilters`）
写的，261 调 `getFilters` 落到兜底返回 null，平台把 null 当迭代器传给 `addAll` → **平台内置 MCP
服务对所有客户端 HTTP 500**，`idea.log` 特征行是
`NullPointerException: Parameter specified as non-null is null ... CollectionsKt.addAll`。

修复（T-Mcp261FilterContract）：先探测契约再注册 + 未知方法按返回类型空值兜底 + 实现体异常降级。
此前该修复只有「对真实 261 jar 字节码跑形态探测」的取证（`_mcp261_probe/`），**从未在真 261 IDE 上
运行验证过**——本册补的就是这块。
