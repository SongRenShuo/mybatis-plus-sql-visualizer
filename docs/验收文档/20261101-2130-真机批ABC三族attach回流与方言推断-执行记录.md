### 2.2 卡点：插件不会挂到「非 IDE 启动」的 JVM

逐条实测：

1. **捕获开关 ▶ 已开**（面板显示 `捕获中 | 增强捕获: 已开启 | 已收集事件 0 条`），三个宿主进程在跑，面板零条目。
2. **重启宿主进程**（模拟「进程出现」）→ 仍零条目；日志无 `onProcessAppeared` / `attachToPid`。
   说明进程出现回调只接 IDE Run 链路（`RunConfigurationProcessListener`），不覆盖外部 JVM。
3. **代码里唯一覆盖外部 JVM 的入口**是设置变更的**上升沿**：
   `AgentManager.init` 订阅 `SETTINGS_CHANGE_TOPIC`，`enhancedCaptureEnabled` 由 false→true 时
   `scanAndAttachRunningProcesses(project, "settings-rescan")` 扫在跑进程补挂。
4. **该上升沿在本轮真机没有触发**：在设置页把「增强捕获」关掉→Apply→打开→Apply 之后，
   日志既无 `设置变更：增强捕获重新开启——用户暂停已复位`，也无 `在跑进程补挂 N 个`；
   退出 IDE 后 `config/options/mp-sql-visualizer.xml` 里也没有该字段（默认值 true 本就不落盘，
   故这一条**只能证明「没有非默认值被写」，不能单独证明 apply 失败**）。
