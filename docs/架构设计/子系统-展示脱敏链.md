## 职责与边界（Responsibilities and sources of truth）

| Part | Responsibility | Source of truth |
|---|---|---|
| 判定与打码 | 关键词 hint contains + 身份证/手机号形态双条件；白名单优先于一切识别 | `util/DisplayMasker.kt`（`classify`） |
| 动作分级 | OFF/MASK/WARN/BLOCK 四档（屏显面全语义；离开 IDE 面归一为 MASK） | `util/DisplayMasker.kt`（`MaskMode` / `scanSqlText`） |
| 命中计数（Hint） | `MaskScan.counts` 三类键（sensitive_column/id_card/mobile），只含类别×次数，**绝不携带原值** | `util/DisplayMasker.kt`（`MaskScan` / `warnLine`） |
| fail-closed 兜底 | 引擎异常按阻断兜底（`log.preview.maskFailed`），绝不裸出原文；OFF 档入口短路 | `util/DisplayMasker.kt`（`safely`；code-standards M1） |
| 设置模型 | `displayMaskMode`（空串=未迁移哨兵，按旧布尔推导）+ `displayMaskAllowList`；`displayMaskEnabled` 仅作迁移源 | `config/PluginSettings.kt`（`displayMaskMode()` 访问器 + loadState 归一） |
| 设置 UI | 分级下拉 + 白名单文本域；选项携带枚举本体（WARN/BLOCK 的唯一产出点） | `config/PluginSettingsPanel.kt`（`MaskModeOption` / `maskModeOptions`） |
| 屏显面 | 日志列表渲染/历史页/预览浮层（WARN 加警示行）/停靠预览 | `log/LogEntryRendering.kt`、`log/HistorySqlLogPanel.kt`、`log/SqlClickPreview.kt`、`log/SqlDockedPreview.kt` |
| 离开 IDE 面 | 导出/Replay 脚本/MCP（独立开关 `mcpMaskEnabled`）/浮层复制/优化留痕导出（只对 SQL 打码，计划文本不打码——打码器会抹掉数字、失去诊断价值）：mode≠OFF 一律打码 | `log/SqlExportService.kt`、`log/ReplayScriptExport.kt`、`mcp/SqlVisualizerRenderLogsTool.kt`、`log/TraceDocExport.kt` |
| 复制出口 | 日志列表 Ctrl+C 与预览复制都走脱敏（W2 补齐缺口） | `log/LogEntryFiltering.kt`（`textFor`）、`SqlClickPreview.previewCopySafeText` |
| AI 上下文 | `parameterize` 参数化，不受开关控制 | `util/AiContextExport.kt` |

## 关键约束

- **双侧同步纪律（收窄后）**：同步范围=KEYWORDS 与形态规则本体；分级/白名单/计数是展示侧有意差异，agent 不跟进（无 UI 无状态）。
- **屏显面与出口面分开**：WARN/BLOCK 的原文语义不外流——导出/复制/MCP 一律归一 MASK 后渲染。
- **提示不回显原值**：警示行与 BLOCK 占位只含类别与次数（bundle `log.preview.maskWarn`/`maskBlocked`）。
- **缓存键带 mode**：渲染缓存（`cachedListLineFragmentsMasked` 等）以 MaskMode 串为键，防不同档结果串缓存。
- **插值对位**：INSERT VALUES 按列清单与值序列位置对位取 hint（UI-021），白名单豁免后计数为 0 的 BLOCK 按 OFF 原样。

## 失败与兼容行为

- `displayMaskMode` 旧值兼容：空串哨兵按 `displayMaskEnabled` 推导（true→MASK / false→OFF）；非法串回落 MASK。
- 引擎异常 fail-closed：`MaskMode.OFF` 不进兜底（不扫描=引擎不参与）；其余档异常一律落 `log.preview.maskFailed`。
- `settings.display.mask` 键复用为模式下拉的行标签与搜索身份（不新增幽灵条目，`SettingsPanelSearchableGuardTest` 钉住）。
