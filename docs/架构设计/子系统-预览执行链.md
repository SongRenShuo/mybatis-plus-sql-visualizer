## 职责与边界（Responsibilities and sources of truth）

| Part | Responsibility | Source of truth |
|---|---|---|
| 预览装配生命周期 | 面板编辑器三级降级装配（完整编辑器→内存 PSI→裸 document）与预热等待 | `ui/SqlPreviewPanelEditorLifecycle.kt`（`installAndAssemble` / `createInMemoryPreviewPsi` / `fallbackPreviewDocument`） |
| 降级原因分型 | 七档枚举 + 宽限期翻译（硬失败优先于超时） | `ui/PreviewDegradationReason.kt`（枚举 + `degradationReasonOrNull`） |
| 横幅披露 | 橙色 DEGRADED 横幅、宽限期延迟披露、重试动作 | `ui/DegradationBanner.kt` + `SqlPreviewPanel.kt`（`showDegradedBanner` / `flushDegradedGrace` / `retryPrewarm`） |
| 执行投递 | 反射链三处 catch 点统一收口，结构化错误投递 UI | `execute/DataSourceSelectorResults.kt`（`deliverError` / `buildInfo`） |
| 错误位置提取 | PG `Position: N` / MySQL `at line N` marker 单一性门控与越界钳制 | `execute/ExecutionErrorInfo.kt`（`ErrorPositionExtractor`） |
| 错误分类 | 先归因再处置：CONNECTION/PERMISSION/OBJECT_MISSING/SYNTAX/OTHER | `execute/ExecutionErrorCategory.kt`（`ExecutionErrorClassifier`） |
| 错误呈现 | UI 三入口共用纯文本格式（元数据只显有效值 + 分类出路提示行） | `execute/ExecutionErrorInfo.kt`（`ExecutionErrorFormatter.format`，唯一接线点） |
| 连接类特判 | 连接断开≠未生效：CREATE TABLE 后台探测表是否已建 | `execute/ConnectionErrorClassifier.kt` + `ui/SqlPreviewPanelExecution.kt`（`maybeProbeDdlEffective`） |

## 主运行路径

1. 用户触发预览 → `SqlPreviewPanel` 装配：预热（≤500ms 预算）→ 完整编辑器装配；超预算走 3s 宽限期静默等待，硬失败立即按档披露。
2. 执行：SQL 经数据源选择/方言闸门 → JDBC 执行；异常被反射链 catch 点转成 `ExecutionErrorInfo`（message/sqlState/errorCode/position）。
3. 错误呈现：`deliverError` → UI 面 → `SqlResultPanel.showError(ExecutionErrorFormatter.format(info))`；定位跳转按 `positionChar`/`lineInSql` 三态 tooltip。

## 关键约束

- **无自动 failover**：执行失败不存在自动换数据源重试；切源永远是用户显式动作（方言门禁按钮 / `executeSql(forceChoose=true)` / 回滚弹窗）。
- **分类只给出路，不替用户做决定**：`ExecutionErrorClassifier` 产出类别后仅追加静态提示文案；CONNECTION 不加提示（既有出口已承接），OTHER 不硬给出路。
- **提示不回显参数值**：分类提示是静态文案；错误原文本身含什么就显示什么（这是「错误定位」语义，与展示脱敏是两个面）。
- **EDT/线程两段式**（code-standards S1）：预热在后台，装配收口在 EDT；BGT 不读盘、不碰 Document。

## 失败与兼容行为

- 预热失败七档全部落到同一动作 `retryPrewarm()`；TIMEOUT 档宽限期内产物到达则横幅一次都不出现。
- `ConnectionErrorClassifier` 的排除表（deadlock/access denied/password）防连接误判触发无意义 DDL 探测；`ExecutionErrorClassifier` 复用其判定且继承排除表语义。
- 权限档优先于对象缺失档：`Access denied … to user` 与 `… does not exist` 同串出现时归权限（先修权限才有意义）。
