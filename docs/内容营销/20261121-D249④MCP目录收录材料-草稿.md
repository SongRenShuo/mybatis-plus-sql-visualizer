## 统一母本描述（三份同源）

- 短版（awesome 条目 / 表单单行）：
  > IntelliJ IDEA plugin rendering MyBatis-Plus, JPA, JdbcTemplate and iBatis queries into executable SQL with real parameters, with runtime SQL capture, EXPLAIN and reverse SQL-to-Java, exposed to coding agents via 11 deterministic read-only MCP tools.
- 中版（mcp.so 条目页 / glama 简介）：
  > SQL Visualizer is an IntelliJ IDEA plugin that renders MyBatis-Plus Wrapper chains, mapper XML, annotation SQL and JPA/JdbcTemplate queries into executable SQL with real parameter values — before the server starts. It also captures runtime SQL (parameters, duration, affected rows) directly from the running app, and exposes 11 deterministic read-only `sqlv_*` MCP tools (render, log restore, static checks, EXPLAIN, rollback plan, CRUD, reverse SQL-to-Java) through the IDE's built-in MCP Server, so AI coding agents can work with real project SQL instead of guessing.
- 链接组：仓库 https://github.com/SongRenShuo/mybatis-plus-sql-visualizer · 接入文档 https://sql-visualizer.jvtools.cn/features/mcp · 安装 https://plugins.jetbrains.com/plugin/33633-mybatis-sql-visualizer
