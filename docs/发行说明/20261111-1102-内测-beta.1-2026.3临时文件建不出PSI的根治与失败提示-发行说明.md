# v2026.11.12-beta.1 内测发行说明（2026.3 临时文件建不出 PSI 的根治与按原因给修复入口）

- 版本：`2026.11.12-beta.1`（内测，Gitee 抢先体验通道；Marketplace 不收内测包）
- 发布日期：2026-11-11
- 提交范围：`2026.11.11` 正式版 tag 之后，主线 `87226496` → `43845bb7`（T-ExecPsiGate 十三轮），另含 `48b6f04f`（T-ConsoleFlushAlign）与 `9219ca61`（T-OBExplainFormat）
- 兼容 IDE：2024.3（243）/ 2025.3（253）/ 2026.2（262）/ 2026.3（263）

## 修复

**Mac / UOS 上点「执行 SQL」恒报「创建临时 SQL 文件失败：findPsi」——根因定位并修好。**

反编译 2026.3 平台（本机 `IU-263.7307.200`）确认：`SingleRootFileViewProvider.createFile()` 新增了 `shouldCreatePsi()` 闸门，`AbstractFileViewProvider` 里的判据是「父目录拿不到 `PsiDirectory`（不在内容模型里、或被排除/忽略）且不在库源码/库类里 → 直接不建 PSI」。于是 `findFile` 返回 null，而 `VirtualFile` 本身完全有效——这正是用户五元组的样子（`vfValid=true / fileType=SQL / mappedLang=null`）。243/262 没有这道闸门，所以本地一直复现不出来。

修法按平台同一条判据来，不再靠猜：

- **执行侧**：失败时先把原因和修复入口摆给用户——命中「文件类型」忽略规则直达该设置页，被 `.gitignore` 忽略直达那个文件，方言问题直达 SQL 方言设置；另给一颗「改用项目根落点重试」，用户点了才把临时文件写到 `<项目根>/.sql-visualizer/exec/`（自带 `.gitignore`，不进版本控制），并记住该选择，本会话后续执行直接走备用落点。兜底不抢在提示前面。
- **预览侧**：预览的失败形态是降级而不是阻断，所以自动改用 `<项目根>/.sql-visualizer/preview/` 保证预览与补全照常可用，同时在面板给一条**只出现一次**的说明与修配置入口。

同族两处一并补齐：映射到的方言建不出 SQL PSI 时先钉一个已知可用的方言再试；临时文件的 VFS 条目失效时先重新定位取新条目再建 PSI（后者的依据是两组实验——并发外部写 344 次零 null、坏映射连取 5 次恒抛 CCE，把「本地能造出 null 的唯一路径」收窄到 vf 失效）。

## 新增

- **失败文案按原因给可点入口**：三种成因在报错上一模一样，修法却完全不同，现在每种都指到该去的地方；判定是纯函数，忽略类原因压过方言类，不会把人送到错的设置页。
- **失败文案带上可定位的诊断项**：vf 有效性、文件类型、映射方言、继承方言、平台实际选中的语言、这些语言各自能否建 PSI、是否被排除或忽略、`ide.hide.excluded.files` 取值、IDE Build 与绝对路径。用户不能提供日志时，截一张报错图就能定案。
- **控制台 MyBatis / Hibernate 日志补齐静默冲刷**（T-ConsoleFlushAlign）：对齐 JdbcTemplate，会话结束前的最后几条 SQL 不再等下一次执行才上屏。
- **OceanBase 的 EXPLAIN 计划树给出索引建议**（T-OBExplainFormat）：与 MySQL 同口径。

## 真机复现（Windows）

用户在本机 `IU-263.7307.200` 上勾 `ide.hide.excluded.files`、重启、把 `.idea` 标为 Excluded，demo 项目复现出与 UOS / Mac **一字不差**的五元组；`File Types` 的忽略模式同样能复现。两种形态对应平台判据的两条分支（`isExcludedFile` / `isUnderIgnored`），本版对两条分支都成立，不依赖 Registry 取值。

## 已知边界

- `shouldCreatePsi` 还有一条 `isIgnored()` 分支（文件被 IDE 标成 ignored），本版的落点判定走的是 `PsiManager.findDirectory` 那条，未单独覆盖；若真机仍有残留，把判定换成「写探针文件试建一次 PSI」即可。
- 「项目结构」页在 243 / 2026.3 已无稳定公开入口（`ProjectStructureDialog` 已移除），所以「目录被排除」那一档只给原因、不给设置页链接——宁可指不出，也不指错。
- 预览侧仍是自动兜底（设计取舍：降级不宜阻断），只补一次性告知，不提供「切回 `.idea` 重试」按钮。
- **本次未跑 `releaseGate` 全量门禁与 `dialectExternalVerify` 方言矩阵**（内测版走定向 + 反向验证；全量交正式版前那一轮）。

## 兼容性

- 最低 2024.3（`sinceBuild=243`）；无平台 API 面新增，不改用户既有配置。
- 新版会在需要时于项目根创建 `.sql-visualizer/`（内含 `exec/` 或 `preview/` 与一份 `*` 的 `.gitignore`），不进入版本控制。

## 安装

- Gitee 发行版附件 `mybatis-plus-sql-visualizer-2026.11.12-beta.1.zip`，IDE 内 Settings → Plugins → 齿轮 → Install Plugin from Disk。
