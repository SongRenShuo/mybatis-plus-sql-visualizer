# v2026.11.10-beta.3 发行说明（内测）

- 发行：2026-11-10
- 版本：`2026.11.10-beta.3`（沿用 11.10 内测线；`beta.3 > beta.2` 可被 IDE 更新检查识别）
- 范围＝`v2026.11.10-beta.2` 发行包之后的全部用户可见增量：**iBatis 四项真机缺陷修复**（调用行与方法定义行的多余预览图标、jdbcType 未驱动回填引号、XML 侧 Ctrl+Click 跳不回 DAO）

## 修复

### 1. XML 语句 id 上 Ctrl+B / Ctrl+Click 跳不回 DAO 调用点

`User.xml` 的语句 `id` 上按 Ctrl+Click，平台报「Cannot find declaration to go to」——而反方向（DAO 调用行 → XML 语句）一切正常。

根因不是分支没合，是这条路径**从来没接过平台的 GTD 管线**：Java→XML 有专属 `GotoDeclarationHandler`，XML 侧只有 gutter 箭头走词索引；`psi.referenceContributor` 只给 `refid` / `resultMap` / `parameterMap` 造引用，语句自己的 `id` 没造任何引用。

现新增 `IbatisXmlStatementGotoDeclarationHandler`：认 `id` 属性值与语句起始标签名 token 两个锚，目标集复用券 B 的词索引（`IbatisJavaCallSites` 扩出 `findAllCallLiterals`，一条语句被多个 DAO 方法调用时平台弹候选列表，上限 20）。非 sqlMap 语句位置返回 null，其它文件的原生跳转零变化。

### 2. DAO 方法定义行仍多一枚点不开的预览图标

上一版只让 JdbcTemplate 的**调用行**通道让位；`UserDaoImpl` 的**方法定义行**（`public List<User> selectAll()` 那类）仍亮着一枚预览图标，点开什么都没有。

来源是「方法定义锚点」provider（`StringSqlMethodGutterLineMarkerProvider`）：它锚方法签名、扫方法体里「方法名在白名单 + 有字符串实参」的调用，`client.queryForList("User.selectAll")` 同时满足，接收者 `SqlMapClient` 又归类为 UNKNOWN 不被家族排除，于是被当成「方法体内有 SQL」。点开它按 SQL 解析方法体，statementId 不是 SQL，必然空结果。

现同一个让位判据（`IbatisCallYieldGate`，纯语法 O(1)）在方法定义锚点也生效；真正的 JdbcTemplate 方法体不受影响（有正向对照用例）。

### 3. DAO 调用行多出一个 SQL 预览图标

`return client.queryForObject("User.selectById", id);` 这类调用行上出现两枚图标。根因是 `JdbcTemplateMethodDetector` 的方法名白名单（`queryForObject` / `queryForList` / `queryForMap` / `update` / `delete`）与 iBatis `SqlMapExecutor` 的入口名完全重叠，而它只判方法名、不判接收者类型，于是同一次调用被两条 gutter 通道同时认领；更本质的是语义错位——该图标点开是把首个字符串实参当 SQL 预览，而这里是语句 id。

现按家族排除制让位：iBatis 的语句 id 调用行只保留跳转箭头、零预览图标。

### 4. `#x:jdbcType#` 填值后没有引号

`WHERE EMAIL = #email:VARCHAR:0#` 填 `11212` 预览出 `= 11212`（缺引号）。服务层此前从未构造 `paramHints`，面板按「纯数字 → 裸渲染」的启发式走。

现按 jdbcType 映射到既有 `ParamKind` 六类：字符串族恒引号、数值族不引号、时间族先试 ANSI 类型字面量再回落引号；映射不到的类型不产出提示，维持既有启发式（宁缺勿错）。

## 已知边界

- 词的索引上限：`findAllCallLiterals` 最多返回 20 个调用点，超过部分不进候选列表。
- Kotlin DAO 调用形态未覆盖（两个方向的 handler 同口径，Java 侧已验）。
- `<selectKey>` 内的 `#x#` 参数会进参数名序，但没有输入行（`keyProperty` 回写目标不是 `?` 参数）。
