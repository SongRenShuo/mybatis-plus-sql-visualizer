## 这一版有什么

### 预览打开更快，大工程不再卡死

- 大工程打开即卡死 / 预览白屏的问题已修（2026.11.12 在 Linux 上的主诉）：调用点预取不再占着读锁跑索引检索，预览解析加了单次 800ms 上限超时退占位骨架；升级后会自动修好被旧版本写坏的工程文件，数据源切换记忆也不再写坏它（`39d4b2706` / `9f712eb78` / `e08280a00`）。
- 打开 mapper XML 时就在后台把预览装配算一遍（只算不建界面），本会话第一次点开预览的冷启动成本挪到了点击之前；每文件只预热一次、每项目至多 2 个文件（`da6ccb982` / `589be7dcd`）。
- 带 `Example_Where_Clause` 的预览不再同步等待动辄数秒的调用点检索：首次打开立即出占位骨架，条件反推在后台落地后自动补上真实条件（`bccc3fd8e`）。
- 打开预览不再顺带把整个工程短暂拖进重索引（也就不再拖累补全）：执行控制台改在你第一次执行（或切换数据源）时才准备，设置页可调「惰性带入口 / 惰性无入口 / 打开即准备」三档口径（`02bccd045` / `70694995d` / `bcf1529da`）；方言映射写入加本地备忘，探测不可用时不再每轮重写（`e6d26cca7`）。

### 表名反查索引大幅提速

「SQL 表名 → 实体类」的反查原本查一个表名就把工程内所有类扫一遍，且缓存挂在 PSI 版本上、预览自己写文件就会把它顶掉，导致每次打开都在重扫（2500 表 / 16804 类的工程一趟 3.8 秒）。这轮连做五步：一次扫描建「表名 → 类」全表索引（任意表名 O(1) 命中）、建索引挪到后台线程（点击至多有界等 800ms）、候选源改走平台注解索引（16804 类 → 812 类、稳态重建 4737ms → 187ms）、联表候选改「缓存优先 + 后台预热」（点击链 0~2ms）、启动期重复建 7 次收成 1 次且回补扫描按结构版本缓存（`c96759946` / `e99750f53` / `ee8c69e9a` / `59e58ab93` / `589be7dcd`）。

表名反查按 ORM 分源查注解索引：JPA 实体（`@Table(name=…)`，`javax` 与 `jakarta` 两代）同样适用；注解索引未命中再退回一次全项目推断，覆盖 MBG / iBatis / Kotlin / 自定义映射。顺带修了 `@TableName` 兜底反查把全限定名传给以简单名为键的注解索引、从未命中过的问题（`231cd2065` / `47634d4c5`）。

### 预览判型说清依据，不再误判

- 预览面板会说清这条语句类型是怎么判出来的：顶部标出依据是哪一行的哪个调用；同一个 wrapper 被多处复用时可以点「语句」下拉切换查看（`1b3af3ec5`）。
- 一个 wrapper 在多处被复用、在重新赋值那一行点预览、或遇到 `list.remove(...)` 这类 JDK 容器上的同名调用时，查询链不再被误判成 UPDATE/DELETE；判型依据按锚点位置单选，重新赋值即分段（`1b3af3ec5` / `3731e2eed`）。
- 实体更新（`update(entity, wrapper)`）的 SET 各列可以逐列填值，不再被一个输入框一次性填满（`90e494b33`）。

### SQL 补全一组修复与提速

- 敲 `DEL_F` 能补出 `DEL_FLAG`：列名候选同时收录原名 / snake / UPPER_SNAKE 三种形态；插入形态跟随输入大小写风格（`3813d832c` / `c5646b239`）。
- 删掉几个字符后再补全，列名照常给出（读编辑器现值修 stale PSI）；MBG 查询的列名补全不再给出 `xxx_example` 假列；mapper 接口与泛型都解析不到时改按 FROM/JOIN 表名反查实体兜底（`11a8c097` / `7a0d2a101` / `866c6e651`）。
- 改了实体上的注解或字段立刻生效（实体解析缓存改按类正文指纹判据，原来 60 秒时间窗内一律复用旧值）；补全解析加缓存与计数埋点，打开文件时后台预热补全上下文（`ad292a169` / `d29bec9d5` / `acf503f83`）。

### 提示更主动也更省心

- 方言推断走到死路（既无数据源、配置、依赖坐标也无语法特征）时会主动提示一次，说清「按 MySQL 兜底」，并可直达设置或本项目不再提示；标题不写 MyBatis——插件支持面不止它（T-NotifyTune 券 A）。
- 「已捕获到第一条 SQL」的引导改成每台机器只提示一次（原来重启 IDE 就再弹），日志窗已开、自动展开、开关关闭三个场景直接跳过；设置页两条一次性提示都能单独关掉（T-NotifyTune 券 B）。
- 预览里的 INSERT 列名提示让位 IDEA 自带的同类提示，不再每个值前重复显示两枚；没装 DatabaseTools、Community 版或检测不到时本插件照旧提示（`5f054e4c8`）。

### 日志清净与顺带修复

- 数据源切换按钮不再每次刷新打 2 条平台 WARN（模板呈现镜像改走平台 `copyFrom` 通道，`be43c4bf6`）；退出 IDE 不再报插件内存泄漏（面板销毁兜底释放编辑器与补全监听，`a02ad51cf`）；关预览面板不再刷平台 Keymap 告警（换全局动作前先置空快捷键集合并走公共注册 API，`3ce4b7c54` / `e00e779b5`）。
- 热更新（免重启装本地包）后设置页点「确定」没反应的问题已修：更新前自动关掉正开着的设置窗口并提示重启（`29e872abe`）。
- 本地安装包目录重启后不再丢失：选好或填好目录立即写盘（原来只有点「确定」才落盘，而选目录→检测→安装的流程不会经过确定）；删空目录同样被记住，路径不合法时不保存并在状态行说明原因（`59a9d1baa`）。
