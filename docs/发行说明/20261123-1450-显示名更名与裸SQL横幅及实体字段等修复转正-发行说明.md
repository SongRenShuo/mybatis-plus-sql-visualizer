## 这一版有什么

**裸 SQL 形态也有 `${}` 直替风险横幅了（T-DollarPlainSqlBanner，`15a166f43` / `8ceced35b`）**：独立工作台或弹窗里直接粘贴的纯 SQL 含未转义的 `${...}` 时，结果区顶部会给出「预览含 N 处直接替换」的信息级提示（可点 ✕ 本次会话不再弹）——此前该提示只对 mapper XML 语句生效，裸 SQL 只有执行前确认与复制注释两道防线，粘贴后一眼看不出这段 SQL 里有直替拼接面。计数口径与既有扫描一致：SQL 字符串字面量与注释里的 `${}` 算字面量不计，`\${` 转义不计；mapper XML 形态的行为不变。

**插件显示名更名：SQL Visualizer → MyBatis SQL Visualizer（T-D244 搜索关键词决策 B1 案，`acd4c8bdb`）**：Marketplace 后台展示名与包内 plugin.xml `<name>` 同步更名，补上名称字段对 mybatis 系搜索词的匹配缺口——官方排名公式里名称字段此前对 mybatis 系词零匹配，是搜索可见性的主缺口。插件 ID / xmlId 与界面内品牌文案（错误报告、导出头、二维码说明、设置页标题）不变。

**Marketplace 描述关键词批（D246，`de2f03f7a`）**：描述首行改为 40 字符关键词句，补入 iBatis / GoldenDB / openGauss 词面与 slow query / execution plan / sql formatter 精确短语，提升商店搜索与 GEO 推荐命中。蓝本列举中的磐维 PanWeiDB 经 Dialect.kt 对账不存在独立格式化方言档，按实际改列 openGauss，方言数字 15 不动。

**描述补增强捕获国产库覆盖句（`9e3493389`）**：中英描述补入增强捕获已适配的国产库清单（达梦 / 人大金仓 / GaussDB / 磐维 PanWeiDB / OceanBase / GoldenDB 等）；自定义页方言列举同步对账——磐维不占独立格式化方言档，移出 15 种列举、改为增强捕获专项支持表述。

**实体字段识别对齐真机语义（T-EntityFieldStaticHidden，D254，`8b2b15e13`）**：预览里静态常量（`TABLE_NAME`、日志器等）不再被当成表列；父子类同名字段只保留子类声明，`@TableLogic` / `@TableId` / `@Version` / `@TableField` 随子类字段生效（不再总是取父类那份）。参数类型提示与 XML 属性补全同步去噪（`serialVersionUID` 不再出现在候选里，`@类@` 静态成员补全不受影响）；父类文件修改后预览立即按新字段解析，不再沿用旧缓存。

**`setEntity(entity)` 预览的每个条件可以独立填值（T-SetEntityParamKeyCollision，D255，`33661f779` / `f9aa1b375`）**：此前实体全列展开的所有条件共用一个匿名参数键——左侧参数栏改任意一个框，右侧整段 WHERE 都变成同一个值；点「清除」也只清掉第一个框，要关掉重开预览才恢复。现在每列独立参数键（`query.id`、`query.password`…），改哪个框只影响对应条件，清除立即清空全部条件框；`setUpdateEntity` / `updatable(entity)` 的全列 SET 同步修正。

**无数据源执行失败后结果区不再是整块绿空白（T-NoDataSourceGreenResultPanel，D253，`4a2d08978`）**：独立工作台粘 SQL 点执行、确认框点「是」后，若项目没配数据源，结果区会变成整块纯色空白（真机呈亮绿）。根因是确认框期间编辑器被释放、失败链无重渲染，结果区透出父级主题底色。现在结果区容器自带不透明主题底色，失败收口时在无控制台且编辑器空的情况下用最近结果重建预览编辑器，格式化 SQL 仍在；有数据源执行路径不变。
