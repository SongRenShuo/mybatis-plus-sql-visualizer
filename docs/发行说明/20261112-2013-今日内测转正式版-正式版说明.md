## 这一版有什么

### MBG Example 预览能按调用点还原条件

beta.1 起 MBG 生成的 Example mapper 可以预览：从 mapper 方法的调用点找到 example 变量，在同一方法体里逐个解析 `and*` / `or*` 调用、读 `addCriterion` 的常量，`${criterion.condition}` 拿到真实列名与操作符，产物从残缺骨架变成可读 SQL（`6fb76205` / `2d8798a9` / `6212f24e0`）。

beta.3 把真实大工程里剩下的四处缺口补齐：`ReferencesSearch.findFirst()` 在真机恒返回空、同一方法里两次 Example 查询的条件被并进同一条 WHERE、`example.or()` 的条件被拍成 AND、混 kind 时区间条件少一个占位符；同时补上「命中落在实现声明处或方法引用上时继续找真正调用点」与「XML 语句里选中文字后按快捷键误报未找到」两条入口修复（`85e09cab9` / `bdc1f89ab` / `b12ccf8cc` / `875c942f8` / `ab9a8c308`）。没有调用点的删除 / 更新语句，骨架也统一收敛到 `singleValue`，固定为 `WHERE ( {{criterion.condition}} ? )`，不再退化成连占位符都没有的形态（`0d52f8e1d` / `405aee737` / `1a327d5f8`）。

### 预览左栏可填可解释

- 按条件文本直接生成可填行：`staff_login LIKE 值`、`create_time between 值/结束值`，行名就是条件本身；`__frch_criterion_N` 的编号按首次出现顺序与注入条件对齐，不再显示「条件 2 值」这类读不懂的名字（`c33f9542c` / `0d52f8e1d`）。
- 点「清除」显式回收已播种的展开项键，不再残留 `BETWEEN '11' AND ?`（`c33f9542c`）。
- 条件对象容器（`oredCriteria` / `criteria.criteria`）的值框一律只读并说明去哪里填；已还原元素对象的集合不回显历史值，改为占位「已还原 N 项」；分支没走到的值框给灰字「本轮未展开：填了不影响产物」（`89c74c663` / `f3e4f2fca` / `e9b140fb1`）。
- 标签列宽按「每行文本 + 该行内边距」取最大，长参数名标签随视口宽度自适应；真正超宽时走插件自己的中段省略，不再被 Swing 截成 `criteria.crit…`（`e9b140fb1` / `2096fa2f5`）。

### 提示跟着本轮产物走

- XML 重渲染分支补 `updateMeta`：改完勾选后横幅立即按本轮产物重算，产物里已经没占位就不再挂着「预览未完整还原」（`e9b140fb1`）。
- 新增 `fullTableWriteRisk` 纯函数与 `WRITE_RISK` 横幅类别：产物变成没有 WHERE 的全表删除 / 更新时顶部直接警示，优先级高于渲染警示；判据只看未回填产物，参数值里出现 `where` 不会污染判定（`e9b140fb1`）。

### 首次打开更快

- 打开 mapper 文件时，gutter 渲染对 `select` 且 `parameterType` 以 Example 结尾的语句后台预取一次条件解析（失败记忆、单条在途两道护栏），真机首次点开 `m2=1ms`、装配 104ms，同语句再点 30ms（`34488db41` / `773421955`）。
- schema 预热链加 60 秒去重窗口：同一张表窗口内只尝试一次，窗口外放行以保留「数据源晚连接后自愈」，不再每次打开都重扫 15 个数据源（`20cc719dd`）。

### 预览与复制不再改坏 SQL

- 多字符运算符按最长匹配整体分词，`||` `::` `<=>` `->` `->>` `&&` `<<` `>>` `:=` `@>` `<@` `!~` `~*` `=>` 一次修好普通 / 关键字换行 / 竖向排列三条格式化路径；`#>` `#>>` 与 `?|` `?&` 因与 iBatis `#x#` 闭合界、`?` 占位符记账冲突保持原样（`17eabc420`）。
- 复制可执行 SQL 时产物头部加一条带计数的注释，说明哪些是待替换的 `{{…}}` 预览占位，分享面板一并接上（`2e553316`）。

### 执行失败不再只剩红字

- 反编译 2026.3 平台确认 `shouldCreatePsi()` 问的是父目录，归因改为取文件与父目录的并集；成因随失败文案本身传递（尾部 ` [hint=XXX]`，UI 渲染前剥掉、日志与「复制错误信息」保留），不再被预热链清空或并发覆盖（`a34aef25` / `c46d5907` / `23457844` / `908623ed` / `61205cf2` / `1a5ce405` / `7ab0d5335`）。
- 目录能否建 PSI 的判定改为每次现探，改了排除或忽略设置后下一次打开立即生效；失败行给原因说明 + 蓝色「改用项目根落点重试」+ 蓝色「打开文件类型设置」，面板五处执行回调统一走同一条提示（`43845bb7` / `cef8545e`）。
- 按用户定案：落点不自动改写（`.idea` 仍是默认，失败要人点），也不引导用户改 `.gitignore`。

### 顺带修复

- iBatis DAO 调用行可直接预览 SQL（`8ad491b8`）；裸 `#name#` 参数按 `parameterClass` 字段类型决定引号（`cb4ec1ed3` / `5a2e0419d`）。
- 关于页新增本地安装包目录，放入插件 zip 即自动识别最高版本并直接安装，「打开」改用系统文件管理器 API（`f0c7c30d5` / `202c5dfcb`）。
- 数据源列表末尾新增「添加数据源…」，并移除了点了会报错的「unknown」死项（`c728c8058`）。
- 2026.3 上打开数据源列表不再刷一条插件错误，日志里不再出现 `getChildren(null)` 告警（`ab9a8c308`）。
- OceanBase 的 EXPLAIN 计划树给出与 MySQL 同口径的索引建议（`9219ca61`）。
- 控制台 MyBatis 与 Hibernate 日志补齐静默冲刷，会话结束前的最后几条 SQL 不再等下一次执行（`48b6f04f`）。
