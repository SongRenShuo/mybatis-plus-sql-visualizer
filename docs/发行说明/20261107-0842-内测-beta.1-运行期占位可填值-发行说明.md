# 🎉 SQL Visualizer v2026.11.7-beta.1（内测版）

> 发行说明留档：对应 Gitee 发行版 **v2026.11.7-beta.1**（标签 `2026.11.7-beta.1`），附件 `mybatis-plus-sql-visualizer-2026.11.7-beta.1.zip`。
> 通道：**Gitee 内测版**（Marketplace 不收内测包，正式版转正时另行上传）。
> 范围＝`v2026.11.6-beta.2` 之后的全部用户可见增量：运行期拼接的 SQL 从「只能看注释占位」变成「可以自己填值」，加开发者模式的预览更新通道、更新包 404 的友好提示，以及热替换被平台拒绝时的确定原因。

这一版的主题是「把只读的预览变成能改的预览」。上一版把运行期拼接的片段收口成一条合法的 `/* 运行时值: … */` 块注释，括号和引号不再被吃掉，但用户拿到的仍然是一句跑不了的话——现在参数区会为每个占位建一行，填完就是可执行 SQL，四条下游链路取的是同一份文本。

## ✨ 新增

**运行期拼接的 SQL 可以自己填值（T-RuntimeSlotFill，券 A / B / C，`745cfe3c` / `15de3ede` / `36dc8da3`）**

JdbcTemplate、自定义 DAO、Hibernate 三条字符串 SQL 通道里，凡是静态不可求值的片段，预览中都会出现 `/* 运行时值: … */` 占位。此前这些占位只是说明，用户没法把它变成能跑的语句。现在分三券落地：

- **券 A（占位身份与结构化模板，`745cfe3c`）**：给每个占位一个稳定身份 `rtN` 与结构化模板——单值、循环（带展开模板）、三元（真 / 假两支原文）、可选片段各成一类，模板与展示文本分离。顺带修掉一个旧缺陷：**被括号包住的三元此前不被识别为三元**，`(status == null ? "" : " AND status = " + status)` 这种写法整段退化成普通运行时值，现在能拿到「两支」信息
- **券 B（回填引擎，`15de3ede`）**：占位、`?`、`:name` 三类参数收成**一次前向扫描 + 区间记账**，值一旦产出即原子落位、不再被后续扫描二次替换——实测把三步串行跑会误伤两处 `:name`（值里自带的 `:nm`、未回填占位注释里的 `: y`），区间记账是为此加的。值按字面量渲染，`O'Brien` → `'O''Brien'`
- **券 C（面板接线，`36dc8da3`）**：参数区为每个占位建一行「运行时值 #N · 类型」，控件按语义分——单值（自动 / 字符串 / 数字 / 布尔 / NULL）、循环（填一组值，按你代码里的模板展开成 `(id='1' or id='2' or id='3' )`）、三元（选真 / 假分支）、可选片段（勾「包含这段」）。**填值后预览 / 复制可执行 SQL / 导出回放脚本 / 直接执行四条链路取的是同一份文本**，不会再出现「预览填了、复制出来还是注释」

**留空即原样**：不填值时四条链路与改动前逐字节一致（用例 `testEmptySlotValuesKeepFourChainsByteIdentical` 钉住），所以这个能力对既有行为零影响。

**开发者模式：预览更新通道（T-DevUpdateChannel，`cda8f3e5`）**

设置页的构建号连点 7 次后，更新区多出一个「检测更新（开发版）」按钮，读取 `update/preview.update.json`；正式「检查更新」仍读 `update/update.json`，两者互不干扰。

- 状态行标「（开发版通道）」，按钮 tooltip 写实际读取的 URL
- `-Dmpvs.update.previewManifestUrl` 可换源；换源到本地清单服务器时预览地址同源改名，只需多一条路由
- 解锁只在本会话内存里（不写配置、不弹窗，只改构建号 tooltip），`-Dmpvs.update.devMode=true` 可直通（启动时读一次，需重启生效）
- 语言切换重建面板后按钮仍在（可见性按解锁态重算，不是在解锁那一刻一次性点亮）

## 🛠 修复

**下载更新包遇到 404 / 410 不再甩出一串 HTTP 异常（T-DevUpdateChannel，`cda8f3e5`）**

清单里的 `downloadUrl` 常指向尚未建仓的 Release 附件（预览清单最常撞上），旧口径把 `HttpStatusException` 原文塞进「更新失败：{0}」，看着像插件坏了。现在 404 / 410 单独判为「未发布」——设置页写「该更新包还没有发布（HTTP 404），请稍后重试，或到发布页手动下载」并露出既有发布页兜底链接，日志只记一行带 URL 与状态码的 info；启动通道给同文案的 WARNING 通知。网络不通、非法 zip、安装失败等其余失败仍是普通「更新失败」，不扩散。

**更新被平台拒绝时给出确定原因，不再只说「平台没给原因」（T-HotSwapUnloadSafety，`eff3bbd7`）**

旧版探测入口只返回真假，插件在拒绝时统一写一句「platform gave no reason」，而平台其实在同一份 `idea.log` 上一行就点名了确切项。现在按「非动态 EP 事实表」补位，日志直接写出「本插件扩展了 `com.intellij.sql.dialect`，平台自 baseline 253 起才把它标为动态，当前 243」并说明后果是重启生效。

同一轮取证确认了一条**平台边界**（已写进已知边界）：`dev-support/probe-platform-ep-dynamism.py` 对发行 zip 走 HTTP Range 只抽 `database-plugin.jar`，四处平台实测——

| 平台 | `<sql.dialect>` 声明 | 可否免重启热替换 |
|------|---------------------|-----------------|
| 243（IU-2024.3.7.1） | 2 处，0 处 `dynamic` | 不可，只能重启生效 |
| 253（IU-253.33514.17） | 1 处 `dynamic="true"` | 可 |
| 262（2026.2 最新发行） | 1 处 `dynamic="true"` | 可（与用户真机一致） |
| 263（IU-263.7307.200） | 1 处 `dynamic="true"` | 可 |

时间线值得记一笔：`<sql.dialect>` 自 2026-10-14（`6199a2a7`）起注册，而 2026-09-11 那次「免重启实测」在注册之前——能力是后来退化的，不是从没支持过。

## ⚙ 改进

- **循环内拼接的降级占位带上了「追加的是什么」（T-RuntimeConcat-Polish，`10441d9b`）**：上一版把循环内的运行期拼接降级成一条 `/* 运行时值: 循环内追加，运行时重复执行 */`，用户看得到「会重复」、看不到「重复的是什么」。现在占位带上循环体的**模板摘要**——只取循环体里 `append` 的字符串字面量片段，变量引用 / 方法调用 / 三元条件一律替换为 `…`，三元两支以 ` / ` 分隔：`for` 里按 `k == 0 ? "id='…' " : "or id='…' "` 拼条件的样本，占位变成 `/* 运行时值: 循环内追加 id='…' / or id='…'（运行时重复） */`。摘要走占位那套清洗（注释结束符拆开、引号换安全同形字符、空白折叠、长度上限），Java 源码不会漏进预览；循环体取不到任何字符串字面量时回落原文案，不猜内容

## ⚠️ 已知边界

- **循环值的分隔符**：逗号与换行都是分隔符，项内含逗号会被拆成两项，这类值请每行一个
- **可选片段没有可填位置时**：需填任意非空文本（不影响产物），或显式取消勾选；只有「填了值」或「显式取消勾选」才算一次动作
- **占位值不进参数历史与参数预设**：切预设时占位值会丢（与「不跨会话持久化」同向的取舍）；「导入参数」按 `paramValues` 的来源匹配，占位 id（`rtN`）会被报成未匹配，不静默失败
- **互斥 if / else 两支都追加的形态（PAIRED）**：当前只有说明性注释，两支内容在拼接期已丢弃，没有可填的值对象
- **模板里的 `%s` 是字面标记**：源码本身含 `%s`（如 `LIKE '%s%'`）时回填会多认一个占位，此时按「模板 `%s` 个数 = 预期值个数」校验并明确报出
- **243 上热替换只能重启生效**：`com.intellij.sql.dialect` 在 2024.3 是非动态 EP（2 处声明、0 处 `dynamic`），扩展它的插件不可被动态卸载；253 / 262 / 263 上该 EP 已是 `dynamic="true"`，免重启可用
- **开发者模式按钮只在当前会话可见**：重启 IDE 后需重新连点 7 次，除非用 `-Dmpvs.update.devMode=true`
- **更新包未发布时只能手动下载**：404 / 410 会给友好提示与发布页链接，不会自动重试
- 本版为内测通道版本，Marketplace 稳定通道不上传
