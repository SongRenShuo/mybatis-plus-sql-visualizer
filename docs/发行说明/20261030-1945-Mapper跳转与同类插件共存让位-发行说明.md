# 🎉 SQL Visualizer v2026.10.30

> 发行说明留档：对应 Gitee 发行版 **v2026.10.30**（标签 `2026.10.30`），附件 `mybatis-plus-sql-visualizer-2026.10.30.zip`。
> 范围＝自 v2026.10.29 正式版发行包之后的全部用户可见增量（本轮为单项修复版）。

自 v2026.10.29 后的正式版。两处修复：**装了同类 MyBatis 导航插件的工程里，Mapper 双向跳转图标和对方的跳转箭头叠在同一行**（补上默认开启的让位开关）；以及 **v2026.10.29 引入的一处回归——方言冲突时预览悬停的证据面丢掉候选数据源 UUID**。

## 🛠 修复

**方言冲突时预览头部的候选数据源证据丢失（回归，v2026.10.29 引入）**
- 现象：预览头部显示方言冲突 / 兼容回退时，把鼠标停在 meta 行上，证据面只剩「候选标识（UUID 或未识别临时键）：无精确绑定」——上游其实算过候选数据源，UUID 清单在面板里被丢了
- 根因：v2026.10.29 引入的 `withResolvedDialect` 只在「已有决策**且**渲染方言在场」时才原样返回。冲突/不可用决策的 `dialectName` 是 null（冲突本来就没有单一结论），于是这条判据不成立、面板重新算了一遍，把带证据的决策替换成了兜底决策
- 修复：**以上游决策为准**——决策在场即不重算，仅在决策知道方言名而渲染方言缺席时用该名字回填渲染方言（渲染端与临时文件映射端仍取同一值）；候选 UUID、来源与置信度随决策一并保留
- 验证：`SqlPreviewPanelMetaHintTooltipTest` 7/0（该例原本全量红）、`SqlPreviewPanelUiTest` 6/0、方言决策链 54 类 716 例 0 失败

**Mapper 双向跳转图标与同类 MyBatis 导航插件叠在同一行（T-MapperNavCoexistYield）**
- 现象（用户真机报障）：mapper XML 的 `select` / `insert` / `update` / `delete` 标签行、以及 Mapper 接口方法行，会出现两个跳转图标——一个是 v2026.10.28 合入的双向跳转，一个是对方自带的跳转箭头，同一处点哪个都别扭
- 根因：这两个 provider 只接了全局总闸（`showGutterIcon`）与按来源分组开关（`GutterGroups`），**没有任何同类插件共存判定**。而全仓原有的「第三方插件在位即让位」判定在 T-XmlGap W1 随注入**区间互补**一起废止了——那对注入/着色面是对的（在位 ≠ 覆盖，必须逐区间问），但 gutter 图标不是区间问题：同一行两个来源各画一个**都合规**，纪律是让位。这条纪律（2026-09-24 你确认过的「双让位」）一直没落到 gutter 面
- 修复：检测到同类 MyBatis 导航插件处于启用状态时，本插件这两个跳转图标不产出（XML 语句行 ↔ Mapper 接口方法行）；其余 gutter（SQL 预览、注解 SQL、JPA/HQL、JDBC、Wrapper 链、通用 XML 内嵌）不受影响，与对方不撞车
- 探测走全反射（`PluginManagerCore.getPlugins()` → `PluginDescriptor.getPluginId()` / `isEnabled()` → `PluginId.getIdString()`），**不静态引用** `PluginId` / `PluginManagerCore`——该组 API 在 2025.3~2026.2 有形态漂移，编译基线 2024.3 与运行 IDE 2026.2 双端直接引用有链接风险
- 任何反射失败按「不在位」处理并只 WARN 一次：不确定时不删功能，宁可多画一个图标；结论按 IDE 生命周期懒缓存（插件启停本就要重启）
- 同类插件前缀是**列表**（当前登记 `com.ccnode.codegenerator`，覆盖 MyBatisCodeHelperPro 及其 Marketplace 版与历史 id 变体），将来收更多同类插件只加前缀、探测逻辑不动

## ✨ 新增

**设置项「与同类 MyBatis 导航插件共存时让出 Mapper 跳转图标」（默认开）**
- 位置：设置 → 工具 → SQL Visualizer → 界面与操作，紧跟「在代码左侧显示预览 SQL 图标」与各来源分组开关之后，接入 IDE 设置搜索
- 默认开＝让位。关掉后即使对方在位也强制显示本插件图标；两套图标同处时由用户自己取舍
- 关掉只影响「跳转图标」这一件事，不改变任何 SQL 渲染、采集或执行行为

## 兼容性

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；EXPLAIN、执行 SQL、表右键入口与 Database 原生图需 Ultimate；MCP 能力需平台 MCP Server）
- 插件 ID 与升级链路不变，v2026.10.29 用户可直接覆盖升级
- 设置项总数 +1（新增让位开关，默认开）；未装同类插件的用户看不到任何行为差异
- 装了同类插件且习惯本插件跳转图标的用户：把「与同类 MyBatis 导航插件共存时让出 Mapper 跳转图标」关掉即可两者共存

## 📦 安装

1. 下载附件 `mybatis-plus-sql-visualizer-2026.10.30.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. Marketplace 用户：市场页直接更新；Gitee 通道用户：设置页「更新」分区检查更新即自动收到本版，自 v2026.9.11 起经该通道更新免重启即时生效
