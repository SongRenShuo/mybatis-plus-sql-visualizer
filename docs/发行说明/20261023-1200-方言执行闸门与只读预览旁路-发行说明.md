# 🎉 SQL Visualizer v2026.10.23-beta.1（内测版）

> 内测版留档：Gitee 抢先体验通道发行版，标签 `2026.10.23-beta.1`，附件 `mybatis-plus-sql-visualizer-2026.10.23-beta.1.zip`。
> 基线为正式版 v2026.10.16，本内测版承载其后的全部增量（含此前只在 dev 批次内完成的第十九轮能力）；对外更新清单只保留最新一个 beta 版。

自 v2026.10.16 正式版后的首个内测版。本版主线是把「预览 → 执行」收紧成一条方言感知的安全链路：预览执行按目标数据源方言出 Runner，真实执行前核对来源方言与执行目标，冲突时阻断并给出就地修复入口；方言闸门阻断态可直接切数据源或改方言，绑定后按新方言重渲染。同时把只读动作从预览编辑器里分离出来——预估影响行数、EXPLAIN 与回滚快照查询都走只读旁路，不再替换你正在看的 SQL。另有一批新能力与 UI 走查缺陷修复随本版交付。

## ✨ 新增

**预览执行与方言（O-145 / O-136 / UI-040）**
- 预览点执行时按目标数据源（上次使用 → 显示名 → 默认）路由平台方言，不再写死 MySQL；平台缺对应方言时回退插件 URL 推断，仍无法确定则诚实保持原样
- 方言匹配集不是全部数据源时，平台返回的「All」组 Runner 自动展开子项并去重，达梦等此前被死组项挡住的方言可以直接执行
- 注解、mapper XML 与 Wrapper 在真实 SQL PSI 可用时读取 IDEA provider 与有效方言；无法可靠解析时降级为不可用，不标 STRONG、不取第一个数据源
- 实际选定的数据源在 session attach 前、原生控制台提交前分别核对；手动冲突与未知写 / EXPLAIN 阻断，能无损重渲染的自动模式要求先复核再执行
- 阻断态给出「切换数据源」「方言设置」两个就地入口；改完方言或切源后按目标方言重渲染并重试
- 预览面板可按需查看方言来源、置信度与候选数据源 UUID

**只读旁路（T-PreviewSideQuery）**
- 预估影响行数、EXPLAIN 与回滚快照查询改走只读旁路，不再用执行结果替换预览编辑器里的 SQL
- 影响行数结果改为顶部独立横幅；EXPLAIN 改为非模态对话框，执行视图新增「返回预览」

**复制 SQL 并关闭（UI-042 / UI-043 / UI-044）**
- 预览面板底部新增蓝色主行动按钮，一次复制当前 SQL 并关闭面板
- 按钮按平台 LAF 绘制（圆角与蓝色底跟随主题），复制后的通知不再附带「关闭 SQL 面板」动作

**回滚快照（UI-033 / UI-036 / UI-037 / UI-041）**
- 快照查询结果支持表格 / 文本双态切换与列宽调整，可在 IDEA 原生 CSV 编辑器中打开
- 快照查询没有数据源时直接弹选择器，绑定后自动重试；查询走只读旁路并自动填充生成回滚
- 预览的 INSERT 仍可一键推导逆向 DELETE；仅真实提交回执才更新回滚留痕与横幅

**参数预设按方法隔离与绑定（T-PresetMethodScope / T-PresetMethodBinding）**
- 预设、参数历史与最近参数按「声明方法的签名」分桶，同名预设不再跨方法互相覆盖
- 预设保存时记住所属方法，之后改写 SQL 文本（换参数名、调整结构）仍按方法命中，不再因文本指纹变化丢预设
- 从历史召回只回填到原方法；首次召回 foreach 快照时同步 SQL 展开长度

**EXPLAIN 计划历史与对比（R90 / R61）**
- 复用应用级预览历史 XML 保存有界结构化计划快照，按项目、稳定数据源 UUID、方言、格式与实际 SQL 指纹隔离；基线选择只读，不重跑查询
- 两次 EXPLAIN 结果做树对齐 diff，标注 cost / rows 变化；MySQL / MariaDB 表格族与 PG / KingBase JSON 族可比，Oracle / SQL Server 文本计划诚实降级为不可比
- 原始计划可能含业务值与凭据，因此原计划保留是独立开关且默认关闭，设置页明示存储与清理边界

**AI 上下文与展示脱敏（R37 / R60 / R91）**
- 「复制为 AI 上下文」升级为版本化诊断投影：含来源与方言、已取得的计划摘要、静态表列计数；默认不执行 EXPLAIN、不调用网络 / JDBC / MCP
- 「更多」菜单新增「含表列名」出口，需要完整表列名时使用；结构关键词（FROM / WHERE / JOIN 等）恢复可读
- 展示脱敏覆盖四条链：SQL 日志列表、单击预览浮层、历史 / 日志导出、MCP `sqlv_render_logs`；「展示脱敏」与「脱敏字面量」双开关默认关
- 诊断反馈草稿默认隐藏 SQL 值、注释、参数名与标识符，不附参数、路径、原始计划与附件；逐段审阅、编辑后逐次同意提交

**FieldFill 安全模拟（R92）**
- CRUD / MP 批量参数区展示填充元信息与逐列模拟值，默认关闭，不执行用户 Handler
- 仅适配活跃 INSERT / UPDATE 写列，显式参数优先，WHERE 条件与 UPSERT 不猜填；`[fill=…]` 角标与字段名同行，模拟值优先于普通输入框

**执行辅助（R42 / R45 / R46 / R48 / R50 / R52）**
- 执行前 Schema 校验（未识别列 + did-you-mean，只校验已预热表列，fail-open 不误报）
- 方言能力矩阵与执行前自检；DML 影响面预演（UPDATE / DELETE 只读 COUNT 试算）
- EXPLAIN 执行计划体检、MetaObjectHandler 自动填充仿真
- 一键诊断报告：SQL + 参数、性能规则、EXPLAIN 建议、无界写、回滚预案与方言能力，可复制 Markdown 或导出 HTML

**其它新增**
- 捕获双通道状态常驻状态栏（已挂载 / 已收事件数 / 暂停中 / 总开关关）
- 预览 SQL 中无法解析的列标红波浪线并给出悬停建议（UI025）
- 历史列表工具栏新增「直达当前过滤末条」
- 执行前限定目标 Schema 预检，拒绝 CTE 与 `DELETE ... USING` 歧义（UI023）

## 🔧 改进

- **增强捕获默认开启（T-EnhancedCaptureDefaultOn）**：总开关默认开启，打开即授权，不再逐次弹注入确认；旧配置里的 `confirmed=false` 与拒绝时刻静默归一，用户显式关闭的开关保持关闭
- **增强捕获暂停按钮暂时隐藏（T-AgentPauseVisibility）**：暂停按钮在应用未运行时没有可暂停对象，且与捕捉按钮形成播放 / 暂停误读，先整体隐藏；关闭总开关仍回落控制台
- **预览降级横幅按原因分型（T-DegradedPreviewUx）**：首开预热仅超 500ms 预算不再立刻挂红横幅，改为 3 秒宽限期静默（期间恢复则横幅不出现），硬失败才立即披露并写明原因
- **工具栏图标语义统一（T-ToolbarIconSemantics）**：四个页签统一为插件自带 SVG 图标，消除 243 与 262 平台图标形态差异
- **性能优化（T-PerfSweep D31）**：历史检索扫描环三合一重写（文件名倒序、条目粒度封顶、双旧预跳过），参数预设缓存改桶外粗锁，日志解析逐行 token 单次提取；大历史目录不再卡顿
- **本地数据分离清理**：设置页可打开捕获历史目录，或分别确认清除预览 SQL 历史与参数历史 / 预设
- **检查更新失败可诊断化（R62）**：区分网络不通 / 更新通道 404 / 已是最新三态，404 态给出 Marketplace 与 Gitee Releases 兜底链接
- **分发包合规与瘦身**：LICENSE 与 THIRD-PARTY-NOTICES 随包分发（插件目录与主 jar `META-INF/` 双落位）；排除 JSqlParser 误带的 jmh-core / jopt-simple / commons-math3，分发 zip 约减 20.8%
- **Kotlin Wrapper 主动预览改为诚实说明**：无法可靠推断实体表、列和值时继续隐藏 gutter 假入口；主动使用时非模态说明限制，不生成猜测 SQL

## 🐛 修复

- **SQL 转 Java 条件组与逻辑删除（T-ReverseGroupLogicDelete）**：`or()` 不再被后续 `and(...)` 静默吞掉，嵌套条件组保留 `NOT`，逻辑删除列不再重复生成 `AND deleted = 0`
- **SQL 转 Java 类选择字段（UI-045）**：类名输入框描边与圆角改用平台口径（2px 描边 + 贝塞尔圆角），与原生输入框一致
- **UI 走查批次 · 预览与执行**：设置页列宽污染（UI-001）；EXPLAIN 历史基线改为双语可读来源与本地时间（UI-002）；准备阶段取消与排队替代请求补齐终态、用户交互超时不再被当作失败（UI-014）；原生控制台视图随项目关闭正确释放、取消时致命错误照常透传（UI-016）；INSERT 列名与值对位（UI-021）；结构化执行计划不可用时直接弹数据源选择器并重试（UI-030）；执行计划对话框取消按钮跟随插件语言、无数据源直达 Database 工具窗口（UI-035）；影响面预演取消选择后解除 loading、不可试算时覆盖旧的内联结果（UI-031 / UI-034）
- **UI 走查批次 · 日志与历史**：历史页首次进入自动加载已有文件（UI-004）；兼容 ShardingSphere 5.5.2 参数日志、保留原始 Logic / Actual 配对，同结构计数与执行去重分开（UI-008 / UI-013）；非法正则显式反馈，区分无匹配与空文件（UI-009）；手动浏览后的滚底状态与「滚到底部」恢复（UI-012）；跨方法另存同名预设不再被全局查重拒绝（UI-017）；仅真实提交回执更新回滚留痕（UI-020）；存储操作按钮宽度与英文设置页横向溢出（UI-024 / UI-026）；日志时间拒绝跨签名借时，也不给无时间日志伪造时间
- **UI 走查批次 · 转换与捕获**：SQL 反向生成聚合投影整链回落并合并 select、双引号表名不再进入 Java 泛型类名、无实体时 QueryWrapper 输出保持兼容（UI-005）；FieldFill 参数区左对齐与窄栏多行布局（UI-006）；增强捕获统一排除 IDE 与构建辅助 JVM（UI-007）；SQL 转 Java 淘汰过期异步回调并隔离解析缓存（UI-010）
- **SQL 片段占位符来源（UI-038 / UI-039）**：`select` / `first` / `around` / UNION / LIMIT 的字符串拼接实参与全部片段入口按序登记占位符来源，修复 SET 丢失与参数错位
- **同名实体跨模块误选（T-EntityNameScope）**：HQL 根实体按查询宿主模块可见性解析；同级多候选判歧义，不选、不提示错、不再静默取第一个
- **MCP 细节**：`sqlv_perf_advice` 的 missing_where 大小写误报修正；设置页区分「声明」与「已注册可调用」；保留反射驱动异常消息与错误位置；识别 POSIX 绝对路径并按真实路径限制项目范围；禁用工具在直接调用时执行前拒绝
- **执行链生命周期**：exec 预暖链与文档写全链挂项目 dispose 生命周期守卫，文档写零窗口化，消除门禁冲突与项目关闭后的迟到写入
- **其它**：日志转 SQL 按提交回执区分取消与阻断，不再提前提示成功；精简 SQL 快捷模板接入右键菜单并先做单表标识符校验；差异对比恒无基线（UI-023）；预览降级态与方言重解析导致的预热 PSI 失效

## 兼容性

- `verifyGate` 三目标 **IU-243 / 253 / 262 均 Compatible**；override-only 用法 **0**、internal API 用法 **0**（模块身份解析已改用公开 `ModuleUtilCore.getModuleDirPath`），计划移除 5 / 6 / 8、弃用 40 / 51 / 123、实验性 98 / 96 / 96——均按 warning 级留观察，不阻断发行
- 本轮未跑 `verifyMarketplace`（在线 3.3GB 校验器）与 `e2eFakeIde`，故不宣称 Marketplace 同口径结论与端到端探针结论；上架 Marketplace 前需补跑

- 支持 IntelliJ IDEA **2024.3+**（Ultimate / Community；EXPLAIN、执行 SQL、表右键入口与 Database 原生图需 Ultimate；MCP 能力需平台 MCP Server）
- 插件 ID 与升级链路不变，v2026.10.16 用户可直接覆盖升级

## 📦 安装（内测通道）

1. 下载附件 `mybatis-plus-sql-visualizer-2026.10.23-beta.1.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装 v2026.9.11+ 用户：设置页「更新」分区检查更新即自动收到本内测版（Gitee 抢先体验通道），经该通道更新免重启即时生效
