## 这一版有什么

**让位开关不再误让 Mapper 接口方法行的跳转图标（T-MapperNavYieldBySide，`beef3fa18`）**：此前开启「同类 MyBatis 导航插件启用时让出跳转图标」后，XML 语句行与 Mapper 接口方法行会被一起让掉。同类插件（MyBatisCodeHelperPro）在接口方法行的跳转箭头注册在 `language="UAST"` 上，而 UAST 是 MetaLanguage，平台会把它并入 Java 文件的 provider 收集集合，对方在该行正常出图标；两家图标又是同款（我方 `mapperMethod.svg` 与对方 `icon/mybatis_java.svg` 同为 11 条 path、同三色）。结果接口方法行只剩对方那一枚同款图标，看不出本插件是否在工作（表现为「mapper 中的图标没显示」）。现在让位只作用于 XML 语句行（该行对方箭头与已有预览图标同在），Mapper 接口方法行恒显示本插件跳转图标；设置项不拆，语义收窄为「让出 XML 语句行的跳转图标」，`Ctrl+B` / `Ctrl+Click` 跳转始终可用，不受影响。
