## 一、首评引导帖

用途：发在 Gitee 仓库与插件交流群，给已用过的人一个开口的理由。现在评价区是空的，新用户在列表页只看到一行标题和一个数字 0。

### 中文

标题：用过的说一句，比什么都有用

这个插件是我一个人在做。市场里的评价区现在还是零，新进来的人看到的就是一行标题，没有别的判断依据。

如果你真的拿它干过活，无论顺手还是别扭，都欢迎写一句。写清楚你拿它做什么、在什么地方卡住，对后面的人比一句「挺好用」有用。遇到问题的，把报错或者当时的 SQL 贴上去也行。

不想写也完全没关系。装了没用上、或者已经卸了，说实话同样有价值。

不需要夸，也不要求按什么格式写。评价入口在插件页面的 Reviews 一栏，账号登录后就能写。

### English

Title: If you have used it, one honest line helps

I build this plugin on my own. The review section is still empty, so anyone landing on the page sees a title and a zero, nothing else.

If you have actually used it on real work, useful or awkward, one line is welcome. What you used it for and where it got in your way is worth more to the next reader than "works great". If something broke, pasting the error or the statement you were running is fine too.

No need to write anything either. Installed it and never used it, or already uninstalled it, that is just as useful to say.

No praise needed and no format required. Reviews are under the Reviews tab on the plugin page once you sign in.

## 二、评分引导话术（插件内）

用途：用户在插件内完成一次成功操作后的一次性提示（状态栏或面板内一行，**不弹模态框**）。原约束：中文不超过 60 字。

- 中文（22 字）：`如果它帮到了你，愿意的话写句真实的使用感受。`
- English（64 字符）：`if it helped, an honest line in the reviews would go a long way.`

备用（更短，中文 13 字，用于极窄状态栏）：`用得上的话，留句真实感受。`

使用纪律：
- 只出一次，用户关掉即长期不再出现（走既有「领取即消耗」的版本粒度开关）。
- 不阻断操作，不弹模态，不挂在关键路径按钮上。
- 文案里不出现任何回报承诺，也不要求写好评。

## 三、发布时的自检清单（V47）

| 检查项 | 判据 |
|---|---|
| 自愿 | 帖子里明确写了「不想写也没关系」 |
| 不代写 | 全文没有任何可直接复制的评价模板或话术 |
| 不承诺回报 | 全文无奖励、无折扣、无互评暗示 |
| 不筛选 | 明说差评与卸载同样有价值，没有「请给五星」之类表述 |
| 不重复打扰 | 插件内提示只出一次，且不在关键操作路径上阻断 |
| 时效 | 帖子里的版本号、下载量这类会过期的数字一律不写 |
