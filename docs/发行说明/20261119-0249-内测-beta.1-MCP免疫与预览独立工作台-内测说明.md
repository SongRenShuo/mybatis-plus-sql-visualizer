## 这一版有什么

**MCP：结构性免疫（T-McpGlobalBreakHardening）**——本批立项的缘起是用户报障「插件导致 IDEA 的所有 MCP 都无法使用」（2026.1.x 上过滤接口契约不匹配，插件把平台内置 MCP Server 整体拖垮）。本版把这类事故变成结构性不可能，并在真机走查中顺带修出两个真缺陷：

- 平台过滤器契约再变也不会拖垮内置 MCP Server：注册前按「契约白名单」判定，接口上出现任何不认识的方法（含 suspend 化）一律不注册；万一运行期还是调到未知方法，代理先按返回类型给安全值、并立刻把自己从平台扩展点摘掉——最坏结果是「门控不生效」，MCP 服务继续可用
- 关掉插件 MCP 总开关后，插件完全不碰平台 MCP 的两个注册面（toolset 与过滤 provider），重新打开后无需重启即时生效
- 修复 IDEA 2026.3 上 MCP 工具清单只剩 1 个的问题（2026.3 给工具集接口新增三个钩子，插件工具集没实现，真机实测 92 个工具只剩 1 个 sqlv 且无任何报错）
- 修复 MCP 设置子页改动要重启才生效的问题（子页 apply 漏发设置变更广播，热同步从未被触发；现在勾上/取消总开关立即注册/注销，真机双向实测）
- 设置页 MCP 区新增只读状态行「外部会话门控：已生效 / 未识别 / 已关闭 / 无此能力 / 已熔断」；Registry 键 `sqlvis.mcp.gateFilterEp` 是逃生开关，万一平台再改契约可只关这一项、不必卸载插件

**SQL 预览独立工作台（T-SqlPreviewStandalone）**：主侧边栏新增「SQL 预览」页签——粘贴一段 SQL 或 mapper XML 片段就能快速格式化、填值、复制可执行 SQL（Tools 菜单与 `Alt+Shift+P` 直达）。支持 iBatis 2 条件标签与占位语法；随批修掉六轮走查缺陷（弹框打开失效、空弹窗贴入即识别、首开降级误报、缺失 include 占位与补齐、弹窗选文件、长警告看全、错误信息可复制等）。

**吸收 Hibernate Debugger 精华五项（T-HdAbsorb D215~D219）**：SQL 日志耗时按测量来源分档并补偿调试器挂起时段；同模板 60 秒滑动窗判定「疑似 N+1」红色徽章；调用栈里的 JDK/CGLIB 代理帧反解为业务类型；数据源改名后按「URL+用户+库名」指纹兜底恢复记忆；MCP 工具输出可选摘要档（`detail=false`）。

**性能与稳定性（T-PerfSweep31/32）**：iBatis 别名表索引化（首次预览不再整模块慢扫）；索引构建期点预览/跳转不再「点了没反应」（等索引就绪自动重试）；同一预览打开 exec 文件不再重复写盘；导出 HTML 报告移入后台；跳转图标缓存按项目隔离；预览参数已带引号的值不再被二次转义。
