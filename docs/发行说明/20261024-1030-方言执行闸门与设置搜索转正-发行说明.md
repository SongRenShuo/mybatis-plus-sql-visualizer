# 🎉 SQL Visualizer v2026.10.23

> 发行说明留档：对应 Gitee 发行版 **v2026.10.23**（标签 `2026.10.23`），附件 `mybatis-plus-sql-visualizer-2026.10.23.zip`。
> 范围＝自 v2026.10.16 正式版发行包之后的全部用户可见增量，含 v2026.10.23-beta.1 ~ beta.3 三个内测版的累计内容，以及首次发行后又修的 11 笔（同 tag 重发，发行版 id 不变）。

自 v2026.10.16 后的正式版。本版把「预览 → 执行」收紧成一条方言感知的安全链路，把只读动作从预览编辑器里彻底分离，并补齐了运行期捕获的稳定性与实体解析的边界形态。beta.1~beta.3 三轮内测的内容全部并入本版，对外清单做了合并去重。

首版发行后又修了一批执行计划取源与换源的问题（详见下方「首次发行后的补充修复」），因此同一标签下重新构建并替换了发行包——**版本号与标签不变，附件已更新**，已装首版的用户重新下载即可。

## 🔁 首次发行后的补充修复

**执行计划取源与换源（十二轮迭代收口）**
- 方言闸门重渲染后自动重新提交；直送链取源接上次使用数据源回落
- **按表归属路由选源**：SQL 里的表不在当前候选源时，自动改取持有该表的源
- **按模块学习归属**：多模块工程里发生过执行的模块记住自己的数据源，冲突不猜，消掉跨模块错源执行
- 排队执行意图自有有界结算（15 秒），不再被别的请求拖着不返回
- 选错源不再弹模态框打断，改为就地横幅引导换源；换源最终交还平台原生 `Data Sources` 工具栏，插件不自建下拉
- 执行计划最终形态收回到**预览窗内嵌原生控制台**：插件不选源、不筛、不猜，取源与换源全交平台
- 顺带偿还了一笔技术债：执行视图下点只读动作（回滚 SQL / 导出回放 / 复制 AI 上下文 / 导出可移植 SQL / 预估影响行数）此前会把 EXPLAIN 语句当成预览 SQL，现改为读预览快照
- 「启用结构化并重试」推荐通知此前每次点执行计划都弹、点过一次就把开关永久点亮且界面无提示，现改为只提示一次；结构化通道保留、默认关

**上次使用数据源按模块隔离（T-ModuleScopedLastUsed）**
- 三层记忆：活控制台 > 模块级上次使用 > 项目级兜底；多模块工程不再串用其他模块的数据源
- 指示行灰字区分「本模块上次使用」与项目级兜底；模块信息缺失时回落项目级（纯 `.sql` 入口不致退化成永未绑定）
- 沙盒验收抓出并修掉一处误判：用「兜底读取的返回值」反推命中层级恒为真，纯项目级兜底会被冒称成模块级

**SQL 日志工具栏卡顿（T-SqlLogToolbarEdt）**
- 动作组与 11 个动作逐个声明后台线程更新，消除每次抢占编辑线程 3.1~4.0 秒的告警
- 排序标签构造去分配改静态查表，20 万次实测 38.1 秒降至 5.8 秒（6.6 倍）

**其它**
- exec 预热改异步，不再阻塞编辑线程

## ✨ 新增

**预览执行与方言（O-145 / O-136）**
- 预览点执行时按目标数据源（上次使用 → 显示名 → 默认）路由平台方言，不再写死 MySQL；平台缺对应方言时回退插件 URL 推断，仍无法确定则诚实保持原样
- 方言匹配集不是全部数据源时，平台返回的「All」组 Runner 自动展开子项并去重，达梦等此前被死组项挡住的方言可以直接执行
- 注解、mapper XML 与 Wrapper 在真实 SQL PSI 可用时读取 IDEA provider 与有效方言；无法可靠解析时降级为不可用，不标 STRONG、不取第一个数据源
- 实际选定的数据源在 session attach 前、原生控制台提交前分别核对；手动冲突与未知写 / EXPLAIN 阻断，能无损重渲染的自动模式要求先复核再执行
- 阻断态给出「切换数据源」「方言设置」两个就地入口，改完方言或切源后按目标方言重渲染并重试

**只读旁路（T-PreviewSideQuery）**
- 预估影响行数、EXPLAIN 与回滚快照查询改走只读旁路，不再用执行结果替换预览编辑器里的 SQL
- 影响行数结果改为顶部独立横幅；EXPLAIN 改为非模态对话框，执行视图新增「返回预览」
- 预览面板底部新增蓝色主行动按钮「复制 SQL 并关闭」，按平台 LAF 绘制，复制后的通知不再附带多余动作

**回滚快照（UI-033 / UI-036 / UI-037 / UI-041）**
- 快照查询结果支持表格 / 文本双态切换与列宽调整，可在 IDEA 原生 CSV 编辑器中打开
- 快照查询没有数据源时直接弹选择器，绑定后自动重试；查询走只读旁路并自动填充生成回滚
- 预览的 INSERT 仍可一键推导逆向 DELETE；仅真实提交回执才更新回滚留痕与横幅

**参数预设按方法隔离与绑定（T-PresetMethodScope / T-PresetMethodBinding）**
- 预设、参数历史与最近参数按「声明方法的签名」分桶，同名预设不再跨方法互相覆盖
- 预设保存时记住所属方法，之后改写 SQL 文本（换参数名、调整结构）仍按方法命中，不再因文本指纹变化丢预设
- 从历史召回只回填到原方法；首次召回 foreach 快照时同步 SQL 展开长度

**EXPLAIN 计划历史与对比（R90 / R61）**
- 复用应用级预览历史 XML 保存有界结构化计划快照，按项目、稳定数据源 UUID、方言、格式与实际 SQL 指纹隔离；基线选择只读，不重跑查询
- 两次 EXPLAIN 结果做树对齐 diff，标注 cost / rows 变化；MySQL / MariaDB 表格族与 PG / KingBase JSON 族可比，Oracle / SQL Server 文本计划诚实降级为不可比
- 原始计划可能含业务值与凭据，因此原计划保留是独立开关且默认关闭，设置页明示存储与清理边界
- 结构化执行计划在数据源未存密码时交平台原生密码框；认证失败给出「补存密码」指引，密码框取消只轻通知、绝不自动重试

**AI 上下文与展示脱敏（R37 / R60 / R91）**
- 「复制为 AI 上下文」升级为版本化诊断投影：含来源与方言、已取得的计划摘要、静态表列计数；默认不执行 EXPLAIN、不调用网络 / JDBC / MCP
- 「更多」菜单新增「含表列名」出口；结构关键词（FROM / WHERE / JOIN 等）恢复可读
- 展示脱敏覆盖四条链：SQL 日志列表、单击预览浮层、历史 / 日志导出、MCP `sqlv_render_logs`；双开关默认关
- 诊断反馈草稿默认隐藏 SQL 值、注释、参数名与标识符，逐段审阅、编辑后逐次同意提交

**FieldFill 安全模拟（R92）**
- CRUD / MP 批量参数区展示填充元信息与逐列模拟值，默认关闭，不执行用户 Handler
- 仅适配活跃 INSERT / UPDATE 写列，显式参数优先，WHERE 条件与 UPSERT 不猜填；`[fill=…]` 角标与字段名同行

**执行辅助（R42 / R45 / R46 / R48 / R50 / R52）**
- 执行前 Schema 校验（未识别列 + did-you-mean，只校验已预热表列，fail-open 不误报）
- 方言能力矩阵与执行前自检；DML 影响面预演（UPDATE / DELETE 只读 COUNT 试算）
- EXPLAIN 执行计划体检、MetaObjectHandler 自动填充仿真
- 一键诊断报告：SQL + 参数、性能规则、EXPLAIN 建议、无界写、回滚预案与方言能力，可复制 Markdown 或导出 HTML

**设置搜索（T-SettingsSearchA / T-SettingsSearchB）**
- 插件设置接入 IDE 自带设置搜索：在 `Settings` 搜索框里搜「脱敏」「预设」「FieldFill」等关键词可直接定位到对应设置项，不再只能逐页翻
- 索引与页内搜索共用同一份数据源，两套搜索天然同步；9 个既有设置类一行未改
- 页内搜索补登记「展示与导出脱敏」，并立面板-索引配对守卫，后续新增开关不入索引会被拦下
- 边界声明：索引按插件语言生成，英文词条不命中中文界面

**其它新增**
- 捕获双通道状态常驻状态栏（已挂载 / 已收事件数 / 暂停中 / 总开关关）
- 预览 SQL 中无法解析的列标红波浪线并给出悬停建议（UI025）
- 历史列表工具栏新增「直达当前过滤末条」
- 执行前限定目标 Schema 预检，拒绝 CTE 与 `DELETE ... USING` 歧义（UI023）

## 🔧 改进

- **增强捕获默认开启（T-EnhancedCaptureDefaultOn）**：总开关默认开启，打开即授权，不再逐次弹注入确认；旧配置里的 `confirmed=false` 与拒绝时刻静默归一，用户显式关闭的开关保持关闭
- **增强捕获暂停按钮暂时隐藏（T-AgentPauseVisibility）**：暂停按钮在应用未运行时没有可暂停对象，且与捕捉按钮形成播放 / 暂停误读，先整体隐藏；关闭总开关仍回落控制台
- **预览降级横幅按原因分型（T-DegradedPreviewUx）**：首开预热仅超 500ms 预算不再立刻挂红横幅，改为 3 秒宽限期静默，硬失败才立即披露并写明原因
- **工具栏图标语义统一（T-ToolbarIconSemantics）**：四个页签统一为插件自带 SVG 图标，消除 243 与 262 平台图标形态差异
- **性能优化**：历史检索扫描环三合一重写、参数预设缓存改桶外粗锁、日志解析逐行 token 单次提取、折叠尊重 quick 并加体量熔断、引用解析加 memo；大历史目录与大文件下更稳
- **本地数据分离清理**：设置页可打开捕获历史目录，或分别确认清除预览 SQL 历史与参数历史 / 预设
- **检查更新失败可诊断化（R62）**：区分网络不通 / 更新通道 404 / 已是最新三态，404 态给出 Marketplace 与 Gitee Releases 兜底链接
- **分发包合规与瘦身**：LICENSE 与 THIRD-PARTY-NOTICES 随包分发；排除 JSqlParser 误带的 jmh-core / jopt-simple / commons-math3，分发 zip 约减 20.8%
- **Kotlin Wrapper 主动预览改为诚实说明**：无法可靠推断实体表、列和值时继续隐藏 gutter 假入口；主动使用时非模态说明限制，不生成猜测 SQL

## 🐛 修复

**运行期捕获**
- **增强捕获与第三方 agent 共存导致目标 JVM 无法启动（T-JRebelPremainCrash）**：同时开启增强捕获与 JRebel 启动器时，目标应用以 `FATAL ERROR in native method: processing of -javaagent failed` 直接起不来。根因是名单谓词位于 try 之外，第三方 agent 接管 premain 类加载后 ASM 不可见，谓词触发织入器类初始化抛 `NoClassDefFoundError`，异常穿出 `premain` 即致命。现双入口统一兜底不外抛、名单判定与 ASM 解耦、premain 未回连时提示一次并回落运行期挂载。已在 Corretto 21 上用真实 agent 产物做修复前后对照；未复刻用户 JRebel 的具体转发路径
- **premain 暂停恢复无界 join 挂死**：accept 循环改代际让位 + resume 加有界预算兜底，消除发版门禁中 75 分钟的挂死

**实体解析**
- **jar 内宿主叠加工程同 FQN 影子实体导致实体不可解析（T-ShadowEntityResolve）**：方法、HQL、实体类都在 jar 里，工程下又新增同包名同类名的类时，预览降级为 `task.*` 并提示「实体名有多个同名候选」。现按模块依赖方向与源码形态仲裁：同 FQN 两份都判为工程内容时按源码形态收窄，跨模块同名按依赖方向选宿主模块，workspace 形态下零候选时不再直接判不可解析。jar 以 sources jar 附带与反编译视图两种形态都覆盖
- **同名实体跨模块误选（T-EntityNameScope）**：HQL 根实体按查询宿主模块可见性解析；同级多候选判歧义，不再静默取第一个

**预览与执行链**
- **预览执行链三组平台内部告警收口**：EDT 读盘慢操作断言、裸池线程缺进度上下文、Disposer 二次摘监听三组 SEVERE 归因修复；用户侧表现为「执行计划 → 选源 → 关面板」的会话不再刷内部错误
- **预览错列标注会话未注册进 Disposer 树**：关闭 IDE 时报 24 条 `Memory leak detected`，全部指向 `PreviewSchemaHighlighter$Session`。现以编辑器所属项目为属主注册进 Disposer 树，项目关闭即兜底回收
- **EXPLAIN 真绑定缺失时回落上次使用数据源**：结构化执行计划此前被方言路由的空 Runner 阻断
- **参数未回填不再回退直送**：消掉误导性的「未绑定数据源」红字框
- **结构化执行计划基线下拉被拉伸到整屏宽**：现按内容定宽
- **SQL 片段占位符来源（UI-038 / UI-039）**：`select` / `first` / `around` / UNION / LIMIT 的字符串拼接实参与全部片段入口按序登记占位符来源，修复 SET 丢失与参数错位

**日志与设置**
- **UI 走查批次 · 日志与历史**：历史页首次进入自动加载已有文件（UI-004）；兼容 ShardingSphere 5.5.2 参数日志并保留原始 Logic / Actual 配对（UI-008 / UI-013）；非法正则显式反馈（UI-009）；滚底状态与恢复（UI-012）；跨方法另存同名预设不再被全局查重拒绝（UI-017）；仅真实提交回执更新回滚留痕（UI-020）；存储按钮宽度与英文设置页横向溢出（UI-024 / UI-026）；日志时间拒绝跨签名借时
- **UI 走查批次 · 转换与捕获**：SQL 反向生成聚合投影整链回落并合并 select、双引号表名不再进入 Java 泛型类名（UI-005）；FieldFill 参数区布局（UI-006）；增强捕获统一排除 IDE 与构建辅助 JVM（UI-007）；SQL 转 Java 淘汰过期异步回调（UI-010）
- **SQL 转 Java 条件组与逻辑删除**：`or()` 不再被后续 `and(...)` 静默吞掉，嵌套条件组保留 `NOT`，逻辑删除列不再重复生成 `AND deleted = 0`
- **MCP 细节**：`sqlv_perf_advice` 的 missing_where 大小写误报修正；设置页区分「声明」与「已注册可调用」；保留反射驱动异常消息与错误位置；识别 POSIX 绝对路径并按真实路径限制项目范围；禁用工具在直接调用时执行前拒绝
- **执行链生命周期**：exec 预暖链与文档写全链挂项目 dispose 生命周期守卫，消除项目关闭后的迟到写入
