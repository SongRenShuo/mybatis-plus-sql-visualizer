## 这一版有什么

按新功能 → 修复 → 优化排序。

1. **Mapper XML 根标签也有跳转图标了（T-MapperNavNamespaceJump，`6f6907655`）**：`<mapper namespace="...">` 根标签行新增「跳 Mapper 接口类」图标，点击 / Ctrl+B / Ctrl+Alt+Home 都能跳到对应接口类；接口里没有方法也能跳（无方法时从语句行退化跳类）。让位登记同步扩到 MyBatisX / MyBatisPlus。
2. **Mapper 接口类名也有跳转图标了（T-MapperClassJump，`ddd37a5be`）**：接口声明行新增「类 → 对应 XML 根标签」图标，点击 / Ctrl+B / GotoRelated（Related）三条入口都落到 mapper XML 根标签；对齐 MPJ / MyBatisX 的类级箭头。
3. **让位覆盖 XML 与 Mapper 两侧（T-MapperNavYieldBothSides，`a009cf207` + `ddd37a5be`）**：同类 MyBatis 导航插件在位时，XML 语句行与 Mapper 接口方法行的本插件跳转图标一起让出，同一位置只留对方那一套；让位登记覆盖 MyBatisCodeHelperPro / MyBatisX / MyBatisPlus。能力前提（反编译核实）：XML 侧三家都会画；Java 侧 MyBatisX / MyBatisPlus 会画，MyBatisCodeHelperPro 的 UAST 箭头在当前平台不产出——只装它时 Java 方法行让位后会为空。
4. **切换让位开关后立即重算（T-MapperNavYieldBothSides，`ddd37a5be`）**：设置页切换让位开关后，已打开的 mapper/xml 立即按新值重算图标，无需重开文件；让位开关文案改为「与同类 MyBatis 导航插件共存时让出 XML 与 Mapper 跳转图标」，中英提示同步。
