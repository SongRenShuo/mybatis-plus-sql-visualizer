## 这一版有什么

**SQL 预览独立工作台（T-SqlPreviewStandalone，beta.1/beta.2 已含，本版继续收尾）**：主侧边栏新增「SQL 预览」页签——粘贴一段 SQL 或 mapper XML 片段就能快速格式化、填值、复制可执行 SQL（Tools 菜单与 `Alt+Shift+P` 直达，剪贴板里疑似 SQL 时自动预填）。XML 片段识别复用插件自研 XML 引擎：动态条件勾选、foreach 重放、bind 回填都可用；网页复制的 `&lt;/&gt;` 转义形态与 markdown 代码围栏也能识别；iBatis 2 条件标签（`<dynamic>` / `<isNotNull>`）与 `#id#` / `$name$` 占位语法同样可识别可填值。可直接执行（D233/D234）——复用语句预览那套完整执行链（Schema 校验、DML 二次确认、`${}` raw 确认门、方言闸、控制台内嵌），解析成功后自动跑静态性能检查。

**本版新增：工作台底部动作行（T-PreviewActionRow）**：页签底部新增「执行 SQL / 复制 SQL」两个产物出口——此前页签里没有复制 SQL 的入口，想取走去注释的可执行 SQL 只能先进弹窗或手工全选；顶部图标区保留解析预览 / 格式化 / 从文件加载 / 清空 / 在弹框中打开（清空与在弹框中打开按用户反馈留在原位置，同一动作不两处重复）。预览缺 `<sql>` 片段时结果区直接给「缺少片段 —— 点此补上内容」入口，从工作台打开的弹窗里点了当场用原文重解析、就地看到展开后的 SQL（gutter 图标 / 日志 / 历史打开的弹窗没有原文可重解析，不出现该入口）。

**本版新增：结果区信息分区（T-PreviewInfoLayout）**：警告只在黄色横幅承载（含悬停全文、点正文弹完整信息对话框），meta 行不再重复贴一遍警告正文、表名与判型依据不再被挤掉；性能建议从 meta 第二行搬到工具栏下方整行展示，不再被挤成「…集，建议添加 LIMIT」这种半句、放不下时尾部省略、悬停给全文。顺带修复补齐片段框的「从文件选择…」没有反应（选择器父组件传空，被模态框压住或不显示）。

**本版新增：「从文件加载」移到独立工作台（T-LoadFilePlacement）**：预览弹窗是全插件 21 处入口共用的展示层（gutter 图标、日志、历史、语句预览），在里面换文件会静默改掉「这条 SQL 从哪来」。现在该入口只出现在独立工作台的输入工具栏——选中 mapper XML 后替换输入并直接解析，状态行标注「已从 <文件名> 加载」，超长文件不写入。

**吸收 Hibernate Debugger 精华五项（T-HdAbsorb D215~D219，beta.2 已含）**：SQL 日志耗时按测量来源分档并补偿调试器挂起时段；同模板 60 秒滑动窗判定「疑似 N+1」红色徽章，点开按模板过滤成一组；调用栈里的 JDK/CGLIB 代理帧反解为业务类型；数据源改名后按「URL+用户+库名」指纹兜底恢复记忆；MCP 工具输出可选摘要档（`detail=false`）。其后聚合摘要行排版重做（红色只给短标签、详情转次要灰、退出口链接化）与「关掉 SQL 去重不再让 N+1 检测失效」（D237）一并修掉。

**MCP 结构性免疫（T-McpGlobalBreakHardening，beta.2 已含）**：平台过滤器契约再变也不会拖垮内置 MCP Server（未知契约自动不注册、运行期调到未知方法熔断摘除）；关掉插件 MCP 总开关后完全不碰平台过滤链、重新打开无需重启生效；设置子页改动无需重启生效；设置页 MCP 区新增只读门控状态行与 Registry 逃生开关 `sqlvis.mcp.gateFilterEp`。

**D239：2026.3 / 2025.3 / 2026.2 上 MCP 工具清单只列一两个的根治（beta.2 已含）**：运行期生成的工具集壳类补齐元数据、自己声明工具方法并带上注解，11 个工具集在 2026.3 元数据扫描下都能正常展开；顺带修平台工具清单缓存不刷新。真机三轮读数：165 个工具（含 11 个 `sqlv_*`）/ 154 个（0 个）/ 165 个。

**修复与优化（本版重点，T-PerfSweep33 / T-Perf33MergeAlign）**：独立预览的识别链与读盘全部移出界面线程——弹窗贴入识别改池线程解析，大 XML 片段（上限 100k 字符、最坏 8 次候选解析）不再停在界面线程，贴入停手后不再可感顿挫；工作台「从文件加载…」与补齐框「从文件选择…」的读文本移入后台，读取前按文件长度粗筛、超 100k 不再读进来；EXPLAIN 前置预热补 cache-only 判等，同内容不再绕过零写盘形态；N+1 嫌疑戳登记加双帽兜底——日志面板长期不打开时不再随捕获速率无界累积（单键 64 保最近段、键数 1024 下一窗重建，窗口判定语义不变）。同批新增源码守卫钉住「识别不在 EDT 直跑」形态（`resolve` 调用点恰一处、且必须落在池线程出口内）。

**交流群二维码改引站点 .jpg（本版新增，`d6d34c3dd`）**：group-qr.png 的文件内容一直是 JPEG（扩展名与字节不符，nosniff 下部分客户端会拒渲染）；站点已补 wechat-qr.jpg，交流群弹窗两码统一走 .jpg（描述区与 README 在 11-03 已改过，只有弹窗还留着 .png）。

**更早的稳定性修复（beta.2 已含，摘要）**：JDK 6/7 项目开启增强捕获不再导致应用起不来（T-OldJvmPremainGuard）；IDE 被第三方长读锁卡住时插件不再跟着卡（有界派发，`7e470a9e4`）；首开不再误报「简化模式/完整编辑器尚未就绪」；长警告可悬停/弹窗看全；预览参数已带引号的值不再被二次转义；iBatis 别名表索引化、索引构建期点预览自动重试等一批提速项（T-PerfSweep31/32）。
