# 🎉 SQL Visualizer v2026.11.4-beta.2（内测版）

> 发行说明留档：对应 Gitee 发行版 **v2026.11.4-beta.2**（标签 `2026.11.4-beta.2`），附件 `mybatis-plus-sql-visualizer-2026.11.4-beta.2.zip`。
> 通道：**Gitee 内测版**（Marketplace 侧由作者单独上传）。
> 范围＝v2026.11.4-beta.1 之后的单一增量：没有匹配方言的数据源时，提示改成能照着做的「下一步」。

这一版只做一件事：把一条让人看不懂的红字，改成能照着做的提示。

beta.1 之后有用户反馈：预览打开时底部出现一整段红字——「执行失败：没有与该 SQL 方言（MySQL）匹配的已配置数据源……请打开 Database 工具窗口，在目标数据源属性的 Dialects 设置中把 SQL 方言与语句对齐」，后面还跟着项目里全部 12 个数据源的名字。问题有三层：看不出该改哪一个；「打开 Database 工具窗口 → 属性 → Dialects」是纯文字，得自己一路找；用了「执行失败」的说法，让人以为插件坏了——其实只是这个数据源还没声明自己支持 MySQL。

现在这条提示会先替你判断该动谁。

## ⚡ 改进

**「没有匹配方言的数据源」提示改为可操作的「下一步」**

- 按 JDBC URL 的子协议推断哪些数据源看起来就是目标方言：
  - 只有一个对得上 → 标题直接写源名：「下一步：给「mp_demo@localhost」启用 MySQL 方言」
  - 多个对得上 → 点名前 5 个，其余折叠成「另有 N 个源与 MySQL 不匹配」
  - 一个都推断不出 → 只说「给一个数据源启用 MySQL 方言」，不猜
- 状态行从红色「执行失败」降级为橙色提示，右侧给两个可点入口：**打开数据源属性**（直接打开数据源对话框并选中推断出的那个源）、**切换数据源**（沿用既有原生源列表）
- 悬停查看详文：说明推断依据（唯一命中时带 `jdbc:mysql://…` URL）、明写「右上角「未绑定数据源」就是这个状态——这不是执行失败」，并给出准确落点：**属性页底部的 Dialect 下拉**，设好后用「测试连接」确认能连上
- 顺带纠正了旧文案的位置描述：原文说「属性 → Dialects」，实际 Dialect 下拉在属性页底部（平台把它放在属性面板的南侧区域）

推断规则不做方言家族合并——MariaDB 不会被当成 MySQL，只做渲染名归一（如 `DM（达梦）` ↔ `DM`、`TSQL` ↔ `SQL Server`）。Runner 的筛选逻辑本身没动，五种空 Runner 归因里也只在「方言不匹配」这一态接入了新提示。

## 🧪 测试

- 定向：`DialectMismatchHintTest` 8 例、`ExecDialectRoutingTest` 28 例、`BannedApiScanRuleTest` 12 例、`BundlePlaceholderArityTest` 4 例、`ChangeNotesRatingLineGuardTest` 2 例、`ExecTempFileEdtGuardTest` 2 例，合计 **56 例 0 失败**
- 全量门禁与三目标兼容性验证刻在本版发行前的 `releaseGate` 里，读数见发行记录

## ⚠️ 已知边界

- 推断只认 JDBC URL 子协议。数据源 URL 用了非标准写法、或是通过自定义驱动接入时推断不出，此时退化为「给一个数据源启用…」，仍然可点开数据源属性自己选
- 「打开数据源属性」走的是平台 Data Sources and Drivers 对话框（与右键数据源选 Properties 同一入口），Community 版没有该插件时不会出现这个入口，只保留文字提示
- 本版只有提示层改动，执行链、方言决策与 Runner 枚举的行为与 beta.1 完全一致

## 📦 兼容性

- 支持 IntelliJ IDEA 2024.3（243）及以上，243 / 253 / 262 三目标兼容性由发行门禁校验
- 依赖 IntelliJ IDEA Ultimate 或 DataGrip 的 Database 插件（Community 版预览与复制仍可用）

## 🚀 安装

1. 下载 `mybatis-plus-sql-visualizer-2026.11.4-beta.2.zip`
2. IDEA → Settings → Plugins → 齿轮 → Install Plugin from Disk… → 选择该 zip
3. 重启 IDE

内测通道用户也可以在设置页点「检查更新」直接升级。
