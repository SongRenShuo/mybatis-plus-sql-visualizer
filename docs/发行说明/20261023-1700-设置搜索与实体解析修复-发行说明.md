# 🎉 SQL Visualizer v2026.10.23-beta.3（内测版）

> 内测版留档：Gitee 抢先体验通道发行版，标签 `2026.10.23-beta.3`，附件 `mybatis-plus-sql-visualizer-2026.10.23-beta.3.zip`。
> 基线为内测版 v2026.10.23-beta.2，本版承载其后的全部增量；对外更新清单只保留最新一个 beta 版，内容为全系列累计。

自 v2026.10.23-beta.2 后的同日内测第三轮。本版三个主题：**插件设置接入 IDE 自带设置搜索**（搜「脱敏」「预设」等关键词直接定位设置项）；修掉一组用户真机报障的**实体解析缺陷**（jar 里的宿主 + 工程里新增同名类时预览降级为 `task.*`）；以及一处 IDE 退出时的**内存泄漏告警**修复。

## ✨ 新增

**插件设置接入 IDE 自带设置搜索（T-SettingsSearchA）**

- 在 IDEA `Settings` 搜索框里搜「脱敏」「预设」「FieldFill」等关键词，可直接定位到插件对应的设置项，不再只能逐页翻
- 运行期注册 `search.optionContributor` EP 把设置项喂进平台搜索索引，绕开 `buildSearchableOptions` 在 Windows 中文环境的构建期 locale 失败，不动构建脚本
- 索引与设置页内搜索共用同一份数据源，两套搜索天然同步；9 个既有设置类一行未改（平台 `ConfigurableWrapper` 本身实现 `SearchableConfigurable` 且 `getId()` 优先返回 EP id，243 平台反编译实证）
- 边界如实声明：索引按插件语言生成，英文词条不命中中文界面；真机 runIde 端到端验收待做

**设置页内搜索补登记「展示与导出脱敏」（T-SettingsSearchB）**

- 此前在设置页内搜索「脱敏 / 展示 / 导出 / 打码」都翻不到该开关，已补进索引
- 立面板-索引配对守卫：真实面板控件文本经双语 bundle 反解回键、逐条配对搜索索引（语言无关），白名单五类逐条留痕；后续新增开关不入索引会被守卫拦下

## 🐛 修复

**jar 内宿主叠加工程同 FQN 影子实体导致实体不可解析（T-ShadowEntityResolve）**

- 现象（用户真机报障）：方法、HQL、实体类都在 jar 里，工程下又新增一个同包名同类名的类（字段有差异）时，预览降级为 `task.*` 并提示「实体名有多个同名候选」
- 修法按模块依赖方向与源码形态仲裁：同 FQN 两份都判为工程内容时按源码形态收窄（jar 位于 `resources/lib` 等）；跨模块同名按依赖方向选宿主模块，jar 内宿主仍可正常判定；workspace 形态下宿主作用域零候选时不再直接判不可解析
- jar 以 sources jar 附带与反编译视图两种形态都覆盖；「两份工程源码」「两份库二进制」等仍按既有纪律 fail closed，不猜胜者

**预览错列标注会话未注册进 Disposer 树致 IDE 退出内存泄漏告警**

- 关闭 IDE 时报 24 条 `Memory leak detected`，全部指向 `PreviewSchemaHighlighter$Session`——Session 从未注册进 Disposer 树，其内部 Alarm 以它为 parentDisposable，平台把这条孤儿分支挂到 ROOT_DISPOSABLE 下、退出时不 dispose
- 现安装时以编辑器所属项目为属主注册进 Disposer 树（项目关闭即兜底回收），会话自带可判定的 disposed 标志（243 的 `Disposable` 接口无 `isDisposed`、不能 override，按平台官方替代口径用对象自带布尔标志），卸载改走树感知 dispose
- 新增生命周期护栏测试 5 例；反向摘掉注册恰 1 红

**结构化执行计划的基线下拉被拉伸到整屏宽（d068a5ef）**

- EXPLAIN 结果视图里基线下拉在纵向 BoxLayout 下被拉到容器最大宽度，现按内容定宽

## 📦 安装（内测通道）

1. 下载附件 `mybatis-plus-sql-visualizer-2026.10.23-beta.3.zip`
2. IDEA：`Settings → Plugins → ⚙️ → Install Plugin from Disk…` → 选择 zip → 重启 IDE
3. 已装 v2026.9.11+ 用户：设置页「更新」分区检查更新即自动收到本内测版（Gitee 抢先体验通道），经该通道更新免重启即时生效

## 附：随本版交付的 beta.1 / beta.2 能力（累计）

以下能力自 v2026.10.23-beta.1 / beta.2 起随内测包交付，本版继续包含：

- 预览执行按目标数据源方言出 Runner（达梦等方言的数据源可直接执行）；真实执行前核对来源方言与执行目标，冲突时阻断并给出「切换数据源」「方言设置」两个就地入口
- 只读旁路：预估影响行数、EXPLAIN 与回滚快照查询不再替换预览编辑器里的 SQL；影响行数结果改为顶部横幅；预览面板底部新增「复制 SQL 并关闭」
- 回滚快照表格 / 文本双态与 CSV 编辑器打开；无数据源时直接弹选择器并自动重试
- 参数预设与参数历史按声明方法隔离，预设永久绑定方法，改 SQL 不再丢参数
- 跨会话 EXPLAIN 计划历史与跨次对比；预览可标注无法解析的列
- AI 上下文复制新增「含表列名」出口；日志与导出支持选择性脱敏
- FieldFill 字段填充安全模拟（不执行用户 Handler）
- 执行前 Schema 预检、方言能力自检、DML 影响面试算、一键诊断报告
- 增强捕获默认开启、打开即授权；与 JRebel 等第三方 agent 共存时不再导致应用启动失败，premain 未回连时提示一次并回落运行期挂载
- SQL 转 Java 条件组不吞 OR、保留子组 NOT、逻辑删除条件不重复生成
- 历史检索与日志列表性能优化；分发包补齐 LICENSE 与第三方声明，体积减少约 20%；设置页能力矩阵 MCP 工具数已修正为十一个
