# v2026.11.12 正式版 —— 多字符运算符保真与内测转正

- 发行日期：2026-11-11
- 版本号：`2026.11.12`（转正：吸收 `2026.11.12-beta.1` / `beta.2` 两轮内测与本轮补入的多字符运算符修复）
- 上一个正式版：`2026.11.11`
- 适用：IntelliJ IDEA 2024.3 及以上（Ultimate / Community 均可，Database 能力需 Ultimate）

## 一、这一版解决什么

真机上一条 Oracle 查询里写着 `'%' || #GROUP_NAME# || '%'`，预览面板把它显示成 `'%' | | '弘博' | | '%'`——**一个双竖线拼接运算符被拆成两条竖线、中间还插了空格**。Oracle 下这是语法错误，而预览面板的文本同时就是「复制可执行 SQL」「分享」「直接执行」的输入源，`格式化输出` 又是默认开启的，所以这是默认就命中、且会一路带进数据库的失真。

同类面一并收口：`::`（PG/GaussDB/Vastbase 强转）、`<=>`（MySQL 空安全等值）、`->` / `->>`（JSON 取值）、`&&`、`<<`、`>>`、`:=`、`@>`、`<@`、`!~`、`~*`、`=>` 全部改为按最长匹配整体分词，三条格式化路径（普通 / 关键字换行 / 竖向排列）一处生效三处。

## 二、新增能力（来自两轮内测）

- MBG 生成的 Example mapper 预览能从调用点还原条件：`andXxxYyy` 方法体里的 `addCriterion("cust_id =", …)` 常量被读出来，产物从 `WHERE ( {{criterion.condition}} ? )` 变成 `WHERE ( cust_id = ? )`。
- iBatis 的 DAO 调用行可直接预览 SQL，跳转箭头旁新增预览图标，`Alt+Shift+Q` 在调用行与方法定义行同样可用；MCP 的 `sqlv_render_sql` 同步支持。
- 执行失败按原因给可点入口：命中「文件类型」忽略直达设置页、被 `.gitignore` 忽略直达该文件、方言问题直达 SQL 方言设置。
- 预览落点兜底改为自动改写加一次性告知；执行侧仍是阻断性失败，由用户点「改用项目根落点重试」才切。
- OceanBase 的 EXPLAIN 计划树给出与 MySQL 同口径的索引建议。

## 三、修复

- **多字符运算符被格式化拆成两半（T-SqlOperatorFidelity，17eabc420）**：词法器原只合并 `!=` `<>` `<=` `>=` 四个双字符运算符，其余按单字符吐出、格式化器再按「运算符两侧空格」拼回，于是 `||` 成了 `| |`。现在词法器按最长匹配整体吐 token，格式化器规则一字未改。
- **2026.3 上「临时 SQL 文件建不出 PSI」系列（T-ExecPsiGate R4~R7）**：平台闸门 `shouldCreatePsi` 问的是父目录，插件原按文件取判据；现在归因取文件与父目录的并集，并把钉方言自愈、vf 失效重定位一并补齐。
- **执行失败只剩一行红字（F5/F6）**：成因改为随失败文案本身传递（` [hint=XXX]` 标记），跨线程、跨渲染次数、跨类加载器都不丢；面板里五处执行回调统一走同一条提示。
- **预览一直降级、报错只剩 `unknown`（F3/F4）**：落点判定不再按路径缓存到会话结束，改为每次现探。
- **iBatis 预览里裸 `#name#` 参数不再丢引号（T-IbatisParamClassQuote）**：按 `parameterClass` 字段类型决定引号，纯数字不再丢引号。
- **复制可执行 SQL 会带出模拟占位（T-CopyPlaceholderMarker）**：产物头部加一条带计数的注释说明哪些是待替换的预览占位。
- **2026.3 上 MCP 工具页「点击前往」被拦下（T-McpSettingsJump）**：改为按页面 id 打开并选中，提示文案去掉版本断言。
- **控制台 MyBatis 与 Hibernate 日志补齐静默冲刷（T-ConsoleFlushAlign）**。
