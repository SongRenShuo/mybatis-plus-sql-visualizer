# v2026.11.12

- 字符串拼接等多字符运算符不再被格式化拆开：`||` `::` `<=>` `->` `->>` `&&` `<<` `>>` `:=` `@>` `<@` `!~` `~*` `=>` 在预览、复制与执行里都保持原样
- MBG 的 Example mapper 能从调用点还原条件，预览不再是 `WHERE (AND OR …` 这种残缺骨架
- iBatis DAO 调用行可直接预览 SQL，`Alt+Shift+Q` 在调用行与方法定义行都能用
- 执行失败按原因给可点入口：被文件类型忽略、被 gitignore 忽略、方言不匹配，各直达对应设置
- 临时目录建不出 PSI 时说明原因并给「改用项目根落点重试」，预览侧自动换备用目录且只提示一次
- 失败文案补上 vf 有效性、映射方言、IDE Build 等诊断项，反馈问题一次截图就够
- iBatis 预览里裸 `#name#` 参数按 parameterClass 字段类型决定引号，纯数字不再丢引号
- 复制可执行 SQL 时，产物头部会用一条带计数的注释说明哪些是待替换的预览占位
- 控制台里 MyBatis 与 Hibernate 的日志补齐静默冲刷；OceanBase 的 EXPLAIN 计划树也给索引建议

升级：覆盖安装即可，无需迁移配置。
