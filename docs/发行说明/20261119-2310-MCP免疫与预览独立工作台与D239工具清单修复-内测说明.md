## 这一版有什么

**SQL 预览独立工作台（T-SqlPreviewStandalone）**：主侧边栏新增「SQL 预览」页签——粘贴一段 SQL 或 mapper XML 片段就能快速格式化、填值、复制可执行 SQL（Tools 菜单与 `Alt+Shift+P` 直达）。工作台支持 iBatis 2 条件标签与占位语法（`<dynamic>` / `<isNotNull>`、`#id#` / `$name$`），网页复制的 `&lt;/&gt;` 转义与 markdown 代码围栏也能识别；在弹框中打开后直接贴内容会自动识别，缺失 `<include>` 片段留注释占位并给「点此补上」入口。随批修掉六轮走查缺陷：弹框打开失效、空弹窗贴入即识别、首开降级误报、长警告看全、错误信息可复制、Alt+Shift+Q 重新解析、补齐片段按钮跟随插件语言等。beta.1 之后工作台又能直接执行了（D233/D234）——「执行 SQL」复用语句预览那套完整执行链（Schema 校验、DML 二次确认、`${}` raw 确认门、方言闸、控制台内嵌），粘贴即可「解析 → 填值 → 执行 → 看结果」，解析成功后还会自动跑静态性能检查（`SELECT *`、缺 WHERE）。

**吸收 Hibernate Debugger 精华五项（T-HdAbsorb D215~D219）**：SQL 日志耗时按测量来源分档并补偿调试器挂起时段；同模板 60 秒滑动窗判定「疑似 N+1」红色徽章，点开按模板过滤成一组（条数/首末时间/涉及线程）；调用栈里的 JDK/CGLIB 代理帧反解为业务类型；数据源改名后按「URL+用户+库名」指纹兜底恢复记忆；MCP 工具输出可选摘要档（`detail=false`）。beta.1 之后又补上聚合摘要行排版重做（D235）——红色只给短标签、详情转次要灰、退出口链接化，修掉聚焦 chip × 错位与摘要中途消失两处缺陷；以及关掉「SQL 去重」不再让 N+1 检测与聚合一起失效（D237）。

**修复与加固：MCP 结构性免疫（T-McpGlobalBreakHardening）**——本批立项的缘起是用户报障「插件导致 IDEA 的所有 MCP 都无法使用」（2026.1.x 上过滤接口契约不匹配，插件把平台内置 MCP Server 整体拖垮）。本版把这类事故变成结构性不可能，并在真机走查中顺带修出两个真缺陷：

- 平台过滤器契约再变也不会拖垮内置 MCP Server：注册前按「契约白名单」判定，接口上出现任何不认识的方法（含 suspend 化）一律不注册；万一运行期还是调到未知方法，代理先按返回类型给安全值、并立刻把自己从平台扩展点摘掉——最坏结果是「门控不生效」，MCP 服务继续可用
- 关掉插件 MCP 总开关后，插件完全不碰平台 MCP 的两个注册面（toolset 与过滤 provider），重新打开后无需重启即时生效
- 修复 IDEA 2026.3 上 MCP 工具清单只剩 1 个的问题（2026.3 给工具集接口新增三个钩子，插件工具集没实现，真机实测 92 个工具只剩 1 个 sqlv 且无任何报错）
- 修复 MCP 设置子页改动要重启才生效的问题（子页 apply 漏发设置变更广播，热同步从未被触发；现在勾上/取消总开关立即注册/注销，真机双向实测）
- 设置页 MCP 区新增只读状态行「外部会话门控：已生效 / 未识别 / 已关闭 / 无此能力 / 已熔断」；Registry 键 `sqlvis.mcp.gateFilterEp` 是逃生开关，万一平台再改契约可只关这一项、不必卸载插件

**D239：2026.3 / 2025.3 / 2026.2 上 MCP 工具清单只列一两个的根治（beta.1 之后新增）**：工具集此前为兼容旧版 Marketplace 校验是运行期生成的壳类，2026.3 平台按 Kotlin 元数据扫描工具方法，壳类既无元数据也不自己声明方法，扫到哪个失败就停在哪，清单常只剩 `sqlv_render_sql` 一个。现在壳类补齐元数据、自己声明工具方法并带上注解、给业务类其余方法留同签名占位，11 个工具集都能正常展开；顺带修了平台工具清单缓存不刷新（重算复用注册初期那份残缺结果，连发三次重算都没用）。真机冷启动 / 关总开关 / 再打开三轮读数：165 个工具（含 11 个 `sqlv_*`）/ 154 个（0 个 `sqlv_*`）/ 165 个；2025.3 与 2026.2 走同一条展开链，同一缺陷一并修。

**优化与稳定性（T-PerfSweep31/32）**：iBatis 别名表索引化（首次预览不再整模块慢扫）；索引构建期点预览/跳转不再「点了没反应」（等索引就绪自动重试）；同一预览打开 exec 文件不再重复写盘；导出 HTML 报告移入后台；跳转图标缓存按项目隔离；预览参数已带引号的值不再被二次转义。beta.1 之后另修掉「IDE 被第三方长读锁卡住时插件跟着卡死」（后台等界面线程改有界派发、超时记日志继续走）。
