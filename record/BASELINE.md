## 三、定位纪律（本轮所有「点空/点错」都出在违反这几条）

1. **别目测**。本轮弹窗按钮行目测值偏低 **48px**、连点三次全落空；而三种「按证据算」的定位法一次就对。
0. **先把 IDE 弄到前台并校验**（`locate.ensure_foreground`）：置顶只保证点击不被别的窗口截走，**键盘快捷键要焦点**——不在前台时开文件/唤起预览会静默失败。另：窗口匹配必须**限定沙盒 PID**（`pid_by_cmdline`），否则会捞到别人的同尺寸窗口。
2. **弹窗按钮行按窗口底边算**（`locate.button_row_y`），因为弹窗高度随内容变。
3. **对话框/浮窗用 EnumWindows 按 PID 取矩形**（`locate.window_rect`），别按标题猜、别用主窗口句柄。
4. **亮文字带用像素剖面**（`locate.bright_band_y`）：逐行取均值找最亮连续段。实测按钮文字行均值 47~60、深色面板背景 26。
5. **暗色主题下阈值别按「空白≈0」定**：面板底色均值仅 28、收起态本底噪声就有 13（实测收起 13.09 / 展开 34.95 → 阈值取 22）。
6. **坐标算完回填本表**，并注明来源与是否稳定（高度/宽度可变的一律标「随…变」）。

## 四、自检纪律（`verify.py`，开录前必做）

```python
from verify import Guard
g = Guard()
g.mark("preview", region=(367,166,1190,702))
g.require("preview", msg="预览未就绪/已被浮层遮挡")   # 不符即中止，别录坏画面
r.start()
g.after_click((1256, 829), name="preview", msg="点『执行 SQL』落空")
```

- **开录前 `require()`**：确认浮层已清、目标面板确实开着、停在预期页。
- **点击后 `after_click()`**：无可见变化即判落空（坐标偏 / 未聚焦子窗口吞首击 / 上游开关置灰，症状相同）。
- **take 内必须有真实 UI 变化**：裸屏捕获不含光标，纯凝视 take 的鼠标移动不产生像素变化，会被静段裁剪整段吃掉（实测成片 3.6s vs 有变化时 7.5s）。

## 五、产物局限声明（T-TestGateGems W6-b，2026-10-24）

**每条成片必须自带「它看不到什么」。** 来源：magpie `.github/ui-preview/record.mjs` 的 `unseen` /
`mismatch` / `errors` 三个字段，全部渲染进 PR 块；口径同 `docs/code-standards.md:96-103`：
"What wasn't tried with the real thing isn't built on and isn't told to users as working."

为什么：演示图里「没看到某行为」会被读者直接读成「该功能不存在」。沙盒录制有三类结构性盲区，
必须在配图说明里逐条写清，否则等于用图说谎：

| 盲区 | 说明 |
|---|---|
| 沙盒许可态 | 录制跑在 runIde 沙盒，`-javaagent` 许可由 gradle 注入；真机正式许可下的表现未覆盖 |
| 工程索引规模 | 沙盒里的 demo 工程只加载演示所需文件，大工程索引下的耗时/交互未覆盖 |
| 数据库与环境 | 用本地 demo 库（`mpj_demo`/`mp_demo`），非用户真实库；方言/权限/网络差异未覆盖 |

成片说明模板（复制到文档正文或 GIF alt/说明处）：

```
> 录制环境：runIde 沙盒（JDK/平台版本见发行说明），演示工程为最小 demo。
> 未覆盖：真机正式许可下的表现、大工程索引规模、用户真实库的方言/权限差异。
```

场景脚本 `main()` 收尾应打印本次未覆盖项（对应 magpie 的 `unseen`）——不写即视为「无盲区」。
